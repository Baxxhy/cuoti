# 全站交付复查与修复

2026-10-21。范围为当前全部 50 个页面及学生、教师、家长、管理员流程。前端沿用 uni-app / Vue 3 / TypeScript，仓颉负责业务与 MySQL，Python 提供内部算法；没有更换架构或重写既有数据。

本轮使用 UI UX Pro Max、Information Architect、Frontend Design 和完成证据指导，结合逐页手机/桌面截图检查与真实业务操作；故障定位使用 Systematic Debugging。没有把技能名称当作设计质量或实验效果证明。

## 页面与流程

- **作答**：单题练习突出题目、输入和“提交答案”，移除前后题、答题卡、分值等无用操作。多题及考试保留进度和交卷确认。空答案不能提交；已停用的旧单题可“结束练习”，原题内容隐藏且不计分。
- **订正**：诊断优先引用实际首错步骤；历史或未验证的修正统一标为“待核对”。学习安排压缩重复说明，推荐行动使用主要按钮，其余步骤保留可查入口。
- **知识推荐**：修复卡片 ID 被误当题目 ID 的跳转。卡片详情支持稳定 ID 与原知识编号，保留“结合原题讲解”的题目上下文；讲解仍使用卡片的规范编号。
- **复习与资料**：修复搜索按钮换行，解除复习题干硬裁剪；空复习优先进入已有错题。知识列表去掉与标题相同的章节，组卷去掉没有依据的掌握百分比。图谱未读取时不再宣称“暂无关系”，切换学科等待或失败时清除旧图；画布与节点采用同一缩放，修复桌面连线错位。
- **统一表达与视觉**：统一“单选题”“向 AI 提问”；答题反馈不再用“方法变稳”等推断代替判题结果。空状态标题改为 18px，保留 17px 紧凑二级导航。题库及类似题练习不展示具体年级，选题范围不受影响。
- **角色页面**：家长中心提供明确的查看报告入口，解除关联弱化；教师指标支持键盘操作、按钮文字垂直居中；管理员图例不再逐字挤压，阶段名补齐中文；系统页区分“已配置”和实际可用状态。

其余页面逐一确认主任务、内容位置、字号、留白及当前状态，保留合理结构。完整清单及逐页判断见 [PAGE_AUDIT.md](PAGE_AUDIT.md)，没有用三个核心页面的截图代替全站检查。

## 算法判断

ECED 的来源核验、AEMT 的辅助感知更新、ARPP 的学习动作与选题排序是已有方法之上的项目定制。其实际作用是限制无证据判断、避免把看答案和局部订正计作独立掌握，并在当前范围、时间和复习需求下推荐下一步。**当前不能认定为全新基础算法，也没有学生实验足以证明提分优势。**

实际发现并修复 ARPP 恢复任务时忽略当前掌握度的问题：有本轮作答时采用新计算结果，只恢复时优先采用数据库当前状态。修改前两项复现失败，修改后工作流 12 项通过。方法、源码和验证边界见 [ALGORITHM_REVIEW.md](ALGORITHM_REVIEW.md)。
