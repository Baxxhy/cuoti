# 面向交付的持续产品复查

目标：手机优先，学生能找到下一步，内容密度合理、字号统一、长题干与公式完整；教师、家长、管理员能完成各自主要任务。后端算法以实际实现和验证证据解释价值，不为创新名称扩张流程。

沿用当前简洁蓝白风格、品牌首页、紧凑二级导航。使用 UI UX Pro Max、Information Architect、Frontend Design 的适用指导及完成证据技能。已有用户偏好优先，不另选装饰主题，不重复询问已明确的人群和任务。

执行：
1. 对最新 50 路由双宽度截图逐页人工检查，结合模板与真实接口判断内容放置。记录保留或修改理由。
2. 优先消除订正/讲解/复习中的重复引导，统一同类操作；随后覆盖录题、题库、知识、报告及各角色页面。
3. 审查 ECED、AEMT、ARPP 的数据输入、实际路由和学习结果保存；区分 BKT/信息增益等通用方法、项目自定义策略及尚无实证的效果声明。
4. 对发现的问题直接修复，用可重复场景和必要对照验证。保留真实模型与受控夹具的区别，不把算法命名当作新颖性证据。
5. 对改动页补充手机/桌面可视化，完成项目规定验收、更新交付说明并提交。

信息组织：学生围绕“题目→订正→练习→复习”操作，知识、记录和工具跟随当前任务提供。首页保留主要行动，设置归个人中心；角色工作台独立，学生界面不暴露内部算法与执行字段。

当前已发现：任务初始页重复展示规划理由；AI 讲解仍有旧品牌式按钮“问小智老师”；到期复习空状态引导重新录题而非查看已有错题，区块出现重复分隔线。后端需要核对 ARPP 无本轮作答时是否使用已有掌握状态。
