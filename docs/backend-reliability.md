# 后端可靠性边界

- 当前部署采用一个本地后端进程（一个 Uvicorn worker）。启动时，遗留的待执行、执行中识别任务会标记为失败，显示“服务重启中断”，用户可重新框选或重试。已完成任务和上传原图不会修改。此恢复策略不适用于多个 worker 共享任务；扩展部署前应接入有任务租约的独立队列。
- 图片上传上限为 15 MB、2500 万像素，接受 JPEG、PNG、WEBP。空文件、损坏图片、非法裁剪范围会返回可处理的输入错误。
- 修改题目或作答后，旧分析、诊断及知识映射失效，待复习计划取消；原作答版本和历史教学记录保留。旧教学会话不能继续提交新学习证据。
- 已完成的复习和已获得有效判定的同一道推荐练习不能重复增加掌握度。判定仍需核对的练习可以重试。
- 数学文本仅使用受限的词法和 AST 白名单构建 SymPy 表达式，不执行输入中的 Python。变量分母、变量负幂与分数幂、需额外检查定义域的符号函数保守交由复核；不把约分后丢失定义域的结果视为本地证明。无法可靠解析的不同表达式进入待核对状态。多行过程无法完成复核时，不依据最后一个答案更新掌握度。
- 只有完整的单变量解方程请求允许本地求解结果替换标准答案。模型不可用且没有可靠本地解时，分析、诊断返回可重试错误，不保存占位答案或模拟诊断。启动时不自动探测远端模型。
