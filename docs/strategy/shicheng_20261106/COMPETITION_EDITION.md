# 师承智学：创新创业与软件作品参赛版

2026-11-06｜基于[完整项目方案](PROJECT_REVIEW_DOSSIER.md)整理。本文提供可直接用于计划书、路演和演示的表达，以及下一步应制作的材料；不代表已经完成新增开发或市场验证。

## 1. 让评委记住什么

**师承智学——让好教法跟着学生走的AI学习伙伴。**

学生看过解析，却不一定能独立做出下一题。师承智学希望把优秀教师判断“学生卡在哪里、该怎样引导、何时放手”的经验，变成学生身边持续可用的学习支持。

项目面向K12学生，首先从初中数学切入，重点关注缺少持续个别指导的学生。依托已有错题帮，将拍题、卡点诊断、教法选择、互动引导、独立尝试和后续复习连成一个完整过程，让优质教学经验能够跨越地域被使用。

**作品最有辨识度的一幕：同一道错题，三种学生回应，三条教学路径；随后让学生自己做一道新题，下次进入还能接着学。**

## 2. 三项创新怎样讲得具体

|创新|作品中的具体设计|演示时出示什么|
|---|---|---|
|教师经验成为教学决策|案例同时包含学生信号、判断依据、适用条件、引导动作和调整方式|一张有来源的教法卡，以及它实际触发的指导|
|学生回应改变教学路径|先确认困难，再在提醒、示范、类比等方式中选择；能够独立继续时减少帮助|同题三条分支，以及主动换讲法后的变化|
|独立表现连接长期陪伴|区分受助完成与新题独立完成，用后续表现安排复习和下一步任务|一次自主新题、一次跨次恢复、一条成长记录|

答辩时把创新落在这三种可以观察的行为上。技术解释围绕行为展开：结构化案例与检索支撑选教法，规则和模型交互支撑调整，学习记录与任务调度支撑持续指导。数学核验、图示呈现和已有错题资产提供实现基础。

## 3. 创新创业类：补齐服务怎样持续

### 首个用户与进入场景

首个切入场景是初中数学日常错题订正：学生看过讲解仍不知道怎样继续，或订正后遇到相近题再次卡住。学生直接使用；家长可能参与工具选择和费用决策。乡村及资源相对薄弱地区是重点服务方向，首版采用在线工具交付。

先做“带着错题来，得到合适帮助，自己完成新题”的短流程，再逐步扩展学习目标和跨次服务。全面覆盖K12是长期愿景，首轮演示需要把一个学习过程做完整。

### 商业模式候选

|环节|当前可写入计划书的设计|下一步怎样判断是否成立|
|---|---|---|
|基本服务|提供基础错题记录、复习和有限互动体验，降低开始使用的门槛|观察学生能否自行完成首个学习过程，是否主动再次使用|
|可选付费价值|探索围绕学习管理、成长记录及经审阅内容的订阅；具体服务边界与定价后续确定|了解家庭认为哪些持续服务有价值，是否愿意实际选择|
|内容供给|公开专业依据和自编案例起步，逐步引入适当授权、经审阅的教师经验|记录每批内容的制作、审核、维护工时与可覆盖任务|
|运行成本|模型调用、内容维护、存储和运营支持共同计入成本；优先复用已审阅内容|按实际会话记录单次成本，结合实际使用频次判断可持续性|
|公益可达性|将基础功能与可选增值服务分层；探索公益支持名额|后续记录资源薄弱学生实际能否访问、完成任务和持续使用|

以上是拟验证模式，当前没有新增付费用户、收入、签约教师或公益合作事实。计划书中的财务页先列成本项目和计算关系：**每月收入＝实际付费人数×实际客单价；直接服务成本＝实际使用量对应的模型、内容及运行成本。**取得真实数值后再填，现阶段无需编造三年收入曲线。

### 怎样获得第一批使用机会

拟先制作一段可公开展示的连续演示和可体验样机，围绕一个明确学习问题介绍作品；之后根据实际反馈修正，再扩展内容。当前可继续利用公开资料准备案例，真实使用反馈放到样机可体验后取得。参赛材料分别展示公开需求依据、构造演示和实际使用记录，各自说明作用。

竞争分析围绕一条相同任务进行：带入本人错题、回应帮助、尝试新题、下次继续。比较各产品在这些步骤中的实际表现，再说明本项目在教师经验使用和连续指导上的具体设计。尚未实测的产品能力留待核验，不用“竞品都只能给答案”作为论据。

### 把个人贡献讲出来

创业创新赛也需要看清作品怎样由参赛者做出来。保留需求判断、关键取舍、本人完成内容和版本演进的记录；多人参赛时按实际填写分工。可以使用现有文档与提交记录组织这一页，无需为了写材料先补一个虚构团队。

## 4. 软件创新或个人作品类：把作品感做出来

建议围绕四个页面构成一条可操作的体验：**今天 → 学习 → 错题 → 成长**。评委应当能直接看到选择教法的依据、学生回应带来的变化，以及跨次继续后的下一步安排。

### 三分钟演示脚本

下表是制作脚本。学生情境为构造样例；需在样机中实际跑通后录制，未实现的画面标为设计稿。

|时间|画面与操作|评委看到的核心信息|
|---|---|---|
|0:00—0:25|展示原图：3x＋2＝17，学生写成3x＝19；学生说“看过讲解还是不会”|一个具体的学习困难|
|0:25—0:55|用短问句确认：两边同时减2怎样算？先依据回答选择帮助|选教法有学生证据|
|0:55—1:35|并排展示三条路径：能自改则提醒后放手；不理解等式性质则示范；会简单等式但不会连接则类比|相同表面错误引出不同指导|
|1:35—2:05|回到一条路径，让学生自己完成关键一步；展示“换讲法”后的响应|学生操作实际改变过程|
|2:05—2:30|切到新题2y＋3＝11，先不提供提示，记录学生自己的回答|受助完成与独立尝试分得清|
|2:30—3:00|再次进入“今天”，恢复之前任务；“成长”显示已用帮助和下一步复习|伙伴能够持续接着指导|

技术答辩使用一张简图：**原题与作答 → 确认卡点 → 检索并检查教法适用性 → 互动与调整 → 独立尝试 → 复习记忆**。解释项目自己完成的内容组织、策略和连续体验，现成大模型作为实现工具说明。

若以个人身份提交，另准备一页本人贡献与所用开源、模型及公开材料清单；是否允许单人参赛，按具体赛事当届规则选择。本文的“个人作品版”是一种材料组织方式。

## 5. 一段可直接用于路演的开场

> 一个学生拍下错题，得到了一篇完整解析，却仍然不会独立做下一道题。我们想补上的，是这段从“看懂”走到“会用”的过程。
>
> 师承智学把优秀教师判断学生困难、选择教法和逐步放手的经验，转化为可以被AI调用的教学决策。面对同一道错误，能够自行修正的学生得到提醒，概念不清的学生获得示范，有基础却不会连接的学生得到类比。学生的每一次回应，都会影响下一步指导。
>
> 我们从已有错题帮和初中数学起步，把拍题、引导、独立尝试与后续复习连起来，希望让缺少持续个别指导的学生，也能拥有一个懂得怎样帮助自己、并陪自己继续学的伙伴。

后接真实样机演示；若当前使用交互设计稿，开场后明确说明展示形态。

## 6. 计划书或路演的十页顺序

|页|标题|这一页回答什么|
|---|---|---|
|1|让好教法跟着学生走|作品是什么，服务谁|
|2|看过解析之后，为什么还会卡住|具体问题与公开需求依据|
|3|从教师经验到学生独立行动|三项创新如何连在一起|
|4|同一道题，三种教法|最有辨识度的演示|
|5|一次帮助，接上下一次学习|四入口与持续体验|
|6|我们怎样实现|关键技术、现成工具与本人贡献|
|7|经验与内容从哪里来|来源、自编、审核及维护流程|
|8|怎样持续提供服务|创业版讲用户、付费假设和成本；作品版讲体验与工程完成度|
|9|已经有什么，下一步交付什么|已有错题帮资产、当前新方案、待制作样机分别展示|
|10|让优质教学经验被更多学生使用|回到立意，用作品画面结束|

## 7. 赛道参考与当前最值得补的材料

2026年中国国际大学生创新大赛高教主赛道创意组，四项权重为个人成长30、项目创新30、产业价值25、团队协作15；创业组另有权重及经营表现要求。因此创业版需要补真实成长、贡献和服务逻辑。[官方规则通知及附件](https://cy.ncss.cn/information/2c93f4c6a00f063201a01815a08e0022)（2026-08-19发布，2026-11-06核读第1—4页）。这里据规则提出材料建议，未确认本项目报名组别。

2026年中国大学生计算机设计大赛设软件应用与开发、人工智能应用等类别，要求每件作品由同校2—9名本科生组成，故不能把它列成单人报名赛事。其作品类别可作为软件展示的参考；2026届节点已经过去，后续届次以新通知为准。[官方参赛要求](https://jsjds.blcu.edu.cn/info/1078/1718.htm)（2026-04-10发布，2026-11-06核读）。

按当前材料判断，**优先把作品做成可连续演示的软件创新项目，再为符合条件的创新创业赛增加用户、成本、持续供给和实际反馈材料**。这是对本项目现状的选型建议。

下一步最值得制作的三件东西：一段跑通三条教学路径与跨次继续的短视频；一份能操作的核心样机；一页来自实际使用的反馈与改进记录。它们分别让评委看见差异、确认实现、理解真实价值。当前这轮交付为文档，尚未新增这些实物或记录。

此前六角色评分是方案内部模拟评审，保存在原稿；本参赛版不新增分数，也不把该评分解释为获奖概率。**目标是提高评委识别项目价值的速度，并让后续作品能够支撑这份表达。**
