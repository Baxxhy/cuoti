# 01 项目立意

本文件受[当前版本与状态](README.md)约束；本稿V0.8，未通过。

建议候选名改为**独解学伴——以学习证据校准帮助的数学学习伙伴**。任务档案继续用“师承智学”标识原方向。去掉必须依靠名师头衔的品牌承诺；优秀教师的可授权策略仍是重要候选来源，是否带来增量须与通用策略比较。名称变化不算创新，也不为此加分。

一句话立意：**让缺少及时个别指导的学生，在得到帮助后仍有机会独立解决新题，并让每次教学选择接受新作答的检验。**

使命是扩大合适学习帮助的可获得性，而非替代教师。全国价值在于把可审核的教学策略转成普通终端可以使用的学习支持；是否缩小教育差距仍是H。首版以初一、一元一次方程中的等式变换/符号错误为完整验证场景；初二及其他数学内容为后续范围。长期服务更广K12，不能把首版结果外推到小学、高中或所有学科。

国家层面：优质均衡与教育数字化有明确政策依据[F，E-P1/P2]。社会层面：资源可见不等于学生获得适合当下困难的指导[I]。学生层面：辅助完成与独立完成必须区分[F，E-L1/L2]。行业层面：个性化与启发式辅导已有成熟主张[F，E-C1/C2/C3]。因此本项目应争取的价值是可验证的帮助质量，而非再增加一个讲题入口。

本项目有值得继续的立意；没有证据证明当前已达到国奖竞争准备程度。全国推广必须经过内容跨域验证、可及性及持续成本检验。真实效果、团队贡献和赛事资格缺失时，不以政策相关性替代。
