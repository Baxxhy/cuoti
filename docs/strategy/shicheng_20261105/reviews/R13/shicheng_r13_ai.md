# R13 独立AI技术复审

原意：保持。27、13、14仍以教师经验驱动完整学生伙伴，当前困难、选择教法、自主尝试与跨次复习连贯。首批数学内容约束可发布范围，没有缩小整体使命；当前材料优先和卡点解决后收束，也不等于放弃持续伙伴。

优点：新增中国调查比泛化政策或海外实验更直接支持反复求助与过程帮助期待；稿件没有把自报变成成绩、切换或付费。强对照处理明显更具体：教师参与设计筛查的缓存反馈也可有效；NUMI保持收益有限且耗时，Khanmigo整体效应不能隔离AI。生产先例支持作者校准、源条件核对与派生材料审阅，09没有拿采纳率、模拟对话或参与补偿充作合格产能和报价。新规则确实回应这些事实，18同时检查送达、动作、时间、覆盖与采用，超出了增加文献数量。

最严重问题仍是相对强辅导的净值未被直接识别，而且新证据提高了比较门槛。Bridge已有专家决策，ODPS已有历史/初始行为选策略，DICE已有干预核验；现在又有真实学生使用下的强提示、缓存反馈及受监督AI。项目可争取的是少误教、少重复负担和可维护的连续服务，不能从“案例有边界”直接推到优于它们。中国调查加强需求依据，但认可现有免费AI同时是替代压力；期待新功能不等于愿为新伙伴增加步骤。

历史缺陷的解释必须保留两面：Eedi先前辅导对话未传入，限制了对完整跨次对话记忆的结论；部分历史条件下的无增量仍是实际部署结果，不能整体作废。它既不证明完整记忆无用，也不证明修复就有益。13/14将相关历史作为可能改变动作的输入，属于合理待测选择规则，非该报告已经验证的最优策略。每条回复经真人审阅与本项目预审内容路线不同，94.7%未改也不能转成只审5.3%的工作量；09已正确限制。

重大设计异议：无新增阻断项。当前材料优先与历史按需使用能够相容，收束帮助与可选自主题也保留学生选择；源条件先核补强了供给链，未产生必须重构的新矛盾。必要修改：本轮无新的方向或模块修改要求。实施协议需将按原分配评价的部署净效应与送达诊断分开，故障者仍留在主要结果，不能只取成功送达子样本来证明机制；18保留全部分配者的原则应贯彻到分析，而非仅列人数。

外部未知：①内地初中数学学生在既有工具之外的实际开始、再用与家庭允许；②相同内容、历史、预算下的独立/延后结果，以及总时间、未接触内容和错误指导；③本地完整双审、返工、维护及模板复用成本；④付费与持续承担。现有研究不能关闭这些缺口，也无需先取得本项目因果效果才评方案。

下一步应保留整体方向。方案已能组织公平比较，优先取得可改变上述判断的材料与实际行为证据，不再靠扩功能、换题型或给教师身份加价来论证创新。新增证据提高需求判断信心，尚不足以提高相对净值结论。
