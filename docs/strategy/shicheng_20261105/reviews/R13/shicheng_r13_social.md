# R13 独立整体复审｜社会价值

忠实性：保留了教师经验驱动、学生核心、先初中数学的完整伙伴。今天—学习—错题—成长连接同一人的当前困难、教学选择、自主尝试和后续复习；有限内容是启动边界，没有再让题型取代使命。教师和家长仍是必要支持者。

最强改善是需求依据更具体、产品更克制。中国调查中，学生对提示、诊断和针对练习的直接期待，比一般答疑需要更贴近此方案；同时承认现有AI已有效，避免把乡村等同无人指导。当前材料优先、历史按实际动作需要调用、阻碍解决便收束，把“持续理解学生”与少占学习时间连接起来。基础固定路径、必要自检、资料带走与共享设备恢复，使社会价值有具体承担方式。

最严重问题仍是：需要过程帮助的人，是否愿意反复选择这一完整伙伴，而不是沿用免费AI、课程或真人帮助。中国资料是跨学段自报和期待，抽样与筛选限制仍在；学生与家长篇不是独立复制。香港英语学习不证明内地数学选择，未使用也不等于拒绝长期使用。英国逐条真人批准、美国校内学习时段和海外作者研究，分别支持机制或工序可行，不能证明家庭无人监督采用、乡村净收益或国内合格供给成本。新增研究也提高了强替代门槛：教师署名、更多历史和更长互动均不天然增值。

重大设计异议：无。教学选择、准入、更正、退出与服务责任链条自洽；新增来源已实际改变流程和评价，未把未知补成成果。评价纳入证据送达、总时间、课程覆盖、未开始与退出者，实质改善了公平性判断。

必要修改仅一处：18中预先说明“以后有需要时再用”的观察窗与需求机会判定，保留未返回且原因未知者，避免事后只在回访者中确认需求。此为既有指标的定义，不要求扩功能或每日使用。

外部未知须另证：目标学生在真实替代之间的选择、相同任务与时间下的自主收益及负担、不同终端条件的触达损失、完整写审维护成本和家庭承担。电脑研究能改进这些假设，不能验证真实农村受益。

方向判断：支持继续完整项目，不建议改成题包或教师平台。下一步应围绕上述选择与净值补真实证据；不以未开发、无自身因果结果自动否决，也不因来源增加而宣布普惠或商业成立。方案成熟度提高，持续采用可信度仍属有条件假设。
