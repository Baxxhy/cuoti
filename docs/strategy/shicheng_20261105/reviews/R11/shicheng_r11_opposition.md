# R11 独立反方完整方案评审

原意忠实性：整体忠实。学生核心、优秀教师经验、乡村及薄弱地区关注、错题帮复用和纯软件边界均回到主线；先初中数学、案例用于验证而非定义使命，合理。本轮按完整伙伴重评，不继承R10局部方案分数。

优点：今天—学习—错题—成长连接当前帮助与跨次学习；区分系统策略迁移和学生迁移；允许学生反驳、多个合理教法及未知；经验来源、推断、构造材料分开。固定内容可用、动态不强求，内容审核和更正进入持续服务，具备完整产品基础。

重大问题：主承诺仍比兑现机制更明确。Bridge已覆盖专家决策，DICE覆盖介入选择，LongTutor覆盖历史诊断；这些先例不否定产品创新，却要求说明本服务新增了什么。当前17主要是按构造学生证据分支，来源是公开方法启发；尚未完整展示某条教师经验如何经整理、排除边界和新回应改变教法。因此最强拒绝理由仍是“专业内容RAG＋现有错题帮连续流程”，教师经验可能只是合理包装。另一个设计缺口是“一个下一步”缺少多任务竞争时的取舍，四入口尚未充分说明持续伙伴怎样承担跨次学习决策。不是因没有新算法或真人试验否决。

恰好三项最重要修改：

1. 给出一条可核查的经验全链：公开原材料片段→明确观察与目的→整理推断→允许/禁用动作→学生实际得到的一步。明确哪些只能称专家原则启发、自编教学，哪些可称教师明确经验；未明示意图不随审核自动升级成教师原意。
2. 对同一学习事件写“有合格决策经验／只有同内容解析／该经验被排除”三条可执行轨迹，说明实际动作、希望观察的回应及换法依据。不能故意削弱解析基线；如动作相同就承认该事件不体现经验增量。再用现有迁移例检查这些约束，没有必要增加题型。
3. 补一名薄弱资源条件学生的跨次多任务旅程：新困难、未完成任务、到期复习竞争时怎样选一个下一步；前次教法失败怎样改变今天安排；设备中断、无人现场讲解及超支持域怎样继续。沿用既有四入口和能力，不新增管理端或功能堆叠。

外部未知：目标人群的具体任务优先级；具名强替代的同题总负担；来源质量、授权及专业审阅产能；跨情境教法的实际适用性；家庭采用、成本和持续支付。这些需对应事实，不能由构造轨迹或文案证明，也不要求先做本项目因果试验才评方案。

方向判断：保留原完整伙伴方向，不再缩成两题或规则包。应先把经验驱动和跨次决策做实；当前有潜力，但不足以给95。
