# R11 独立AI技术复审

先判对齐：通过。13/14重新围绕完整学生伙伴组织，教师经验—本人证据—教学行动—自主回答—复习连续，数学例题恢复为机制演示；这符合27，而非把原项目替换成题包。以下不继承R10评分，也不把本人机制建议视为正确答案。

优点：来源明确记载、编者推断和团队构造分开；学生可反驳，受助与自主分列，全局经验不因单次成败自动改写。17确实展示同错步因证据不同而示范、搭桥或撤助，并区分系统策略适配与学生学习迁移。有限规则与审核内容能支持纯软件起步，无须自研算法或私有名师视频。18允许强基线采用相同教法、保留动作等价和失败，比较原则合理。

最严重问题是**经验来源、家族适配与在线使用的准入粒度尚未闭合**。05/09提出候选萃取与审阅，17却主要是团队按宽泛原则构造的分支，未见一条完整的“原依据究竟支持什么、哪些条件是编者新增、哪些候选因此被拒”的决策样例。与此同时，14要求数学/教学审阅后使用，又允许新情境条件重建；尚不清楚已审家族能授权哪些即时重建，何时必须退回离线审阅。这不是已证矛盾，但若不明确，容易在“每题人工审”与“模型自行判教学适用”之间摆动，影响供给和可靠性。

其次，跨次修正还多为原则。17的复习轨迹未展示新回答推翻旧判断后，下一次帮助具体怎样改变。仅保存证据和写“结合历史调整”，不足以说明持续伙伴较一次辅导增加的决策价值。

近邻方面，Bridge已有专家决策及简化/相似问题，ODPS已有按历史与初始行为选策略，DICE已有干预选择与接受核验。当前合理差异是来源边界、个人过程和后续修正的产品连接，不是这些部件首次出现。05诚实承认覆盖，但尚缺上述连接带来实际行为差异的完整示范，因此创新不打高满分；这不构成“无新算法即否决”。

必要修改限三项：①用一个现有公开来源完成从原片段到决策案例的桌面样例，逐项标出明确依据、团队补充、未知和拒绝候选，不需真人效果；②明确一次学生新题进入时，已审范围内可即时适配的条件、越界回退及须重新审阅的变化，避免增加实时人工承诺；③补同一学生的一条跨次冲突轨迹，写明暂停哪项旧推断、新回应怎样改变下一动作、何时恢复撤助，不能用重复同答案代表掌握。

重大设计异议：无方向性或技术不可行的否决；上述准入粒度是当前核心未闭合项，尚不能只列为外部未知。建议下一轮只关闭这三项，不换题型、不扩功能。真实目标家庭任务频率、相对强替代的净收益、教学审阅一致性及本地内容/服务成本属于外部待证，不能写成成果，也不要求先取得它们才允许评方案。
