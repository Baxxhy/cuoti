# R1 独立反方评审：原始「师承智学」

日期：2026-11-05。只评原始方案，未读取其他评审。正文约710字。

优点：原始作答、错因回放、独立重做和复习形成可复用资产；关注“听懂却不会独做”比扩大讲题供给更有学生价值。纯软件、远程验证也符合团队边界。

致命问题：最强拒绝理由是核心新增贡献尚不可辨。[Bridge](https://aclanthology.org/2024.naacl-long.120/)已把专家隐性经验拆成错因、策略和意图，再驱动辅导回复；[讯飞](https://edu.iflytek.com/about-us/news/company-news/2833)已公开步骤错因、按实时状态调整策略、启发追问及针对练习。前两项创新高度重合，第三项闭环在现有错题帮已具基础。新加的名师经验供给链反而最费资源，未证明比通用模型加精良提示更有效。

具体质疑：同一错误为何足以区分粗心与概念误解？材料不足时会不会自信贴标签？教学视频能提供学生隐性状态和策略失败条件吗？名师经验是否经授权、能否稳定取得？学生愿否持续完成追问、迁移和延后测试？乡村身份为何必然意味着这套方案更有增益？纯软件可能改善获取成本，但不自动构成教学创新。

扣分原因：社会问题合理，目标却横跨整个K12；没有需求强度、流失、有效服务成本和付费证据。现有工程通过不等于新增教学机制有效。Bridge测的是回答偏好，讯飞数据为厂商自述，均不能替本项目证明学习成效。

必须修改：首版限初中数学一个反复犯错单元。保留采题、原步骤、重做和复习；经验库降为可选知识来源。优先比较更好的学生端方向：用短诊断追问区分候选困难，按新回答逐步撤除提示，以无提示变式及延后作答约束“已掌握”判断。新增价值必须体现在何时少帮、何时换法及未获益学生的恢复路径，并与现有错题帮、同模型普通辅导进行等时对照。[PNAS研究](https://doi.org/10.1073/pnas.2422633122)支持关注撤去AI后的表现，也显示仅加提示保护未必带来独立成绩增益，不能将该方向直接宣布为原创。

下一轮：支持大改后重审；不支持原案定稿或宣称95分成熟。更名不计创新。
