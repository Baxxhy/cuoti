# R1｜AI 技术专家独立评审

评审对象：原始“师承智学——名师教学经验驱动的 K12 个性化 AI 学习伙伴”。日期：2026-11-05。仅依据任务书、当前产品说明和公开研究，未读代码及其他评审。结论：支持修改后进入下一轮；本轮不通过。

**主要优点。**已有原作答、错误步骤、帮助记录、独立重做和延后复习，是比单次聊天更有价值的学习证据基础。学生端定位及纯软件边界合理；现有说明也诚实区分工程验证与学习收益。

**致命问题。**“萃取名师经验，再按学生状态选择策略”已与 [Bridge（NAACL 2024）](https://aclanthology.org/2024.naacl-long.120/) 直接重合：该工作已将专家的错误判断、补救策略和教学意图转为决策模型。[Tutor CoPilot（2024 起）](https://arxiv.org/abs/2410.03017) 已进一步研究专家经验支持实时辅导。整理案例、向量检索和 Agent 调度可以实现产品，但不能单独构成新方法。当前方案尚未给出扣除这些工作后剩余的可检验贡献。

**具体质疑。**同一移项错误怎样区分概念误解、偶然笔误和提示依赖？一条公开视频怎样证明教师“为什么这样教”，而非由模型补写理由？检索相关经验怎样保证适用？为什么新策略比固定追问更好？谁以何种许可提供中文初中数学经验及后续结果？[XES3G5M（2023）](https://proceedings.neurips.cc/paper_files/paper/2023/hash/67fc628f17c2ad53621fb961c6bafcaf-Abstract-Datasets_and_Benchmarks.html) 支持知识追踪研究，却不提供上述策略因果效果。

**扣分原因。**全 K12 范围超过已有证据；模型解释被默认为认知诊断；策略优劣没有同条件基线；工程测试不能证明迁移和保持；数据授权及内容维护成本未闭合。

**必须修改。**先限定初中数学一个错误簇；将经验约束为“可观察证据—适用条件—教学动作—停止/切换条件”，允许证据不足时先问诊。对比同一模型的直接辅导、普通 RAG、固定策略与状态匹配，并做去除教师经验、打乱状态的消融。分别测策略适用性、过度提示、无提示新题及延后保持；模拟学生仅支持离线筛选。先列数据许可，再承诺规模。[MathDial](https://github.com/eth-nlped/mathdial) 与 [TutorMoments（2026）](https://huggingface.co/datasets/allenai/tutormoments-preview) 可提供评测起点，不能替代中国学生效果证据。
