# R1 独立评审：教育领域专家（兼学习科学）

日期：2026-11-05。评审对象为用户目标中的原始“师承智学”候选；现有能力只据 `docs/final/README.md` 和《错题帮项目说明文档》判断。未参考其他评审意见，未审计代码，不修改正式方案。以下分数是模拟成熟度判断。

## 优点

学生始终是核心用户；原作答、帮助记录、重新作答与复习可以自然复用。现有错题帮已区分提示后完成与独立完成，也承认工程样例不能证明长期学习效果。这为可检验的学习产品提供了较好基础。

## 致命问题与具体质疑

1. **“名师经验→适配学生→真正掌握”三个箭头均未获本项目证据支持。**公开课能展示教师做了什么，通常不能证明为什么选择、替代策略为何较差，以及对另一类学生是否有效。凭名师身份不能给策略盖有效章。
2. **单次错步不能唯一识别认知原因。**移项符号错可能来自概念、规则混淆或偶发失误。怎样用一道辨别问题排除解释？无法区分时能否保留未知，避免错误画像持续影响学习？
3. **迁移与保持尚无严格定义。**改数字、换正负号主要检验相近任务，不能据此宣称广泛迁移；刚读解析后重做也可能反映短时记忆。土耳其高中实验发现，无约束AI组撤去AI后的成绩下降，教学约束缓解伤害却没有证明正向考试收益。[Bastani等，2025](https://doi.org/10.1073/pnas.2422633122)
4. **乡村需求尚停留在宏观层面。**政策确认优质均衡需求，不能证明目标学生愿意持续订正、具备可用设备或负担得起服务。国外大学或美国人机协同辅导的结果，不能作为中国乡村学生效果。[教育部等，2023](https://www.moe.gov.cn/srcsite/A06/s3321/202308/t20230830_1076888.html)

## 必须修改

首版收敛初中数学的少数明确困难；把使命落实为“帮助后还能独立解决新题”。经验材料标明原始来源、适用条件、反例和证据强度；诊断允许不确定，先辨别再辅导。验收分别观察无提示新题、预先界定的迁移题和7—14天延迟表现，并控制训练时间与题量。用相同模型比较现有错题帮、通用教学策略、经验匹配版本，检验新增价值。可先远程做内容盲评和使用测试；模拟学生只能验证流程，真人学习收益须另行测量。暂缓全K12、多学科、虚拟课堂及家长管理扩展。
