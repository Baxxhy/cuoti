# R9独立教育复审

仅读冻结R9指定方案及公开研究底稿，未读同轮他评。按方案成熟度评审，不以未开发、缺本项目因果效果或无新算法自动否决。

**最强改善：**由抽象“少问、收手”转为本人规则的条件修复，形成反例、合法对照、实际求解和延后检查的完整学生服务。内容包可审核、可复用，具备产品与服务创新价值。中国来源支持答疑与衔接摩擦值得关注，但未证明两种错误的全国发生率。

**逐式核对：**A原式解为x=1；补x≠1后无解；除非零3后仍得x=1。新题分别得−4、无解、2，均正确。B原式解x>−3；x=0反例、正数对照和严格边界正确；四项新题依次为x≤−2、x≥−5、x≤7、x<3。A/B按不同已学单元准入、基础不足先示范、给定反例计帮助、评价不泄露类别，均合理。同乘0是有效推论但一般不保等价，正文已有正确区分。

**重大反对：**17的“3x=3x约x得3=3，对全实数是否等价”混问了两式关系与论证有效性：两式解集确实均为全体实数；除x的论证却不覆盖0。若据“0处除法未定义”判两式不等价，会把正确理解判错。这是评分语义问题，不能据此否定A主体。24仍称“拒绝非法”、14末称“合法拒绝”，也会削弱前述精确区分。除此未见新的重大教学矛盾。

**三项具体可改行为：**

1. 将恒等式题拆问“两式解集是否相同”“约x能否提供全域论证”；接受“相同，但该论证遗漏0”。另用x=3同乘0后0=0测单向推论与非等价。
2. 全文按目标使用“运算未定义/可推出但不保等价/保等价”，将“合法拒绝”明确为“合法操作误拒”；三类分别评分。
3. 在旅程起点显式选择A/B，确认已学后做对应短先备操作；不只凭年级或勾选分配，也不要求学生先掌握反例术语。

**外部取证另列：**后续独立数学/教学审阅、真实任务负担、固定优质包与动态帮助的比较，及中国目标困难的需求强度。这些限制效果和推广宣称，不是本阶段先完成试验的门槛。

**结论：**支持修正后继续方案复审，当前不通过95分；保留学生学习伙伴方向，无须转向教师产品。
