# R9｜AI技术专家独立复审

对象：冻结V0.9及获准的CONT公开研究底稿；未读本轮他评、源码或接口设计。本轮评方案成熟度，不以缺新算法、未开发、缺自身因果结果或团队未知自动否决。

**最强改善：**主任务从泛化认知诊断转为可核查的规则适用条件修复。两个P0机制给出了原域、先备、有效反例、合法对照和实际求解；特别保留“除数非零”与“除负数变向”的不同数学边界，防止纠偏后形成一律拒绝。公开指导＋自编包、双审和有限版本维护使供给可启动。学生可纠正规则候选、暂停及回访，已构成连贯伙伴流程。

**近邻与差异：**Bridge覆盖专家教学选择；DICE覆盖干预及接受核验；LongTutor覆盖历史诊断；SMRC覆盖正确步骤保留；SymCE覆盖删假设及符号反例。余下价值是将本人可修正规则、原条件核验、合法/不适用的独立实际运用连成服务，属于可成立的产品流程创新；不能称上述部件首创。当前没有发现阻断窄域立项的重大技术矛盾。

**仍反对直接通过95：**部分独立任务同时提示“评价约去是否保留解”，可能主要检验被提醒后的条件检查，而非求解时自行使用条件。规则核验还须在学生呈现和判分中落实“结论对但步骤未定义”的双重状态。技术差异有具体载体，但相对固定优质包的必要性仍是待检验主张，扣创新与产业准备度，不等于方向无价值。

**三项可改的方案行为：**

1. 对`3x=3x`约x等边界，分别输出运算定义、推论/等价及最终解；结论碰巧正确不能放行全域除法，也不能抹去学生正确结论。
2. 学生用展开法独立解对、条件解释仍不足时，记录“求解完成、条件待查”，只提供可选短补救，不重走整包或强迫指定解法。
3. 正式新题先无条件提醒地求解并冻结，再问变形理由/条件；分别报告自发运用与被提示后的辨别，允许练习阶段继续明确引导。

**外部取证另列：**两包的独立数学/教学审阅；同输入固定包与强RAG的误放、误拒及总负担；目标学生真实求助事件与内容维护成本。需要宣称学习收益时再取得对应独立/延后结果。这些是待取证事项，不是现有设计自相矛盾。

**裁决：**支持进入下一轮，维持未通过95；不必改换方向。IES证据等级与公有领域版本、OATutor逐条归属及OpenStax现行/历史许可均已区分，发布时照此逐项执行，不能凭代码许可放行内容。
