# R9 独立反方复审

最强改善：R9已从泛泛“更懂学生”转为具体的规则条件修复；原条件内反例、合法对照、独立实际求解和回访形成连续学生服务。两个包确实需要不同数学审阅，公开指南加自编包也解除私有名师材料的启动依赖。产品流程创新成立为可评对象，不以新算法、开发或自身因果结果设门槛。

重大反对：无足以推翻整体方向的重大反对。支持完整学生伙伴定位。定稿仍有局部行为缺口；创新分保留扣分，因为正确/错误例与强辅导已有覆盖，独特价值应落在本人规则、条件证据及持续修订的可靠连接，不能笼统承诺更会迁移。需求及产业扣分是目标任务的相对优先级、跨包持续选择理由尚未充分落实，不把这些未知说成设计已失败。

最重要的三项修改：

1. 拆开17的“3x=3x约x得3=3对全实数是否等价”。前后解集恰相同，但除x在x=0无定义。分别问解集关系和该操作能否作为全域变形依据，接受“结论相同而此依据不成立”，防止把正确理解误判。
2. 将“明确持有错误规则／知道条件但漏写／无法确认规则”写成不同的正常续接分支：第一类可进反例修复，第二类局部补证后直接新题，第三类只核对实际步骤、不要求先认领模型规则。表达不出条件句也可用正确操作展示理解，不因此阻断后续。
3. 明确一次短任务的最小结束点与跨次补测：优先处理一条关键规则，合法应用和不适用修复可分次完成；未覆盖项显示未测。多处错误先处理阻碍当前求解者，避免把每包四题或两个包变成固定闯关负担。

必须外部取证另列：目标学生实际遇到的重复误用及现有替代；具名强辅导同题的条件正确性和总负担；自编包独立审阅、返工及跨包维护成本；家庭持续选择/支付。它们决定优势、效果与经营宣称的强度，均不要求本轮先开发。

裁决：支持沿当前方向实改后再审，无需另换路线；本轮未达95。下一轮应看上述行为是否落定，不能只增加原则说明。
