# 17 完整主线的设计演示

V0.12。以下为团队构造/文献方法启发，不是已授权教师原话、真人使用或效果。完整旧数学校核在[R10案例](rounds/R10/17_DECISION_CASES.md)，新数量关系探索在[研究底稿](research/NEXT_CASE_CHECK.md)；它们均只是验证材料。

## 学生跨次使用的一条旅程

学生从今天选择“看这一步”，带来3x+2=17及本人写的3x=19。伙伴保留原图/作答并核对，不先覆盖标准答案。原步骤相同，回应证据不同，行动应不同：

|本次可观察证据|可考虑的合格动作|为何不同/何时退出|
|---|---|---|
|学生核对后自行写3x=15、x=5，并能继续|局部确认，直接给可选自主新题或结束|没有必要再给完整概念教学；这不是确诊“粗心”|
|学生连u+2=8也不会处理，认为只改一边仍相等|先正确示范双边同操作，再让其做一步|搭桥依靠的先备不存在，不能不断出相似题|
|简单等式能做，但明确说不知怎样处理3x这个整体|可用熟悉子任务搭桥，先观察能否自行写3x=15；也可有其他低负担合格动作|系数消元另核，不能因会u+2=8就假定会3x=15求x；若已能局部自查就撤去搭桥|
|作答含义或识别不清|核对实际文字/变量，或未知|不把模型补写的步骤当学生事实|

此处结论经简单方程核对。系统不必先问满一套诊断题，能直接用共同短检查时就先帮助。学生可反驳、跳过、请求换法。

之后学生订正；伙伴提供完整题干的新方程2y+3=13先自主作答。审阅解y=5，属于相同技能新题，不称远迁移。提交冻结后才可选问理由；求助转练习。完成可结束，不强制整包。

之后从今天/错题复习进入未见任务，先答再看：如4z−1=15，z=4。记录真实间隔/帮助；再次卡住时结合前次教法和新回应调整。成长展示当时受助、此次自主或尚未测，不出“永久掌握”结论。正式确认集须独立编制、平衡答案和难度，不能由背答案通过。

## 同一学生：旧成功与现在失败冲突后，伙伴具体改什么

以下各天及回答都是设计演示，非使用日志；不把示范间隔当最佳复习安排。

|时刻与实际证据（构造）|学生看到什么，伙伴改变什么T|保留什么/不能得出什么|
|---|---|---|
|第0天，用搭桥从3x+2=17写到3x=15；系数消元另核后，学生在无帮助新题2y+3=13独立写y=5|本次结束，之后可先自主尝试；不再默认整段基础讲解|保留原帮助和这一次自主成功，不判永久掌握|
|第7天，同时有上次未完应用题、到期方程复习和本人现在带来的作业|本人主动开始当前作业时先处理当前题；若只是打开今天页且未选任务，先给到期复习这一建议，同时可选继续未完或新问题|未完/复习保留，改选可另约下次；不罚分、不自动加量、不替学生决定紧急性|
|学生选择当前作业4z−1=15，却写4z=14；不愿先做复习|暂停旧的“本次可以直接撤助继续”安排，先用共同短核对：两边都加1时右边是多少；不用逼其重讲上周全部过程|一次当前失败不能抹掉第0天成功，也不能确诊退步/粗心；若学生立即自纠则直接继续|
|学生回答“只改左边也可以”，与旧先备冲突|本次不沿用搭桥；用已审正确例说明双边同操作，再请其回原题自己写4z=16。此时只观察等式操作，下一步求z另核|受助订正不计新的自主能力；个人当前先备改为需复核，不改全局家族|
|订正后学生愿意再试：只给完整新题5v−4=11，独立写5v=15、v=3|本次先收束，不追加基础追问；成长标这次新题自主完成，下一次仍先给未见任务尝试，再决定帮助|恢复的是可撤助尝试的安排，不是“先备永久成立”；不会用刚教过的原题冒充新证据|

若学生不愿再试就结束，下一次先提供可选复核；没有新自主回答便记待查，不强制完成来填满成长图。这条持续轨迹的价值在于少重复交代、该换教法时换、该撤助时撤；是否比强替代更省事仍须比较。

资源较弱条件不当作学生能力标签。上述学生若使用家庭共享手机、中途须归还设备，只结束本次并保留已保存原图、回答、帮助和停点；下次接着该停点，可换任务，不把中断记为不会。未上传/未保存的内容明确提示，不能声称全部已留存或可离线AI辅导。没有现场教师也不强求实时转接；超支持域就保留问题、用合格常规路径或待查，不能给未审教法填空。设备可支配时间和愿用仍是待核事实。

## 同一事件，三种内容条件怎样影响行动

继续使用“当前双边操作先备不成立”的同一事件，下表是预期可执行轨迹T，不是跑过模型得到的比较结果。三个条件均能读到相同原题、历史、当前回答和帮助记录；不限制强基线正常推理或追问。

|内容条件|本次动作、观察与调整T|能否说明教师经验有增量|
|---|---|---|
|假定已有合格决策案例，含先备/禁用分支|识别搭桥禁用，改已审双边同操作示范；观察学生自己写4z=16。不会求z另核系数消元，不继续把两种困难混成一种|说明约束怎样落到动作；尚未证明胜过强基线|
|只有同内容解析的强辅导，无显式案例边界|可据同样当前回答自行选择正确示范、追问或其他合理帮助；若也检查双边操作、改法和系数消元，按等价动作计|相同行为就承认本事件不能识别决策案例的贡献；不预设它只会整题灌答案|
|检索到搭桥经验，但其先备被当前回答排除|不运行该经验，转已审基础分支/合格常规帮助；无合格路径则待查，原记录继续可查|排除本身有可检查意义；强RAG若也排除就不算独有优势|

有/无案例的区别须看跨事件能否更稳定地排除不适用、少误教、少重复输入及是否便于审阅维护；观察和成本须实际比较。不能用这份构造表证明现有工具做不到，也不能只靠字段可追踪宣布国奖创新。

## 一个策略家族怎样在不同情境使用

家族：**从已有子任务搭桥，再交回原任务。**公开依据包含Bridge的简化/相似问题动作、IES的已解问题分析；以下具体条件、材料与退出是团队设计待审，不冒称原作者给出了该完整规则。

|检验情境|先备/目标|适配动作|不能省掉的核对|
|---|---|---|---|
|方程复合项|学生确会简单双边操作，当前不知复合项怎样连接|用简单等式说明相同操作位置，再让其回原题处理3x|不能把简单题答案抄回；先备不成立改基础示范|
|换算中计算执行|学生已说明分钟到秒为何乘60，确会8×6，但把8×60写成560|先调用8×6=48，连接60=6×10，再由学生回到480秒|单位关系若不懂，就先澄清单位，不能只练乘法|
|同表面方程错，但双边操作本身不懂|家族所需先备未成立|本次不适用，给正确示范或其他合格路径|不因题面相似沿用；不把照抄当会|

第二情境为自编变体；Bridge存在类似7×60的修订路径，后续学生为教师模拟，不能算真人效果。这里展示同一教学关系的重建，不承诺首发扩到新学段。[详细来源限制](research/SPINE_DECISION_MECHANISM.md)

原字段和被拒候选见[公开来源桌面追踪](research/DESKTOP_SOURCE_TRACE.md)。从原例到自编材料增加了先备与退出条件，全部属于团队设计待审；允许的在线重建和必须重新审阅的变化见[05](05_CORE_INNOVATION.md)。

**系统策略迁移**看新情境是否保留先备、目标、搭桥及回原题关系；**学生迁移**须另看学生脱离帮助做新题。家族适配成功、回复像教师或模拟续答都不能替代学生证据。

## 经验如何成为可用依据

专家材料明确原则/意图→整理本次动作及适用/无益/未知情境→数学/教学审阅→实际一小步帮助→本人新回应→本次调整。缺少原意只标团队推断；教师不同意见可保留多个合理动作，不强求唯一标签。

收到矛盾回应先核材料、先备和帮助暴露，换法或未知；一位学生失败不自动删全局经验。反复不适用案例进入离线复审，严重内容错误停版本、说明更正并保留历史。

## 数学与判分底线继续保留

变量意义/背景域先核；反例可以是原关系真而本人模型假，也可以反向，须说清检验方向。运算定义、推论/等价、最终答案分开；例如3x=3x与3=3同解，并不使x=0处除x有定义。局部核验不能伪装完整解题证明。新题先自主求解，理由可选，不因合法替代方法判错。

本页说明主线怎样工作，不决定首发仅做上述题目。已展示材料都是开发/讨论样例，不是封存确认集。
