# 05 教师经验、教学决策与策略迁移

V0.13。整体候选机制，不是新算法/理论首创结论。具体数学题用于验证，不定义项目使命。

## 三项候选怎样构成一条链

|候选|要解决的具体问题|产品要求|不能以什么代替|
|---|---|---|---|
|经验转为可用教学决策|解析文本不说明此时为何这样教|原依据/目的、先备、可选动作、适用/不适用和回应后的调整可审|名师语气、视频摘要、检索命中|
|证据驱动的选择与策略迁移|相同表面错误可能需要不同动作，新情境不应照搬|根据本人作答/历史/帮助条件选允许动作，换情境重核边界，回应不符可换法|统一错因标签、同解析改语气、更多Agent|
|自主证据驱动持续学习|提示后原题正确可能掩盖未会|新题自主尝试和之后复习分层，证据决定继续/撤助/下一任务|题量、时长、复述或模拟学生答对|

## 经验的使用单位

“教学决策案例及策略家族”回答：老师看到了什么、要推进什么目标、学生已有何先备、为何选某动作、何时不适用、什么回应触发调整。公开明确意图、原可观察行动、整理推断、团队构造分开；来源没说的目的就未知。

策略家族保留教学目的、依赖的先备、关键行动关系与失效边界，具体例题不是可原样复制的脚本。RAG可检索依据，但最相似文本不直接等于下一步教法；先核目标和证据，决定用、不用、先核对或暂缓，并形成学生能回应的一小步。

## 一次决策必须能解释实际变化

看本次原步骤与疑问→区分已支持/冲突/未知的先备和帮助历史→选择有适用依据的动作（可多种合理）→观察一个可核查回应→继续、换法、撤助或保留未知。若不同解释有共同低负担帮助，不为分类多问；不循环至学生认同模型。

同错步下，已自行修正者直接自主尝试；基础不足者正确示范；已有简单操作却在复合任务无法连接者可搭桥。学生新回答可推翻先前判断，不以历史答对强迫继续某教法。[具体轨迹](17_DECISION_CASES.md)

经验还要决定何时少说。默认依据当前题、本人当前作答与本次帮助；当前材料足够选择共同短帮助时，不展开整份历史。跨次继续或历史可能改变先备、禁用、换法/撤助时，才调用对应旧证据，保留其当时的帮助条件。提及上次成绩或写了教学计划不算已经使用经验，必须能指出哪条证据改变了实际动作；合理动作本应相同时允许不变。

当前阻碍解决后，结束本次帮助或由学生自愿试新题，不因固定脚本再追问一轮概念。想系统补基础可继续相应合格路径，不把长聊当深入学习。此为据[新真实试验](research/POST_R12_PRIMARY_FINDINGS.md)落实的选择规则，未证明其效果；长期学习仍由之后新回答检查。

## 策略迁移与学生迁移分开

|对象|保持什么、重新检查什么|确认依据|
|---|---|---|
|系统策略迁移|保留教学目的/先备/关键关系；重建新题数学内容、表示与动作，核禁用条件|留出情境中的适用与排除、数学正确、独立教学审阅、交互负担|
|学生学习迁移|学生自己在未见题/表述/情境使用知识|自主回答、窗口帮助、相应范围的延后表现|

例：先借已会子任务搭桥再回原任务，可用于复合方程与一项数值执行困难；先备本身不成立就不得照搬。它只是可审家族设计，不表示已训练出跨学科泛化模型。[来源及构造边界](research/SPINE_DECISION_MECHANISM.md)

首期可用有限明确规则与审核内容起步。后续案例积累用于修订适用边界，不把一次受助正确或模型偏好当因果规律；局部失败先修本次选择，全局经验更新另行复审。

## 一次审阅授权什么，学生新题到来时能改什么

审阅单位是**策略家族及其允许的课程范围、先备证据、动作和退出分支，连同具体材料或有界参数模板**。只审过一个案例，不等于已审所有方程或所有“搭桥”。审阅状态、适用范围和来源分别留存；当前候选仍未获真人审阅通过。

|新题/新回应情况|可以即时做的调整T|不能即时扩大的权限|
|---|---|---|
|属于已审内容与模板，目标/定义域/表示及先备条件均符合|选择已审动作；在模板允许的数值、符号和表达范围重建；核数学与学生所见结果|不能因求解正确就认可新教学条件；不符合范围不强套|
|新回答推翻原先备，或学生已自行解决|切到已审基础分支、共同短帮助、撤助或未知；更新本人的当前判断|不自动修改所有学生的家族规则|
|来自未审知识域、表示/定义域有新要求，或需要新先备/新动作|保留原题与学习记录，说明经验支持范围；用已有合格常规帮助，仍无合格路径则待查|不以模型自评给新分支发布许可，也不承诺每题真人在线审核|
|准备新增域、先备条件、教学动作，修正数学/适用边界或改变模板结构|先离线完成数学与教学审阅，并回查受影响提示、自主任务及旧推断，再发布版本|单次成功、模型偏好或数学验证均不能代替教学审阅|

例如，已审正整数系数的一次方程模板不能顺便接受含未知数作分母的方程；那是定义域与目标变化。首次把搭桥用于单位换算也要先审该内容域及条件，不能在学生会话中凭“同一家族”自行跨域。策略迁移仍可研究、审核后使用，不要求每次换数字重新人工审整题。

[公开来源桌面追踪](research/DESKTOP_SOURCE_TRACE.md)逐项标出原动作、原标注、团队补充、未知与被拒候选；原例标签为提问/提示错误，不把整理出的“搭桥”倒写成原教师标签。可追溯和有界适配是可检查要求，不自动等于创新已胜过近邻。

## 与最近工作的关系及证伪

Bridge已有专家决策，ODPS已有按历史/初始行为选策略，DICE已有介入与接受核验，LongTutor已有长期诊断，强教育产品也有个性化主张。**三个候选均有先例，不能按字段数或组件组合宣布独有。**

可检验的整体贡献是让有来源、有适用/失效边界的决策在学生个人长期流程中稳定起作用，并用新回答纠正使用。如果只是换句话、强RAG同样做到且更省事、跨情境丢了先备、或自主任务没有增量，则相应主张不能成立。比较固定优质内容、同模型同内容强RAG和近邻覆盖点，允许其自然作同样教学。

国创赛接受产品/服务/流程创新，不要求所有项目新算法，但仍要具体差异和价值。当前是待评候选，不继承旧局部方案分数。

AI辅助萃取可先按教学转折定位学生线索、教师动作和明确说明，对齐原片段，再归纳策略家族及适用/反例候选；审阅确认后才进入使用。未明示的意图保持未知或团队假设，自动归纳不等于已证有效或允许自动发布。
