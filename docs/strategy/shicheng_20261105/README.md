评审角色使用六个隔离初始上下文，同一模型家族；每轮独立提交之前不读取同轮其他角色意见。后续复审保留各自历史判断。模拟角色不能代替真人专家、用户或教学实验。只共享提交方案及公共证据，不共享其他角色评分。没有将论文上传至外部模型评审服务。

内部权重：立意25%、需求20%、创新20%、产品15%、可行10%、产业10%。委员会六维分采用六位评分逐维中位数，再按权重计算；另保留每位信心分和重大反对，一项不满足就不通过。95只表示用户定义的内部准备成熟度。最多8轮；未通过即提交原因与具体补证要求，不强行生成V1.0。

事实标签：**F**公开资料明确支持；**I**基于资料推断；**H**待验证假设；**T**本团队设计/验收目标。所有尚未实测的数值阈值均为T。来源的发布日期与核验日期分开，网页未标日期时明确注明。来源及素材公开可访问不等于取得产品再利用授权。

用户后续要求：集中项目强度，团队/资格不作为本轮产品方案否决项，不再追问。官方参赛资格仍需实际报名时核对。本阶段不要求先开发或证明全部学习因果效果才可评方案；公开证据、可说明的差异、可实现的产品和可验证路径是评审重点。历史观点保留，不以此口径校正强行抬分。
