# 08 范围裁决

版本状态见[README](README.md)。

**P0：**初一一元一次方程等式变换错误簇；学生个人课后订正；原图/原回答；证据不足辨别；有条件且经审核的教学材料；受助记录；无提示同单元新题；到期复习和恢复。最小监护授权及内部内容审核为支撑。默认一题一困难，目标短时完成；时长与提问上限须测试后定。

**P1：**同一学段扩展到经验证的少量数学单元；策略质量与失效回顾；学生可选择分享的周期报告；进一步弱网体验和可及性优化。必须先证P0使用与内容可靠，不能为路演先扩学科。

**P2：**高中/小学及其他学科、教师独立审阅入口、机构内容共建。小学开放式生成使用边界须重新审查，不沿用初中流程。不会自动升级为教师培训、班管和备课产品。

**删除/退出新项目主线：**虚拟课堂、数字人名师表演、人格标签、无限聊天记忆、家长排名监控、教师班级作业管理、全学科知识图谱新建。现有模拟考试、整卷练习、批量组卷和PDF/Excel导出暂不作为新项目首版主导航/创新；可保留旧产品维护入口，无须删除已有工作。基础知识卡保留，复杂关系图展示后置。

取舍原则：一项功能若不改变当前学习决策、独立结果或可获得性，则不进入P0。新策略需要新增内容与质量证据，不因已有模块就强行保留，也不因想冲国奖就新增入口。
