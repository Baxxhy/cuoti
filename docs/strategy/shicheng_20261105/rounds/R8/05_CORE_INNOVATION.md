# 05 创新点说明书（候选）

版本状态见[README](README.md)。以下是待证研究贡献，不称首创。公开先例见[A1—A6](research/AI_EVIDENCE.md)。

## 一条主张、三个互相约束的环节

**核心候选：让教学帮助的选择与撤除，接受可追溯策略条件和学生新作答的共同约束。**

1. **可追溯的条件化教学策略。**每条材料明确来源/授权、年级知识前提、可观察困难、支持/反对证据、建议动作、停止/切换条件、已知失败和审核。材料没有说明的教师意图只能记为萃取者推断，不能包装成名师原意。比普通文档检索多的是发布边界和失败条件；这些字段本身不是创新证明。
2. **承认不确定的辨别与选择。**同一错步保留多个解释；先用短问题区分，再选择合格帮助。缺证据则保留未知或退到基础解释，允许新回答推翻旧判断。知识追踪只提供线索，不当认知真相。与普通Prompt的区别必须通过成对状态案例和对照证明。
3. **以撤去帮助后的表现反馈教学选择。**同题提示后正确只能说明辅导推进；新题无提示、表征变化和延迟保持分别记录。适用策略持续失败则降级/停用，不能因学生刷题多而证明策略有效。这是产品机制，须防把短期数据当策略因果。

## 同一表面错误的产品设计例

例子均为团队构造，不是实际教师案例或用户访谈。学生把3x+2=17写成3x=17+2。候选H1等式性质不清、H2知道性质但规则操作混淆、H3偶发笔误。先请学生说明“从上一行到下一行，你对等号两边分别做了什么？”；若再问“两边同时减2”，这已经是教学性提示，之后答对不能追溯证明学生原本知道。回答只更新当前可观察证据，不给学生确诊认知类型；仍不清楚就记未知。

H1用等式两边同操作解释；H2对照正确/错误变换让学生说明；H3给局部检查提醒后尽快撤助。不能以一次回答断言永久类型。教师审核前，这三个动作都只是设计样例，不能冠以已验证名师策略。

## 可证伪条件

若同模型、同内容和同时间下，条件化策略不优于普通RAG或精良通用辅导；若状态打乱不改变结果；若删除经验来源后不变；若撤助新题更差或退出显著增加，则核心假设不成立。可以保留基础错题帮，降级经验匹配为内容功能，或转向更窄的可解释诊断研究；不得用新名称掩盖阴性结果。

当前研究价值：策略适用边界、证据不足时的选择、错误决策被新回答修正。当前普通功能：OCR、聊天、画像、图谱、RAG、Agent、练习与复习。完整逻辑为“合格经验供给→有证据选择→帮助后独立测量→纠正下一次选择”；任一箭头缺证据都不能声称闭环有效。

## R6后进一步收敛

核心帮助控制规则：仅当不同合理解释会改变下一步帮助时才辨别，否则直接提供共同适用帮助，不为诊断标签多问。每个分叉需列证据、动作差异和无益边界，见[公开场景与差异](23_PUBLIC_CONTEXT_AND_DIFFERENCE.md)。ODPS、POMDP和2026诊断—补救评测都构成近邻；不主张信息增益/策略选择首创。实际竞争力取决于这项约束能否在较低负担下减少不适用帮助，强基线也可能实现，允许融回错题帮。
