## 学生为什么反复错

一种错误可能来自概念、规则混淆、先备知识、抄写或偶发运算；这是诊断候选，不是由单个错步直接得出的事实。例题读懂可能依赖外在提示，相近变式可能只反映同结构练习；不能由此确认跨情境迁移。学生难以发现漏洞，需要可观察的新回答帮助区分解释；模型给出的“认知状态”仍是可被纠正的估计。长期掌握须有间隔后的无提示作答，间隔不能一律越长越好[L4]。

原型中的符号错误只是演示案例，不声称已确认其在人群中最高频。首发选择它，是因为题型边界清楚、可核对等价变换、已有资产可复用[I]；频度和需求强度仍须调查。

## 八项立意答复

重大问题是缺少个别支持时，学生难以将一次受助完成转为独立能力。它关联优质教育获取，但本项目只处理课后少数任务。社会关注有政策与学习研究依据；具体普遍性及严重程度尚无目标样本量化。当前方案并非完全没解决，而是不同产品/研究已覆盖许多环节，本项目增量待证。AI可降低策略表达和交互供给成本，却不能保证判断正确。全国价值取决于可复制内容与实际可及性，不以全国学生总数作为市场。国赛评委可能认可问题与路径，但目前不能认可已具竞争成果。

R6后补证：课标明确等式性质与方程；2023原始数学教育研究揭示等号/移项困难及教学方法受学习背景影响。因此首发不是凭空场景，但仍不能估计中国初一频度或乡村需求优先级。[逐源日期与边界](23_PUBLIC_CONTEXT_AND_DIFFERENCE.md)
