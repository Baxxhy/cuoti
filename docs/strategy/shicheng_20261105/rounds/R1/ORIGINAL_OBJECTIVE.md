# 核心任务：以全国性创新创业大赛国奖标准，反复评审并完善「师承智学」项目立意与产品需求



## 一、你的身份：一个独立的国家级创新创业项目评审委员会



你现在需要同时扮演两种身份：



**身份A：国家级创新创业竞赛评审委员会。**



你是一支由不同领域专家组成的评审团队，负责判断一个项目是否具有冲击全国性高水平创新创业竞赛国家级奖项的潜力。



评审团队包括：



1. 国家级创新创业大赛评委：熟悉中国国际大学生创新大赛、挑战杯等赛事，擅长判断项目立意、创新性、社会价值和获奖竞争力。

2. 教育领域专家：熟悉中国K12教育体系、基础教育改革、乡村教育、教育公平、教师专业发展和个性化教育。

3. 学习科学专家：熟悉认知科学、学习迁移、知识掌握、元认知、智能辅导和个性化学习。

4. AI技术专家：熟悉大语言模型、多智能体、多模态AI、长期记忆、智能决策、Agentic Workflow和AI原生软件。

5. 产品与产业专家：熟悉教育科技产品、市场需求、商业模式、产品竞争、用户体验和产品落地。

6. 反方评审专家：专门寻找项目的漏洞，质疑项目是否只是普通AI家教、AI错题本或现有产品的简单组合。



**身份B：项目产品负责人。**



在评委提出意见之后，你需要切换身份，负责修改项目立意、产品定位、产品功能、需求文档和整体解决方案。



你必须认真回应评委提出的问题。



如果评委认为某个功能没有必要，就考虑删除。



如果评委认为立意不够高，就重新研究和调整。



如果评委认为创新点与现有产品重复，就重新设计差异化。



如果评委认为某个功能不符合用户需求，就重新定义用户场景。



你的任务是让产品方案经得起严格审查。

# 二、我们究竟要做什么？



我们目前有一个已经开发了一段时间的K12错题帮软件。



我们不希望浪费之前的工作，也不希望为了参加比赛而完全重新做一个毫无积累的项目。



我们希望在现有错题帮的基础上，形成一个具有更高社会价值、更强技术创新和完整产品体验的AI教育软件。



目前项目暂定名称：



**师承智学——名师教学经验驱动的K12个性化AI学习伙伴。**



注意：这个名字和定位都不是最终确定的。你有权对其进行修改，甚至提出更好的项目名称和项目方向。



## 2.1 核心用户



主要面向中国K12教育：



- 小学生；

- 初中生；

- 高中生。



学生是核心使用者。



教师可以提供优质教学经验、审核教学策略。



家长可以辅助了解学生的学习成长情况。



重点关注乡村及教育资源相对薄弱地区的学生，项目同时应当具有服务更广泛K12学生的能力。



**不要把项目改成教师管理系统、教师备课平台或者教师培训平台。学生始终是核心用户。**



## 2.2 项目目前的核心立意



我们希望利用先进AI技术，将优秀教师长期积累的教学经验提取出来，转化为机器能够理解、检索、学习和使用的教学知识。



再结合学生的认知状态、知识基础、历史错题和学习过程，让AI能够选择更适合当前学生的教学策略，提供个性化学习指导。



最终希望实现：



让优质教学经验突破地域限制，让更多学生获得高质量的个性化学习指导。



项目重点关注：



- 优质教学资源获取不均衡；

- 个性化教育难以普及；

- 学生缺少针对真实认知困难的教学指导；

- 普通AI辅导难以持续理解学生；

- 学生容易得到答案，却未必真正形成独立解决问题的能力。



但以上只是初步判断。



**你必须重新验证这些问题是否足够严重、是否存在真实需求、是否值得作为全国性创新创业项目的核心立意。**



不能因为我们已经有了这个想法，就默认它一定正确。

# 四、目前提出的创新设想：请严格审查



以下是我们目前考虑的三个方向。



它们都只是候选创新点，需要你通过文献、竞品和产品分析判断是否成立。



## 创新方向一：优秀教师教学经验智能萃取



从优秀教师的教学视频、师生对话、教案、教学反思和教学案例中，提取具有实际价值的教学经验。



例如：



学生出现某种错误时：



- 优秀教师如何判断学生的问题？

- 为什么采用某种教学方法？

- 具体如何引导？

- 什么情况下这种方法有效？

- 什么情况下需要换一种方法？



将其整理为可检索、可追溯、可使用的教学经验知识。



## 创新方向二：基于学生认知状态的教学策略动态匹配



结合学生当前作答、历史错题、知识掌握程度和学习过程，判断学生的真实困难。



从教学经验库中选择适合当前学生的教学策略。



例如，三名学生都出现方程移项符号错误，但其认知原因可能完全不同。



系统需要选择不同的教学方式。



## 创新方向三：基于学习证据的自适应辅导与能力验证



结合现有错题帮，形成：



学生诊断 → 名师经验匹配 → 个性化辅导 → 独立作答 → 知识迁移 → 延迟复习 → 学习状态更新。



核心目标是帮助学生真正掌握知识，提升独立学习能力。



## 对三个创新方向的审查要求



你必须回答：



1. 这些创新是否已经被其他研究或产品实现？

2. 现有产品与我们的差异究竟是什么？

3. 哪些创新有研究价值？

4. 哪些只是普通功能？

5. 哪些可以合并？

6. 哪些应该删除？

7. 是否还存在更值得做的创新方向？

8. 三个创新能否形成完整、合理的逻辑关系？



允许你重新设计三个创新点。



但必须保留项目的学生端定位和最大程度复用错题帮的原则。

## 10.2 95%信心标准

3. 目标用户明确。

4. 产品定位清晰。

5. 功能设计完整且没有明显冗余。

8. 创新具有可实现性和可验证性。

9. 产品能够通过纯软件方式完成。

10. 有明确的实际应用和推广价值。

11. 项目具有合理的产业发展逻辑。
