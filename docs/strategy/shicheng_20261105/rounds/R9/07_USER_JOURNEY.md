# 07 学生旅程

V0.9。两条完整构造轨迹见[17](17_DECISION_CASES.md)，均非用户研究。

|时刻|学生动作与前台内容|系统责任|退出/异常|
|---|---|---|---|
|开始|处理一道、继续上次、到期回访|普通终端；显示本次任务，不展示模型参数|可只查阅自己的资料|
|核对|看原图、改文本、确认本人哪一步|保留原图，不补写学生没写过的步骤|没步骤可补/走普通帮助，不冒充规则诊断|
|说出方法|先写一句依据或确认/修改候选|候选可反驳，区分明确表达与模型推测|只抄错/已能修正直接短路径|
|检验条件|预测或代入一项，比较条件不同的变形|反例在原域内；先备不足给正确示范|无合格内容不临时编一条充数|
|修订|自己补条件、完成原题|接受不同合法解法；提示被记录|无进展可换基础一次或结束，不循环至认同AI|
|自己用|未见题实际求解，应用与不适用辨别|先答后看，不预告正反类别；求助转练习|没有合格新题记未测|
|收尾|本次结果、已看帮助、下一步，可带走短说明|不把当日受助原题完成算掌握|可选分享，不自动发送|
|之后|到期先做未见短任务，再看原记录|记录真实间隔与新证据，旧规则可改|未回访记未测，独立正确后减少帮助|

每次是一道题的一个困难；不强制完成所有环节。学生只想核对、固定帮助已足够或已能独立运用，立即结束。弱网/模型失败保留草稿、原图和已审核固定内容，恢复不重复计学习事件；改原题后旧分析需复核。

教师在幕后供给/审阅内容，家长承担必要监护授权及学生可选支持。持续伙伴关系来自记得实际作答、理解待解之处、选择合适帮助，而非无限对话、人格标签或数字人。
