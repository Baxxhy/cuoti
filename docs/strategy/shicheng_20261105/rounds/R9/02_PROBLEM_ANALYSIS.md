**构造场景，非访谈：**学生在3(x−1)=6(x−1)两边约去x−1，得到3=6判无解。可能是忘条件、漏写分情况、不理解解或抄写，不能直接贴概念标签。若核对后确实忽略除数可能为零，x=1是原条件内反例；还须检查能否接受除以非零常数3的合法变换。

任务是把规则修为“同除非零量；可能为零先保留相应情况”，在新题独立用对。已知条件者核对表达即可，不会代入者先学基础，抄错者无需反例。[数学与教学轨迹](17_DECISION_CASES.md)

订正、理解、新题和回访在不同时间发生，旧产品适合承接连续路径I。公共内容优先复用或合法链接，固定帮助够用就结束，须根据本人步骤修正规则才动态交互T。候选价值是比重讲整题更适合当前困难H。

公开研究使场景更有依据，仍没有中国初中“换条件又错”的代表性比例。北京轮换成本支持连续性，不直接证明规则修复频率。首次选择来自可核验、旧资产和内容复用I；实际频率、净负担、使用意愿待事件研究H。

撤销“名师萃取本身新颖”“普遍缺帮助”“问得更少就是主创新”。错例可能加负担，固定纠错练习可能同样有效。新增路径若使学生拒绝合法操作，应修复或停用该包。[验证](18_VALIDATION_PROTOCOL.md)
