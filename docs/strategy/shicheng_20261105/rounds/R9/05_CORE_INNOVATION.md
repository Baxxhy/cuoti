# 05 核心创新载体

V0.9。**候选产品与服务流程创新：围绕学生本人的数学规则，完成适用条件修复和双向独立运用。**不是发明反例教学、RAG、符号算法或学习科学理论。

## 一条核心链，而非三个技术标签

|环节|具体做法|学生得到什么|限制|
|---|---|---|---|
|本人规则|引用原步骤；可由学生先说，也可展示待确认候选；允许改写、拒绝、未知|AI的理解可被纠正|一次错步不等于稳定信念|
|条件证据|明确实数范围、原题限制和变形目标；反例须满足全部原条件|看见哪里成立、哪里不成立|一个反例反驳过强规则，不证明完整新规则|
|适用教学|按代入/运算等先备选择正确示范、结构对照或反例|不会基础时先补基础|没有理由改变动作就不加问诊|
|规则修订|学生补条件、保留有效部分；不强制照抄术语|形成自己能用的短说明|复述正确不等于会运用|
|双向独立运用|未见题中实际求解，既接受合法变换，也识别并修复不适用步骤|避免从“总能用”变成“一律不能用”|判断题猜中、原题重做不作迁移|
|后续修订|保留帮助与新作答；之后失败可改旧规则|伙伴随证据更新|不写永久认知标签|

## 内容单位发生的变化

“规则边界学习包”包含：学习目标/前提、原步骤类型、可修正规则、合法与不适用对照、数学理由/反例、先备路径、独立求解与边界任务、来源权限/审阅版本及维护记录。它让教师经验可以被实际使用、检查和修正。不是一题一张名师卡，也不是无边界地采集整课。

两个具体包见[17](17_DECISION_CASES.md)。同一交互和内容准入可复用，除数非零与不等式方向的数学条件、先备、反例和测验必须分别写审，不能一键扩科。[供给](09_FEASIBILITY_ANALYSIS.md)

## 先例、机会和证伪

专家策略、选择介入、长期记忆、修正步骤和反例核验已有直接先例，见[04](04_COMPETITOR_ANALYSIS.md)。余下机会是将本人可修正规则、严格前提对照、正反独立实际运用和连续记录组成适合学生的完整服务。本轮定向研究未证明全球无相同系统；2026赛事认可产品/流程创新，但这种组合也需有净价值。

与固定审核包比，检验本人匹配/动态教学是否值得；与同模型同内容强RAG比，检验整条过程的可靠性和负担。若只提高辨别标签、不提高实际求解，或使合法操作拒绝增多，主张失败。若去掉教师来源不影响结果，就保留好内容而撤销名师优势。若固定路径足够，优先固定路径；不把增加聊天作为创新结果。
