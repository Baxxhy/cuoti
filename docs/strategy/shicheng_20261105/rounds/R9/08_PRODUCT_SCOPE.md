# 08 产品范围与演进

V0.9。首发完整学生路径，内容边界与产品完整性分开。

|阶段|内容与学生能力|进入下一阶段的依据|
|---|---|---|
|P0|两种已学初中代数机制：除数非零条件；数字系数不等式负数乘除。各含先备路径、本人规则、对照、实际新题、回访和恢复|数学/教学内容准入、负担与比较有可解释证据，不以先做全K12启动|
|P1|同学段关键概念逐包加入，如分母原始定义域；学生可选择分享的周期进展；可及体验|每包重审条件、先备与任务，检查旧包回归；不能只换数宣称扩展|
|P2|更多数学学段，之后才研究其他学科、机构内容共建或教师独立审阅入口|相应内容、适龄、许可和学习证据重新成立|

P0六个任务束为材料核对、规则确认、适用教学、独立运用、延后检查、记录继续。必要监护和内部内容准入为支撑，不新增完整教师/家长业务平台。默认一题一困难，可跳过、暂停、结束。

原图、OCR、证据回放、任务恢复、数学验证、题库、新题作答、帮助记录、记忆、复习和报告复用。旧考试/组卷/批量导出不作为新项目主入口，保留已有工作。删除新增数字人、虚拟课堂、人格标签、家长排名和教师班管。

持续项目的扩展单位是“一类有条件的数学方法及其学习包”，不是页面数量。概念路径只根据已学内容与回答安排，不把未知标会，也不强迫为了留存重复已会单元。
