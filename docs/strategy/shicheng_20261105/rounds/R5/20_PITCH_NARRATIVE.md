# 20 路演核心叙事（候选）

版本状态见[README](README.md)。以下是建议讲法，展示前须以实际材料替换占位事实；不把构造案例称真实学生。

“得到解释”和“自己会做”需要不同证据。以一个构造例子开场：三位学生都写错了移项符号，一位不理解等式性质，一位混淆规则，一位只是笔误。仅凭这一步不能知道该怎样教，我们先提出能区分困难的短问题。

接着承认现有产品：拍照、诊断、启发式讲解和复习都已有，错题帮也已经形成这些基础。新项目要验证的不是再多一个AI老师，而是帮助何时适用、何时应换、什么时候应让学生自己试。

展示同一题的证据、候选解释、经审核策略、帮助记录和独立新题。教师经验提供可使用且可追溯的教学材料；没有依据时明确未知。最后呈现延迟任务，说明“这次会了”与“之后能独立完成”分开记录。

把这一小环节连接到社会目标：普通终端上的合格帮助，可能服务缺少及时个别支持的学生。它是否真的降低负担、改善独立学习、惠及资源较弱家庭，要靠真实使用和对照证明。当前不展示虚构用户规模、提分或合作学校。

结尾应交代真实进度：已有错题帮资产、已完成研究和本轮评审；新增机制尚待内容授权与真人验证。拟用同模型强基线、无提示新题、延迟结果和单位任务成本检验。若结果不支持，就缩减或调整，而不是扩大功能掩盖问题。
