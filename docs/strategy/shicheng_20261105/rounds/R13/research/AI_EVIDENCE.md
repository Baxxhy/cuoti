# 师承智学 AI 技术证据卡｜R1 可复用底稿

核验日期：2026-11-05。范围：2023—2026 年智能辅导、教师经验萃取、教学决策、知识追踪和公开数据许可。以下仅采用论文作者、正式会议、研究机构及作者数据入口。用于原始方案独立评审；未读取本项目代码和其他专家意见。

标签含义：**事实**为原始来源明确陈述；**推断**为本评审基于来源作出的判断；**未确认**表示本次核验不能支持对应承诺。论文、代码和数据许可分别记录。

## E1｜Bridge：专家经验转为教学决策已有直接工作

- 原链：[NAACL 2024 正式论文页](https://aclanthology.org/2024.naacl-long.120/)、[作者预印本](https://arxiv.org/abs/2310.10648)、[作者仓库说明](https://github.com/rosewang2008/bridge)、[作者数据卡](https://huggingface.co/datasets/rose-e-wang/bridge)。
- 日期：预印本首发 2023-10-16；NAACL 正式发表 2024-06。可信度：高，正式会议和作者发布。
- **事实**：用认知任务分析显化专家补救错误的决策，包含学生错误、补救策略、教学意图；提供约 700 段专家标注的真实辅导对话。
- **许可**：[GitHub LICENSE 为 MIT](https://raw.githubusercontent.com/rosewang2008/bridge/main/LICENSE)；作者 Hugging Face **数据卡为 CC BY-NC 4.0**。两者适用对象不能混同。数据研究使用需遵守署名与非商业条款；用于收费产品或商业训练的额外授权**未确认**。
- 用途：最近工作对照、错误诊断与教学动作分类、离线策略匹配基线。
- 限制：英语数学辅导场景；专家偏好或标注相符不等于学习收益，不能直接迁移为中国初中生有效性证据。
- **推断**：原方案“名师经验萃取＋学生错误匹配”与该工作直接重叠。仅增加 RAG、长期记忆或 Agent 名称不能补出新贡献。

## E2｜Tutor CoPilot：专家经验支持实时辅导已有实证路径

- 原链：[2024 年冻结版本](https://arxiv.org/abs/2410.03017v1)、[当前版本与修订历史](https://arxiv.org/abs/2410.03017)、[作者演示项目说明](https://github.com/rosewang2008/tutor-copilot/)。
- 日期：首发 2024-10-03；当前页面记载修订至 2026-10-10。可信度：高，一手研究；不同版本应分别引用。
- **事实**：系统向正在辅导的真人提供专家式建议；报告了 K12 场景随机对照研究。它验证的是人机协作路径，学生并非脱离真人监督使用自主 AI。
- **许可**：[演示代码为 Apache 2.0](https://raw.githubusercontent.com/rosewang2008/tutor-copilot/main/LICENSE)。本次入口未确认可下载的逐条 RCT 原始对话及其独立数据许可；论文许可也未单独确认，故不列为可直接移用的业务语料。
- 用途：证明“扩散专家经验”不是无人研究的空白；参考策略评价及真实场景对照研究设计。
- 限制：研究版本中的纳入样本、消息量和成本口径有差异，本卡不混用数字；既有试验结果不能支持本项目无人监督、中文 K12 全学科效果，也不能直接用其美元成本估算本项目。
- **推断**：保留学生端仍可成立，但差异必须落在可检验的学生证据、教学决策及能力结果上。

## E3｜MathDial：教师动作与引导对话可公开研究，但学生是模拟的

- 原链：[EMNLP 2023 正式论文](https://aclanthology.org/2023.findings-emnlp.372/)、[作者仓库](https://github.com/eth-nlped/mathdial)、[作者数据卡](https://huggingface.co/datasets/eth-nlped/mathdial)。
- 日期：预印本首发 2023-05-23；正式发表 2023-12。可信度：高，正式会议和作者发布。
- **事实**：约 3000 段数学辅导对话，由真人教师与扮演错误学生的 LLM 交互形成；带学生错误和教师动作信息，研究避免过早泄露答案。
- **许可**：作者 GitHub README 明写 **CC BY-SA 4.0**，作者 Hugging Face 卡写 **CC BY 4.0**。存在官方入口冲突，不能任选宽松声明后承诺商用；固定所用发布版本并向维护者确认适用许可，确认前按存在 ShareAlike 义务处理。翻译、改写和再分发仍须跟随所用版本条款。
- 用途：策略动作分类、提示设计、离线对话评价与公开基线。
- 限制：英语题目、模型扮演学生；模拟“纠错成功”不能当作真人掌握、迁移或长期保持证据，也不等于可直接获得中国名师经验。

## E4｜XES3G5M：中文知识追踪可做，不能由作答日志推断策略因果

- 原链：[NeurIPS 2023 正式论文页](https://proceedings.neurips.cc/paper_files/paper/2023/hash/67fc628f17c2ad53621fb961c6bafcaf-Abstract-Datasets_and_Benchmarks.html)、[论文全文，许可见 3.1 节](https://proceedings.nips.cc/paper_files/paper/2023/file/67fc628f17c2ad53621fb961c6bafcaf-Paper-Datasets_and_Benchmarks.pdf)、[作者数据说明](https://github.com/ai4ed/XES3G5M/blob/main/README.md)。
- 日期：NeurIPS Datasets and Benchmarks 2023。可信度：高，正式会议和发布方说明。
- **事实**：包含中国三年级数学学习数据，约 1.8 万学生、550 万次交互、题目文本及知识点辅助信息，用于预测后续作答表现。
- **许可**：论文 3.1 节明确数据以 **MIT** 发布；[仓库 LICENSE 同为 MIT](https://raw.githubusercontent.com/ai4ed/XES3G5M/main/LICENSE)。使用和再分发保留相应版权及许可通知；并不赋予识别匿名学生的权利。
- 用途：知识追踪、冷启动和校准研究；可以作为“学生画像已有成熟任务和基线”的证据。
- 限制：小学三年级域，不是初中数学；没有与目标方案相同的教师干预、提示暴露和延后独立测量，不能证明策略匹配有效，也不能将预测正确率解释为唯一认知原因。

## E5｜LearnLM：智能辅导的强近邻与监督边界

- 原链：[Google/Eedi 研究预印本](https://arxiv.org/abs/2512.23633)、[论文 HTML](https://arxiv.org/html/2512.23633v1)。
- 日期：arXiv 首发 2025-12-29。可信度：较高，一手探索性 RCT 报告；本卡不将预印本当作已完成所有外部复现。
- **事实**：165 名英国中学生参加研究；专家逐条审核、编辑或替换 LearnLM 拟发消息。评价区分原题错误补救、后续同单元表现及后续单元新题表现。
- **许可**：论文 HTML 明示 **CC BY 4.0**。该论文许可不能自动覆盖 Eedi 学生原始数据或模型权重；可下载完整试验语料及其授权**未确认**。
- 用途：对照智能辅导评价层次，避免只以原题在提示下做对作为产品验收。
- 限制：效果来自有人监督的具体平台和学科安排；“后续单元新题”是论文的操作定义，不能扩展成远迁移、长期保持或全自动 AI 优于教师。
- **推断**：师承智学若主张无人监督，应另验策略可靠性和独立结果；不能借用该研究的效果。

## E6｜TutorMoments：2026 年已有“何时帮助、何时收手”评测

- 原链：[Ai2 官方发布文章](https://huggingface.co/blog/allenai/tutormoments)、[发布方数据卡](https://huggingface.co/datasets/allenai/tutormoments-preview)、[数据卡原文](https://huggingface.co/datasets/allenai/tutormoments-preview/raw/main/README.md)。
- 日期：官方文章 2026-08-07；数据卡按 2026-11-05 可见版本核验。可信度：较高，一手预览数据与研究发布，尚非已完成同行评审的全部结论。
- **事实**：公开 462 段真实数学辅导会话及教学标注；当前运行集合包含 520 个关键时刻，考察合适支架、认知挑战和过度帮助。回放续写包含 LLM 模拟学生。
- **许可**：数据卡写 **CC BY 4.0**，同时说明面向研究和教育并遵循 Ai2 Responsible Use Guidelines；模型生成回放还受各提供方条款约束。不得重新识别学生，发现残余个人信息的记录不可继续分发。商业使用具体组合条款尚未逐条确认。
- 用途：检验策略“是否适时”、过度提示及学生状态敏感性；可先做离线反例库。
- 限制：单一美国项目，英语为主；部分标签由模型协助，回放不是独立学生学习实验。不能把专家标签命中率包装为实际提分。

## 对原始三个创新的直接判定

| 原始创新 | 最近证据 | 本轮判定 | 能改变判断的证据 |
| --- | --- | --- | --- |
| 优秀教师经验智能萃取 | Bridge；MathDial | 已有直接方法与数据，不成立为泛化首创 | 提供比专家任务分析或简单抽取更可靠的适用边界、错误检测与审核证据 |
| 学生认知状态动态匹配策略 | Bridge；XES3G5M；TutorMoments | 状态预测和情境决策均有先例，组合本身不能证明创新 | 同题表面错误相同、证据不同的配对测试中优于普通 RAG 和固定策略，且避免过度推断 |
| 辅导—独立作答—迁移—复习 | MathDial；LearnLM 等 | 合理产品闭环及评价目标，不自动成为新算法 | 无提示新题与延后测量中的比较证据，并明确测量范围 |

可研究的剩余差异是：**在有限可观察证据下，决定是否需要先问诊、何时适用/停用某条教学经验，并能让错误决定被新回答纠正。**这仍是候选设计，尚未证明新颖或优于现有方法；需重新做最近工作细查和同条件比较。

纯电脑阶段可以完成公开数据筛选、许可核对、策略适用性标注和模拟回放。真人教学效果需要经授权的远程学生研究；不是必须进入学校拍摄课堂，但也不能靠模型互聊代替。当前未确认有同时满足“中国初中数学＋授权名师意图＋状态—策略—学习结果”的现成开放数据，不应把多个异质数据集简单拼接为已具备的数据闭环。
