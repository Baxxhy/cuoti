# 建设性调研：以完整学生价值组织规则迁移学习项目

研究日期：2026-11-05（Asia/Shanghai）。本次不评分，不读同轮他评，不读源码，不修改正式方案，不联系外部机构。本文件是研究建议，不是已验证的产品结果或开发指令。共采用5项一手来源，实际读取范围见末表。

## 1. 官方规则允许什么：不需要把产品项目变成算法论文

**2026规则没有规定所有项目必须提出新算法。**高教主赛道创意组明确接受产品、工艺流程、服务及商业模式方面的创新；创业组同样列这些方向。红旅公益组也列产品和服务创新。附件文本检索未见“算法”字样；结论主要依据上述正面条款，不能只凭关键词未出现推断。[S1通知](https://cy.ncss.cn/information/2c93f4c6a00f063201a01815a08e0022)、[S2规则附件](https://cy.ncss.cn/picture?name=%E4%B8%AD%E5%9B%BD%E5%9B%BD%E9%99%85%E5%A4%A7%E5%AD%A6%E7%94%9F%E5%88%9B%E6%96%B0%E5%A4%A7%E8%B5%9B%EF%BC%882026%EF%BC%89%E8%AF%84%E5%AE%A1%E8%A7%84%E5%88%99.pdf&path=pxe67lv2y8kifl50)，通知2026-08-19，核验2026-11-05。

因此，把“无新算法”设为本项目的否决门槛，会误用规则。成熟算法与已有教学原则可以用于新产品；要说明改变了哪段学习过程、为何值得学生采用，以及如何检查价值。组件有先例不等于整体产品没有创新，但功能组合本身也不自动成立创新。

**方案成熟度与真实参赛实践必须分开。**当前可审问题、机制、流程、供给、产业逻辑及验证路径是否自洽，不要求先开发；正式参赛则还评价调研、成果、落地及真实贡献，创业组还涉及经营绩效。内部95不是官方获奖线，方案通过不能写成已具国奖实践成果。[S2](https://cy.ncss.cn/picture?name=%E4%B8%AD%E5%9B%BD%E5%9B%BD%E9%99%85%E5%A4%A7%E5%AD%A6%E7%94%9F%E5%88%9B%E6%96%B0%E5%A4%A7%E8%B5%9B%EF%BC%882026%EF%BC%89%E8%AF%84%E5%AE%A1%E8%A7%84%E5%88%99.pdf&path=pxe67lv2y8kifl50)，第1—5页，核验2026-11-05。

## 2. 三个官方国奖案例：可以学什么，不能反推什么

### 案例A：灵知寓学-基于RAG增强的大模型沉浸式智能教育系统

- **官网确认奖项**：第十九届“挑战杯”2025年度中国青年科技创新“揭榜挂帅”擂台赛，人工智能领域全国特等奖。它是“揭榜挂帅”专项，不是主体赛特等奖，也不是国创赛金奖。
- **用户问题与载体**：官网指向学生学习支持、课堂互动和教师辅助，描述RAG知识检索、MCP调度及可视化教学助手等系统模块。
- **真实可确认成果**：高校官方明确报道全国获奖，并展示系统及决赛现场；公开文字没有给出可核验的学校部署数、随机对照学习增益或收益数字。
- **本项目启示（推断）**：以学习场景组织成熟技术，可以形成参赛系统。不能据简介未写新算法就断定它完全没有算法创新，更不能把“RAG也获奖”当作本项目自动有竞争力的证据。本项目不必照抄数字人或教师端。[S3西南大学官方报道](https://cis.swu.edu.cn/info/1119/5573.htm)，2025-10-27，全文可读，核验2026-11-05。

### 案例B：慧语科技——AI智能教育领航者

- **官网确认奖项**：中国国际大学生创新大赛（2024），高教主赛道本科生创意组，全国银奖。不能写成金奖。
- **用户问题与载体**：医学生缺少问诊练习机会，产品是智能虚拟病人培训，连接助学、仿真实训与考核。
- **真实可确认成果**：官网有项目说明和全国银奖表；描述了具体训练系统。其关于改善技能的陈述不是本次独立核验的教学效果，未见可据此报告的学生样本、效果量或商业收入。
- **本项目启示（推断）**：完整项目的辨识度可以来自“一个学生难以获得的练习机会”，不必来自全学科范围。规则边界学习同样可以围绕一种缺失的练习机会建立完整服务，而不是继续堆功能。[S4中国地质大学官方报道](https://voice.cug.edu.cn/info/1032/26627.htm)，2024-12-23，全文及奖项表可读，核验2026-11-05。

### 案例C：新肝宝贝，移路同行——数智化公益护航儿童肝病全周期管理

- **官网确认奖项**：上海交通大学官网在中国国际大学生创新大赛（2025）的“金奖项目介绍”中列明此项目。本轮依据该明确栏目与项目名确认，未重新读取教育部附件来确认组别，不添加组别结论。
- **用户问题与载体**：患儿及家庭需要从诊断、救助到术后管理的连续支持；载体包括慈善救助平台、云端随访与已有医疗服务。
- **真实成果的证据性质**：校方自报累计帮助4000余名中国患儿、70余名东南亚患儿完成肝移植。它是官方项目报道中的服务事实陈述，未做独立审计；尤其不能归因于软件单独带来的效果。
- **本项目启示（推断）**：项目范围应围绕一段持续用户旅程组织。单个软件模块只是载体；有明确前后环节和承接责任，才能讲清完整服务。[S5上海交通大学创业学院](https://chuangye.sjtu.edu.cn/news/8/3d36cbf967dc45f9a21c913584dcf8df)，正文事件为2025-10-13—15，页面未显示独立发布日期；相关段落及金奖栏目可读，核验2026-11-05。

这些案例不是统计样本，官网也没有披露评委逐项评分。只能说明相应获奖事实、产品形态和公开成果，不能证明它们“因不做新算法而获奖”，也不能推导本项目获奖概率。

## 3. 新方向可以成为完整项目，而非一个错题帮小插件

建议围绕这一学生承诺组织：**“不只知道这题怎样做，还能判断学到的方法在什么条件下能用，并在新题中自己用出来。”**这是产品目标，不是现有效果。持续AI伙伴的长期主线是帮助学生积累、检查和修正自己使用的方法；错题帮提供最自然的入口、过程材料和恢复能力，不决定项目价值只能停在录题工具。

现有新链条比泛称“名师策略匹配”更容易让学生感受到变化：

原作答 → 学生能确认或反驳的规则候选 → 条件对照/经数学核验的反例 → 学生修改规则及适用条件 → 在未见新题中判断并实际求解 → 之后回访再用。

不应只把最后一步做成“接受合法/拒绝非法”的判断题。学生还要能自己完成合法应用、说明关键条件，必要时修复不适用步骤；否则可能只是识别系统题型，而未形成解题能力。规则候选可以先由学生表达，模型帮助整理；系统猜测的规则要让学生纠正，不能成为新的认知标签。

**一个值得保留的数学边界：判断对象须明确。**例如，从2x=6到0=0，是两边同乘0得到的推论，但不是等价方程。不能笼统教成“这种数学操作非法”。若学生的规则候选是“两边做相同操作永远不改变解集”，可用同加1、同乘2、同乘0的对照，让学生区分保持相等与保持解集；再修订非零等条件。例子为本评委构造，不是真实学生材料或已审核任务。反例必须针对明确的命题、定义域和变形目标，不能偷换前提后宣布学生错。

完整项目不等于一次推出全K12。可以先用等式变形完成全旅程，再按同一价值扩展到不等式变号、分母非零等数学规则边界；这些是待设计的后续方向，不是首版已经支持的内容。扩展单位是“学生要学会的一类有条件方法”，不是增加家长端、虚拟课堂或几十种页面。

## 4. 一个可以支撑完整产品的学生旅程

|学生时刻|产品提供什么|学生得到的可见价值|
|---|---|---|
|今天又错了|保留原题与本人步骤，确认真正需要处理的位置|不用反复转述，能核对系统是否理解自己的作答|
|我以为规则是这样|整理一条可编辑规则，保留“只是猜测/尚不确定”|能够反驳AI，而非被动接受错因标签|
|换个条件还成立吗|少量合格对照与反例，让学生预测、说明、尝试|发现方法边界，而不只是重看原题解析|
|我重新写规则|学生修改条件与做法，必要时保留未解决处|形成自己能解释的学习记录|
|现在自己用|未见题中的合法应用、不适用辨别和实际求解|知道本次是否独立完成，不用原题复述冒充迁移|
|下次再遇到|按真实回答继续或复习，失败可重新修正规则|学习伙伴记住的是可改的证据，不是永久缺陷标签|

这些是同一学生价值链的连续环节，可利用旧产品已有能力组织；不是要求新增六套独立功能。任务应可跳过、暂停和结束，纯查阅需求也有价值。伙伴关系来自连续理解与合适行动，不靠无限聊天或数字人形象。

## 5. 可用的产品、创新与产业叙事

**产品叙事建议**：独解学伴是面向中学生的数学AI学习伙伴，从真实错题中找出学生正在使用的方法，帮助学生检验条件、修正理解，并用独立新题和之后复习检查方法能否继续使用。优先服务课后缺少及时个别指导、愿意完成短学习任务的学生。

**创新载体建议**：不是“发明规则学习理论”，而是让原步骤、可修正的规则、前提明确的对照、实际新题应用和持续复习在同一任务中相互约束。可以按产品/服务流程创新申报：学生能否纠正系统解释；例子是否确实检验相应条件；自己能否应用和拒绝不适用变形；后续回答是否推动规则修订。各环节有先例，不影响审查整个服务是否解决了具体未满足需求，但不可称世界首创。

**内容启动建议**：公开教师/专家指导中的教学原则，加上自编数学任务和独立审阅，可以形成首批材料；不用把私有名师视频设为项目必要前提。公开原则的引用、具体材料的再利用和专家为本产品背书不是同一件事。自编内容也必须检查数学正确性、适用边界和反例针对性。内容包承载的是完整学习目标，不是孤立三张策略卡。

**产业叙事建议**：使用者是学生，潜在购买者是家长；基础记录、已审核自检与查看自己的学习证据保持可达，增强价值来自更丰富的合格单元内容、适量个别帮助和连续学习支持。可比较按内容包、学期服务或限额增强的不同支付方式，均为待验证选择，不预设订阅才成立。学生学会后少用某单元是成功，长期价值来自新的真实学习需求，不靠人为增加复习。

成本和质量应一起看：内容编制、独立审阅、数学核验、维护与动态帮助共同形成可交付服务。潜在壁垒可以来自已审核的规则边界任务内容、可复用的质量流程、持续学习体验及信任；“模型调用”不是壁垒，学生数据数量也不自动是壁垒。家庭付费不可行时，可研究内容合作或定向资助，但不能提前写成已获渠道，更不能为了渠道把学生产品改成教师管理工具。

普惠价值应落在可负担的合格帮助和独立练习机会：固定审核内容可以保留低持续成本路径，动态部分透明限额；若暂停增强，保留原图、作答与学习记录。普通终端入口只降低一部分门槛，不能宣称已经覆盖无终端学生或缩小城乡差距。

## 6. 后续方案论证的重点，不设新算法门槛

1. 找准适用人群：不是所有搜题者都需要规则检验。最值得服务的是看懂原题、相似或条件变化后仍反复出错，且缺少及时个别帮助的学生。用公开领域材料与后续真实事件研究说明需求，不把整个K12人数当需求人数。
2. 区分三个基线：原有错题帮的订正与类似题；同模型高质量通用辅导；获得同样内容的检索辅导。允许它们自然做反例和渐撤，不能故意禁止来制造优势。
3. 在方案阶段先给可核对的成对轨迹：同样原作答下，哪条规则可能成立、哪种条件能改变判断、什么对照无益、何时直接结束。不是先要求大规模真人因果结果。
4. 验证价值应同时覆盖“会用”和“知边界”，并有实际求解与延后表现；只提高判断题正确率、对话长度或规则卡数量不足以支持完整学习价值。
5. 若强基线也能提供同样帮助，就比较可靠性、时间、恢复与持续记录的组合价值。即使不产生独有算法，仍可能成立更好的产品；若这些也没有净增量，再收缩。不要在没有比较理由前，预先把整个长期学生伙伴愿景降为插件。
