# C/D新构造任务的数学与教学校核

2026-11-05。仅据本次给定构造任务独立校核，不评分、不改正式稿。以下是设计检查，**不是真人教师审核、学生观察或教学效果**。

结论：C1、C2及D的主要方程和数值正确。必须精确处理两点：**C2的−2、4都不在共同背景域内，只能称候选结果冲突，不能直接当域内反例；D的全部对照答案都须保留减价后非负的下界。**

## C1：先确认变量，再判断倍数方向

原条件为甲乙共24张、甲为乙的3倍。设x为甲，则乙为24−x，正确模型是`x=3(24−x)`，得甲18、乙6。学生式`3x=24−x`得x=6，代回是甲6、乙18。

- 该数对满足共同背景：张数为非负整数、和为24，也满足学生模型；但不满足“甲为乙3倍”。因此它反驳的是**学生模型⇒原题关系**，证明学生模型纳入了不合原关系的解。不应要求它同时满足正在被反驳的倍数关系。
- 如果学生原先设x为乙，`3x=24−x`完全正确，x=6应译为乙6、甲18；不能只看相同式子就判错。应先核对原先变量意义，学生之后改定义时也须同步改写数量解释。
- 真同义建议写成完整句：“乙的张数的3倍等于甲的张数”，仍是甲18、乙6。不要省略成易读歧义的“乙张数3倍是甲”。
- 真反转：“每3张乙对应1张甲”，仍共24，实际是乙为甲3倍，故甲6、乙18；学生原式在这个新关系下恰好合法。这是条件真的改变，不是同义改写。
- 独立新题共35：“甲的张数恰为乙的4倍”得甲28、乙7；“每4张乙对应1张甲”得甲7、乙28。两题答案正确，分别覆盖关系保持与关系反转。

教学宜让学生核对“3x表示谁的数量”，或检查一个可行数对；不从一个式子直接确诊“按语序套式”。若学生已说明变量、自己修正，给一道纯题干新题即可结束。总量互补、倍数或解的含义不足时，先用数量表/数值正确例，不强求反例术语。给定6与18是教学线索，之后改对不得记作自发发现。

## C2：时点更新与倍数方向须分开修

完整表述应明确“乙原来比甲少8张”。设甲原来x张：

|数量|原来|甲给乙6张后|
|---|---|---|
|甲|x|x−6|
|乙|x−8|x−2|

共同背景域为`x为整数且x≥8`，已同时保证乙原来非负及甲有足够张数转出。原题关系是转移后乙为甲2倍，所以`2(x−6)=x−2`，得x=10。原来甲10乙2，之后甲4乙8；总张数始终12，全部条件一致。

1. **漏更新受赠数量：**`2(x−6)=x−8`确实得x=4，但乙原来为−4、甲也不能给出6张。它是“所得候选值不合背景”，不是可直接用于共同域的反例。针对这一步应先补时点表中的乙`+6`，必要时检查转移前后总量，不能只叫学生改倍数。
2. **倍数倒置：**`x−6=2(x−2)`确实得x=−2，同样不合共同域；针对它应比较“谁是谁的2倍”，不能再机械演示一次受赠更新。
3. **若要域内证明两模型不等价：**用x=10。它满足背景和原关系，却分别不满足两条错式：第一条为8≠2，第二条为4≠16。此时反驳的是**原题关系⇒学生模型**，即错模型漏掉原题的合法解。反方向不能硬写；在共同域内，两条错式都无解，学生模型⇒原题关系反而是空真。

给出x=10进行检查已经提供了原题解，必须计帮助，不能用于独立求解评分。C2含互补基础、前后时点与倍数多步要求，适合作为备选后续；首轮不应在C1尚未处理好时强制追加。一次只修最阻碍当前求解的一处，其他错误保留待处理。

## D：总额、每份量与上界

按题设将标价m视为实数金额，减价后非负，故共同域`m≥120`；四期等额，无利息、费用与取整，每期金额为`(m−120)/4`。

“每期至多300”对应`(m−120)/4≤300`，等价于`m−120≤1200`。**完整解为`120≤m≤1320`**。

学生式`4(m−120)≤300`在共同域内得到`120≤m≤195`。m=520时减后总额400、每期100，原题成立，而学生式1600≤300不成立。因此该值证明**原题⇒学生模型不成立**，即漏掉合法价格；它没有满足学生模型，不能说成“学生模型产生了520这个错误解”。该错模型在本域内其实是原允许集合的子集。

|只改变的一项条件|完整答案|教学核对|
|---|---|---|
|减后总付款至多300|`120≤m≤420`|须写清总额指减后总付款；不能只报上界而丢下界|
|每期少于300，其余不变|`120≤m<1320`|只改变严格性，m=1320时每期恰为300，可以区分“至多”和“少于”|
|新题标价p减80，五期，每期至多240|`80≤p≤1280`|减后总额为p−80，每期为(p−80)/5|
|新题改为减后总付款至多240|`80≤p≤320`|五期不再将总额上限乘5|

主要错误是总量与每份量的关系，第一教学动作可写清“4×每期额＝减后总额”，或给一个总额分四份的正确例。D没有负除数，不能把它统一送去B的负数变向解释。只有“至多/少于”实际混淆时才查端点，只有减价基数漏算时才补价格时点；不把三个知识点一次全部讲完。

m=120使减后总额为0，按目前“非负”题设可以保留；若后续题另要求实际付款为正，应重新调整下界，而不能默认沿用。反例不得使用减价后为负的价格，也不得临时加入题中没有的费用或取整条件。

## 统一教学与评价边界

把共同背景记为D、原题目标关系记为P、本人模型记为Q。检验等价时：在D内找到P真Q假可证明丢合法解；找到Q真P假可证明引入不合关系的解。只需反驳一个方向便可否定等价，**不要求反例同时满足被反驳的目标关系**；但必须满足共同域及其他未被质疑的背景条件。候选值违反D只能先记背景冲突，不当成域内反例。

日常首轮仍是一处核对、自己订正、一道未见题。先冻结自主列式/求解，之后才可选追问变量、单位、理由或对照；这些后问只作被提醒后的条件辨别。学生用合法不同方法求解应照常承认，理由未查与求解错误分列。上述开发对照不是必做题单，也不能日后当封存确认集。未确认本人信念时保留模型候选，不要求先认领系统诊断才能继续。
