# 07 学生完整旅程

版本状态见[README](README.md)。以下为目标流程，未做本轮用户测试。

1. **进入。**学生看到“处理一道错题/继续上次/到期复习”。首发初一范围说明清楚；未完成适龄/必要监护授权时只看无个人数据示例。
2. **保存材料。**拍照或手动录题，核对题干、图和本人回答。可以只交答案；信息不足时不冒充步骤诊断。
3. **确认当前困难。**显示引用原步骤和“可能需要检查什么”；学生可说“不符合”。必要时回答短辨别问题；不强迫填大量画像。
4. **接受适量帮助。**围绕当前困难得到一个动作。概念不明先解释，偶发失误先检查；学生可主动要提示/完整解析，帮助条件随回答记录。
5. **完成原题。**学生自己订正并解释一处关键变换。状态是“本题已完成/仍需核对”，不是“已掌握”。
6. **独立新题。**新题先答后看；同结构与表征变化分别呈现。求助随时可用，本次改记受助练习，之后再提供适合的独立机会，不能惩罚求助。
7. **结束或退出。**显示做到哪一步、用过什么帮助、下一项可选动作。学生可立即结束，草稿保留；不是必须把全部旅程一次完成。
8. **延迟回访。**到期后先做无提示题，区别“当时受助完成”和“现在独立表现”。未返回不是保持失败，也不是已掌握，而是未测；持续失败回到辨别或基础内容。

## 失败与恢复

OCR不确定→回原图/手动修；原材料变更→原分析不再当当前结论；答非所问/证据冲突→未知与简化提问；策略无效→切换、基础解释或结束；模型不可用→保留草稿和已核验内容、重试；数学无法核验→待核验，不给确定判分；弱网→不要求重传已有原图；新题超出先备知识→更换合格题并记录原因；无新题→说明暂无合格任务，不临时生成未核题凑数。

上述失败均可退出，不循环追问至“学生承认模型正确”。学生前台只需看到任务、依据和下一步，不能被要求理解RAG、Agent或模型参数。
