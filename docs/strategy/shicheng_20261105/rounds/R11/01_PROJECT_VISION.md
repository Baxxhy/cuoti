# 01 项目立意

**V0.11｜2026-11-05｜整体方案重整，待审。**

工作名：**师承智学——优秀教师教学经验驱动的K12个性化AI学习伙伴。**

一句话：让优质教师的判断与教法，成为学生能够持续使用的个别学习指导。以错题帮为基础，先形成完整初中数学学生体验，之后按内容和证据扩到更广K12。乡村及教育资源较弱地区是重点关注人群，不用身份替代个体需求，也不宣称人人都没有帮助。

核心链是教师经验可使用化、学生困难与历史证据、合适教学动作、互动中的调整、自主新任务、之后复习与成长。学生为核心，教师供给/审核经验，家长必要监护与可选支持；不转教师管理、备课或培训平台。

项目应解决的是合适指导及持续学习的供给问题。已有免费资源和强AI能解决很多任务；我们必须解释自己的整条服务为何更适合一类学生，而非反复增加搜题功能。专家经验不是名气、语气或一段可检索解析，要落到教法选择和调整。

初中数学是启动范围，具体题型是验证样例，不再代替项目定位。允许根据证据改内容，不以收缩到容易核验的题目争取模拟分数。长期伙伴也不等于无限聊天，完整学生过程见[立项书](13_FINAL_PROJECT_PROPOSAL.md)。

候选创新、需求与效果仍须严格审查，不称算法首创、不继承旧评分；[27](27_ORIGINAL_INTENT_AND_PRODUCT_SPINE.md)保留用户原意和纠偏依据。
