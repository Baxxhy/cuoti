# 07 完整学生旅程

V0.11。以下为产品设计，非真实使用记录。今天、学习、错题、成长围绕同一份过程，不用学生理解研究模块。

|时刻|学生看到/做什么|伙伴的教学选择|结束与恢复|
|---|---|---|---|
|今天|继续上次、该复习的一题、开始当前问题|据已有证据给一个可选择下一步；无历史不编画像|可换任务，已会不强留|
|进入学习|拍照/手动/已有任务/自主练习，核对原题和原回答|找实际卡点；明确字母意义和条件|仅查阅或已自行修正可直接结束|
|理解困难|看引用，补一句或纠正AI理解|只在能改变帮助时澄清；多个解释同动作可直接帮助|可跳过，未知不强制认领|
|得到教法|正确示范、图/表、结构对比、自我检查等合格动作|基础不足先示范，理解不同换动作；依据来自经验与本次证据|主动求助、换讲法、暂停都正常|
|自己行动|完成一小步、订正；再独立试未见任务|提示后完成与自主新题分开，不预告测哪个规则|只做当前需要的，不一次走完整研究题集|
|本次结束|本题结果与一个下一步|已会撤助；不明则保留待查，可带走短说明|结束/以后再查/自愿继续|
|回到错题|原图、原回答、订正、看过帮助和后续回答连在一起|从当时过程继续，不重建一遍认知标签|内容更正要说明，历史不改写|
|之后复习|从今天/错题到期任务先作答再看旧帮助|按新证据回基础、换法或减少帮助|缺失记未测，失败不机械多加题|
|成长|看到受助到自主的具体变化及仍待查项目|每项结论可回原记录，建议可解释|不以时长、题量或聊天量代替能力|

同一错误不承诺唯一真实原因，也不承诺最优教法。教师经验必须在不同动作及调整上让学生感受到；来源/内部模型参数不占据前台主流程。

首次无历史时先处理学生本次主动问题。自主练习从合格已学内容开始，错误进入同一学习过程；不是必须上传一道错题才允许使用伙伴。具体课程覆盖清楚说明，经验未准入时只用已具备的合格常规功能。

一轮短帮助可参考5—8分钟T，但完整学习可能跨多次，不承诺8分钟掌握。先独立提交再可选问理由；规则句不作闯关门槛。弱网/模型失败保留草稿与已存原图，不重复计算学习事件。[PRD](14_FINAL_PRD.md)、[服务责任](25_SERVICE_AND_QUALITY.md)
