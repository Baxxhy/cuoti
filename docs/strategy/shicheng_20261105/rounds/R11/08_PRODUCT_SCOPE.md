# 08 产品范围与阶段

V0.11。完整产品链先确立，初中数学作为内容启动域。具体题型不等于整个项目。

|阶段|产品与内容范围|扩展依据|
|---|---|---|
|P0|今天、学习、错题、成长四入口共用同一过程；教师决策内容/适用与调整、本人证据、自主新题和继续；必要监护及内部审阅|可审阅的小范围初中数学内容、完整旅程与强替代比较；未准入内容不冒充覆盖|
|P1|更多经审阅数学单元、策略跨情境评价和持续体验、可选择分享的周期说明|独立内容质量、适用边界、负担/成本和学生结果|
|P2|更多数学学段、之后其他学科与内容共建|课程/适龄/许可/策略及学习证据重新成立|

P0不是全初中全题型发布承诺，也不是永久只做两包。首批内容按可获来源、教学动作覆盖和真实问题选取；数量关系、等式、不等式等案例用于检查同教法不同适用情境。旧A/B和探索C/D全部保留为研究样例，不凭更换题型建立新定位。

保留并复用原图/OCR、步骤证据、任务规划/恢复、补救练习/数学核验、独立回答/帮助记录、记忆/复习/报告。旧考试/组卷/批量导出不当新主导航，保留已有工作。新增重点是经验决策及其使用，不重做工程。

删除新增数字人、虚拟课堂、人格画像、家长排名、完整教师班管/备课/培训和全学科资源仓库。首轮短任务可结束、暂停、换法或以后继续，不能把整份研究测验当日常闯关清单。
