# 内容供给事实补证：人工制作、审核与返工

2026-11-05。不评分。已读当前09、10、22、25及CONT_AI；未改正式文件、未读程序源文件、未运行模型、未注册/付费/联络。重点核验指定两篇论文，另加两篇原始研究；四篇均围绕OATutor生态，**不是四次独立团队复制**。

## 可改变现有判断的结论

“公开指导＋人工补充提示＋编辑审核＋有限发布和修订”已有真实生产先例，不必继续只用抽象可行性表述。也有可引用的作者培训、单题制作、候选提示淘汰与发布前适配数据。

但这些材料仍不能把25里的C、M、f、d换成本项目实测值。论文的单位分别是**题目连同帮助、候选提示、提示路径的呈现修订、按课提示词**，并不是本项目完整规则边界包；部分时间是问卷回忆，部分是作者报告，没有中国中文包的统一成本报价。

## 四项原始研究的具体发现

### 1. OATutor，CHI 2023：真实人工生产规模及自报工时

[正式论文，2023-04-19](https://doi.org/10.1145/3544548.3581574)；出版社直开403，读取[作者上传的论文全文](https://www.researchgate.net/publication/370180305_OATutor_An_Open-source_Adaptive_Tutoring_System_and_Curated_Content_Library_for_Learning_Sciences_Research)，不是读其引用者摘要。证据位置：§4、§4.2—4.3、作者调查结果段。

- College Algebra制作先后16名创作者、5名编辑，典型同时活跃约5人与2人；创作者平均承诺每周4小时，整书约6个月完成。这是项目回顾，不是逐人实付工时账。
- **15份时间回答**：培训均值2.27小时（SD1.10）；单题制作11.03分钟（SD9.11），为按小时/分钟估计的回忆问卷，非计时实验。新人先做5道样题。
- 单题工作包含从OER整理题目及编写提示/脚手架，不能改称原创编题或完整双向规则包的验收时间。编辑审查和纠错另有角色，未给完整逐项审核成本。

可用结论：培养有学科经验的内容作者、由编辑把关，确实能产出教材级题目帮助库；不能推算“我方每包11分钟”，也不能将研究学徒/学分激励视为免费且随时可获得的劳动力。

### 2. PLOS ONE 2024：人工筛查有计时，退稿不能当返工完成

[出版社全文，2024-05-24](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0304013)；指定[PMC入口](https://pmc.ncbi.nlm.nih.gov/articles/PMC11125466/)遇验证页，改读出版社原文。位置：“Human tutor-authored hints”“Quality checks”及RQ1结果。

- 原有人写提示由有数学辅导经验的本科生制作、编辑检查；**其编辑审核时间明确未报告**。
- AI候选由第二作者按答案、推导、语言三项筛查，平均每条**37.60秒**。75题中平均24题的提示不合格（32%），主要为答案和过程错误。
- 不合格则淘汰对应题；某目标剩不足8题就换目标重来。这不是把错误提示逐条修好。自一致性另外生成10份回应、由6名内容成员评价，不能当零人工自动通过。

可用结论：筛查时间与淘汰损耗有直接先例；37.6秒不是本项目独立数学/教学双审工时。文中8美元、10—20分钟是学习者实验报酬与会话预期，不是作者工资或制作时间。学习结果的无显著组间差异也不等于证明任意AI内容等效。

### 3. OATutor内容生态，ITB 2023：更具体的内容与编辑单位

[原始工作坊论文，2023-07-03，10页PDF](https://ceur-ws.org/Vol-3444/itb23_s2p2.pdf)。位置：§3.2—3.4。作者参与同一项目，属于生产过程补充报告。

- 题目、步骤、提示和脚手架分别制作；教材学习目标下通常15—30题，每题带团队编制的帮助，并保留源题映射。
- 创作者与较资深编辑分工，编辑在发布前修改并反馈。流程后来让双方在可预览的材料上直接协作，减少格式问题反馈延迟。
- 报告了覆盖三本代数教材及长期运行经历，**未给可核算的审阅分钟、错误返工率或货币成本**。不能用课本数量除项目年数得到个人日产量，更不能把课程试用学期当人工制作工时。

可用结论：先定义学习目标，再以带帮助的具体任务为生产单元，比只报“做了多少策略卡”更有依据；供给组织可借鉴，产能不可照搬。

### 4. PromptHive，2024原作者预印本：生成后仍有显著适配劳动

[固定v1全文，2024-10-21](https://arxiv.org/html/2410.16547v1)。按预印本读取，不将模板中的2025会议行当已独立核实的录用。位置：§4.2—4.3、§5.2、§6.4及结论。

- 10名有OATutor制作经验者参与，协作产生59课级提示词；这是提示词覆盖，不等于59课内容已逐题验收。
- 学习研究取80题的帮助路径；每题生成30份后选代表回应，之后仍作渲染兼容性修改。两作者分别报告**3小时15分、6小时19分**；作者结论称约40%人工时间用于这类语法修正。
- 这些不是完整数学/教学双审计时，不按不明分工强算单题审核速度；也不能与全书提示词的制作时间混用分母。研究中的150美元是专家参与研究补偿，不是内容包报价。

可用结论：批量生成确能进入有专家控制的制作过程，但“生成完成”与“可交付学生”之间有真实劳动；不能从省时直接推出教学有效、无需审阅或本项目成本下降同样倍数。

## 工时口径必须分开的四组量

|量|本次找到的事实|不应替换成什么|
|---|---|---|
|作者上手/单题制作|CHI作者回忆的培训与题目帮助制作时间|完整规则包的总审核时间或本团队承诺|
|质量筛查/损耗|PLOS候选提示筛查、拒绝和换目标|修改完成率、双审通过率或本模型错误率|
|交付前适配|PromptHive报告的呈现/格式修订时间|教学审阅、整本教材验收或模型推理时间|
|学习者会话/试验报酬|学习者完成测试与练习的时间、报酬|内容作者工资、课堂以外的运营成本|

本次没有找到四篇中可直接复用的“合格中文规则包单价”或长期维护工时分布。历史ITS每教学小时需200—300小时等数字多为转引、且混入建模/系统开发，不作为本项目预算锚点。

## 对生产单位和流程的实质建议

以下是据上述事实提出的本项目建议，不是已执行结果，也不增加学生端功能。

1. **包内以可发布任务簇计产。**保留“规则边界包”作为教学目标，但拆出原题与原域、正确示范/条件对照、每条提示路径、实际新题及合法/不适用覆盖、答案和呈现验收。一个包里若只有文字规则而无合格任务，不算产量。把“候选数、退稿数、修复后复审数、最终合格数”分开，避免把生成数量算供给。
2. **已有双审之外，显式核对学生实际看到的内容。**在数学与教学审阅后检查负号/括号/分数显示、题干条件是否齐、是否容纳多种合法答案、提示是否提前泄露独立题所测条件。格式正确不能替代数学正确，数学正确也不能替代输入/呈现能用。无需为此新建教师平台，可用当前内容文稿和预览清单组织。
3. **将作者上手和退稿劳动纳入C。**区分一次培训/样题校准、逐任务制作、数学审核、教学审核、呈现修订、返工复审及版本维护。PLOS说明退掉的候选也消耗时间；不能只按最终通过题平均掉未通过成本。已有25的T表保留，新增来源只作外部参照，不把11.03分钟、37.6秒或两作者工时直接填成我方参数。
4. **若使用AI，只作有界候选供给。**先有人工确认的目标、域、答案与覆盖；可让AI协助提示措辞，但批量结果仍经同一验收。相似回应多数票或向量代表性不证明条件正确。若质量不够，缩小/退回固定自编材料，而非因“已有自一致性”跳过审核。
5. **有限维护落实到受影响内容簇。**修改一条规则条件时，复核关联示范、提示、两类任务和历史说明；区分数学错误、教学适配、文字/显示问题，计实际处理与复审。这样复用的是合格内容版本，不是只复用一段未再次核对的提示词。

## 公开材料的复用与许可边界

[OATutor内容README](https://github.com/CAHLR/OATutor-Content)当前写内容CC BY 4.0，题目/提示/脚手架逐项记录作者组织和许可，并说明团队整理与反馈修正；这使其成为**可以逐项核权的候选**，不是质量担保。此次只读README、未检查每个内容条目或上游版本，不能宣布整库已适合收费中文产品。

CHI论文自身的CC BY-NC-ND与内容README的CC BY是不同对象；PLOS文章CC BY也不自动确认所有外链教材当前许可。PromptHive v1论文页为CC BY-SA 4.0，不能据此假定它引用的教材或生成文件具有相同条款。OpenStax当前与历史版本的限制已在CONT_AI分开，本次不再把2023的开放描述当2026整书的授权。实际采用要固定来源/版本、逐条归属及改编说明，并重新检查中文教学条件与所有答案。

## 可直接用于改写供给论证的边界句

公开研究已报告以受训学科作者、编辑审核和有限教材帮助库组织供给；作者制作、候选筛查及发布前修订存在可查的人力数据。该先例支持本项目采用小范围预审复用流程，并提示必须计入上手、退稿与呈现返工。**它不证明本项目两包已经通过审核，不提供本地报价，也不证明AI辅助内容在中国初中具有同等教学效果。**
