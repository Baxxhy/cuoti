# 08 产品范围与阶段

V0.13。完整产品链先确立，初中数学作为内容启动域。具体题型不等于整个项目。

|阶段|产品与内容范围|扩展依据|
|---|---|---|
|P0|今天、学习、错题、成长四入口共用同一过程；教师决策内容/适用与调整、本人证据、自主新题和继续；必要监护及内部审阅|可审阅的小范围初中数学内容、完整旅程与强替代比较；未准入内容不冒充覆盖|
|P1|更多经审阅数学单元、策略跨情境评价和持续体验、可选择分享的周期说明|独立内容质量、适用边界、负担/成本和学生结果|
|P2|更多数学学段、之后其他学科与内容共建|课程/适龄/许可/策略及学习证据重新成立|

P0不是全初中全题型发布承诺，也不是永久只做两包。首批内容按可获来源、教学动作覆盖和真实问题选取；数量关系、等式、不等式等案例用于检查同教法不同适用情境。旧A/B和探索C/D全部保留为研究样例，不凭更换题型建立新定位。

## 首版完整能力图T

下表区分现有资产、计划新增和未覆盖时的可用路径，不是上线清单；旧能力仅据产品资料，新增经验支持当前没有真人审阅通过项。

|入口|复用的常规资产|首版新增的经验驱动能力|未覆盖或失败时|
|---|---|---|---|
|今天|任务、学习记录与恢复|根据实际记录选一个可更换的下一步，处理未完/复习/当前问题冲突|无证据就从本人主动问题开始；学生改选不丢旧任务|
|学习|原图/OCR、原作答、证据、讲解/练习和数学核验|在已审初中数学单元中，使用基础示范、先备搭桥、关系对照、局部自查/撤助等动作与回应分支|先说明该题未获经验适配支持，使用合格常规帮助；核不清则待查，不冒称同等个性化|
|错题|原图、订正、回答、复习与继续|保留当次教法和帮助条件，当前回应冲突时换路，而非照读旧解析|记录可查；旧教法不可用时不自动重放，提供合格固定材料或待查|
|成长|学习记忆与报告|分列受助、自主、延后与未测，解释建议为什么变；教法依据可选查看|只展示有依据的记录，不估算未覆盖学科或永久能力|

首批内容目标按课程组织为“等式性质与一元一次方程基础”，包括对应的先备核对、例解、易混关系、独立新任务与复习；这是待审内容目标，不是已经覆盖的声明。上述四类教学动作不要求在每个知识点硬凑齐，不适用就不用。不等式、数量关系等作为待准入扩展与压力样例，不凭本轮示例直接上线。产品的完整性来自四入口连通和持续帮助，覆盖广度随审阅扩展；两者不能相互冒充。

保留并复用原图/OCR、步骤证据、任务规划/恢复、补救练习/数学核验、独立回答/帮助记录、记忆/复习/报告。旧考试/组卷/批量导出不当新主导航，保留已有工作。新增重点是经验决策及其使用，不重做工程。

删除新增数字人、虚拟课堂、人格画像、家长排名、完整教师班管/备课/培训和全学科资源仓库。首轮短任务可结束、暂停、换法或以后继续，不能把整份研究测验当日常闯关清单。
