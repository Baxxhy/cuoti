# 管理员只读工作台学生端同源改版设计

## 目标

将现有深色工业监控台改为与学生端一致的蓝白学习产品界面。管理员仍能在电脑端查看全局数据、学生画像、智能体轨迹、认知更新和系统状态，但不再面对黑底、小字体和大量无意义英文标识。

本次只修改管理员工作台前端表现，不改变学生端页面，不新增写接口，不调整现有管理员数据接口。

## 视觉方向

采用 Swiss 方向：白色与中性浅灰表面、单一蓝色强调、中文无衬线字体、清晰的信息网格。为了保持产品一致性，直接复用学生端现有令牌：

- 主色：`#2E69FC`
- 页面背景：`#F7F8FA`
- 卡片背景：`#FFFFFF`
- 主文字：`#101828`
- 次文字：`#667085`
- 边框：`#E4E7EC`
- 成功、提醒、错误颜色继续使用学生端现有语义色
- 字体：系统字体、苹方和微软雅黑
- 卡片圆角、按钮、标签、进度条与学生端保持一致

页面不使用纯黑背景、等宽字体、发光效果、装饰性英文大写标签或小于 12px 的正文。

## 核心差异化设计

首页设置一张“学习闭环”可视图，将真实业务数据按“错题录入 → 错因诊断 → 自适应教学 → 认知更新 → 主动复习”串联起来。每个节点显示对应真实数量，帮助比赛展示时直观看出这不是普通数据后台，而是智能体驱动的完整学习闭环。

## 页面结构

### 整体框架

- 左侧白色导航栏：产品标识、全局概览、学生画像、智能体轨迹、系统状态、刷新与退出。
- 右侧浅灰内容区：页面标题、更新时间、只读状态和当前模块内容。
- 桌面宽度优先；窄屏时导航收缩，内容保持可滚动，不改变学生端移动页面。

### 全局概览

- 六张大数字卡片：学生数、错题数、诊断数、进行中会话数、智能体执行数、待复习数。
- 学习闭环图：五个带 `uni-icons` 图标的步骤节点和真实数据。
- 会话状态环形图：进行中与已结束会话占比。
- 最近学生列表和最近教学会话列表。
- 所有空状态显示明确中文说明，不填充虚构数据。

### 学生画像

- 左侧学生列表使用头像色块、姓名、年级、错题数量。
- 右侧显示学生基本信息与错题、会话、待复习三项统计。
- 知识掌握使用大字号横向进度条。
- 高频误区使用概率条和语义颜色，不再使用难辨认的小数字方块。
- 复习计划以时间和状态列表呈现。

### 智能体轨迹

- 左侧为会话列表，右侧为当前会话详情。
- 顶部使用四张摘要卡展示学生、题目、教学阶段和掌握估计。
- 诊断上下文采用浅蓝信息卡。
- 轨迹使用纵向步骤卡，每一步清晰展示：观察依据、教学决策、目标、调用能力和结果摘要。
- 右侧或底部显示认知更新，将旧值和新值用进度变化条表达。
- 仅展示可解释业务摘要，不展示模型思维链、系统提示词或凭据。

### 系统状态

- 使用白色状态卡展示数据库、逻辑模型、文本线路、视觉线路和语音状态。
- 使用图标和中文状态，不展示内部轮询位置、凭据数量或管理操作。
- 保留“只读访问”说明。

## 图表实现

图表只消费现有管理员接口数据：

- 学习闭环：CSS 网格、连接线和 `uni-icons`。
- 会话状态环形图：CSS `conic-gradient`，无数据时显示空环。
- 掌握度与误区：CSS 进度条。
- 认知变化：旧值、新值双层进度条和变化标识。

不引入新的图表库，不执行模型生成的 JavaScript，不伪造时间序列。现有接口没有真实历史序列时，不展示虚假的折线图。

## 数据与交互

- 页面加载调用 `GET /admin/workbench`。
- 点击学生调用 `GET /admin/students/{student_id}`。
- 点击会话调用 `GET /admin/sessions/{session_id}`。
- 每 15 秒刷新概览数据；学生和会话详情按选择加载。
- 所有操作保持查询性质，没有新增、修改、删除和探测按钮。
- 加载失败保留当前已加载数据，并显示可重试提示。

## 测试与验收

- 更新前端静态测试，断言页面复用学生端关键视觉令牌和中文功能标题。
- 断言管理员页面只导入并调用 `getData`，不调用任何写请求。
- 运行全部前端测试和 H5 构建。
- 运行后端测试，确认本次纯前端改版没有影响管理员接口。
- 浏览器验收重点：背景明亮、字号清晰、图表使用真实数据、与学生端属于同一视觉体系。

## 范围边界

- 不修改学生端。
- 不扩展管理员权限。
- 不新增数据库表或后端写接口。
- 不制作虚构排行榜、虚构性能指标或伪造学习趋势。
