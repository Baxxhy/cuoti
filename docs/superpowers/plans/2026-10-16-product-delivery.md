## 产品边界与差距

现有能力包含录入/框选/OCR校对、诊断与纠正、教学活动/追问、知识关联、真实题库练习、变式、到期复习/历史、学情/图谱、组卷/导出、教师任务、账户和多角色后台。主要差距是入口分散、学习Tab直接等于复习、搜索与错题重复、详情与教学提示答案的时机不明确、跨模块没有携带选题条件。不能通过删除成熟功能解决这些问题。

最终组织：今日（行动调度）、错题（题目资产）、学习（按学习目标选择方式）、我的（账户与使用帮助）。录入是独立全局动作。保留详细诊断、知识、图谱和组卷，但通过本题或明确分类进入；保持旧URL兼容。

| 分类 | 包含功能 | 明确不承担什么 / 数据来源 |
| --- | --- | --- |
| 今日 | 继续上次、到期复习、教师任务、录入 | 不复制完整工具目录、不自行算掌握；dashboard |
| 错题 | 学科/关键词/处理状态/收藏/到期筛选，按知识点或错因分组，组卷衔接 | 分组只是查看方式，不能批量宣布学会；questions |
| 本题学习 | 原图、原作答、诊断纠正、知识、教学、针对练习、学习证据 | 不改写原始作答冒充订正；questions/journey/tutor/practice |
| 复习巩固 | 到期独立作答、反馈、复习历史 | 打开/打印/自评不能代替判题；reviews |
| 专项与备考 | 选错题、收藏重点、按学科/知识点组卷、空白题/解析/数据导出 | 不生成假题库或预测分数；papers |
| 知识与学情 | 可检索知识卡、前置关系、相关错题、学习报告、知识图谱 | 知识卡浏览不更新掌握；knowledge/analytics |
| 我的 | 用户资料、产品用法、返回所属角色工作台、退出 | 不再另设第二套学习目录；auth/profile |
| AI/系统内部 | OCR、校验、选题、教学阶段、复习调度 | 继续使用现有Provider/Qwen/Pydantic/SymPy；不在前端执行生成代码 |

## 最终落地的验收边界

当前交付目标是已有 Python + MySQL 主线的本地单用户学习应用；教师/家长/管理员已有能力继续保留，不将本轮扩大成新的商业平台。仓颉替代后端仍按独立迁移计划推进，本轮只同步知识筛选规则，不宣称迁移完成。

- 功能可用：录入—核对—诊断—学习—独立练习—复习—档案有现成路径；本轮补齐分类、查找、整理与跨页上下文。
- 数据可信：收藏落数据库；页面只存筛选偏好；分组、阅读、打印均不写入掌握证据；原始图与原作答保留。
- 工程可运行：单元、类型、构建、真实 MySQL/HTTP、手机和桌面浏览器验收通过。本轮不以模拟模型反馈证明真实 AI 教学正确率。
- 教学质量验收：正式面向学生使用前，需用覆盖各学科、年级、题型与模糊图片的固定样本集复核 OCR、首错诊断和判题，并记录人工复核结果；已有真实 AI 验证入口可复用。本轮未开展真实学生试用或新增付费模型压测，不能据此承诺学习效果。
- 算法增强：局部订正、条件对照题、自适应同错因任务、自检笔记与整卷识别属于后续增量，分别需要数据模型、接口、判定规则和独立验收；不作为当前入口重构已完成的功能计数。
