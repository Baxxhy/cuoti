# 错题帮：功能与技术说明

更新日期：2026 年 10 月 20 日

错题帮是一款面向初高中学生的 AI 错题学习应用，围绕“录入错题 → 找到错因 → 订正重做 → 练习巩固 → 后续复习”组织功能，当前以本地部署使用为主。

## 现在有什么功能

| 功能 | 可以做什么 |
| --- | --- |
| 错题录入与管理 | 拍照或上传图片、裁剪、识别题目和学生作答，核对后保存；支持手动录入、搜索和筛选错题，保留原始图片。 |
| 错题分析与 AI 讲解 | 查看原答案、参考答案和解题步骤；分析错误原因、回看出错步骤，针对不懂的地方继续提问。 |
| 订正与重新作答 | 按步骤订正、请求提示、重新答题，保存学习过程，中断后可以继续。 |
| 练习与模拟考试 | 题库练习、类似题与变式练习、自适应选题；支持限时抽题考试、交卷判题和结果查看。 |
| 复习与学习分析 | 查看待复习错题、学习记录、个人易错地图和学习报告；设置学习学科、目标和练习量。 |
| 知识学习与资料导出 | 查看知识卡、公式、例题与相关知识；组卷并导出试卷、答案等资料。 |
| 多角色使用 | 学生完成学习和作业；教师管理班级、布置与批改作业；家长在授权后查看学习情况；管理员查看运行信息。 |

## 用了什么框架和技术

| 部分 | 使用的技术 | 主要作用 |
| --- | --- | --- |
| 前端 | uni-app、Vue 3、TypeScript | 实现页面和交互，支持 H5 和 App 资源构建。 |
| 界面与状态 | uni-ui、Pinia、Sass、KaTeX | 提供界面组件、管理页面状态、统一样式和显示数学公式。 |
| 前端构建 | Vite | 开发预览与资源打包。 |
| 业务后端 | 仓颉（Cangjie） | 处理账号权限、错题、作答、学习任务与数据库事务。 |
| 算法服务 | Python、FastAPI、Pydantic | 提供内部算法接口，并校验模型返回的结构化数据。 |
| 学习流程编排 | LangGraph | 用一个状态图串联诊断、作答核验、掌握状态计算和下一步推荐，复用已有任务恢复。 |
| 业务数据库 | MySQL | 保存题目、学生作答、学习记录、任务和权限等业务数据。 |
| 大模型 | Qwen、ApiPoolProvider | 提供题目识别、错因分析和互动讲解；模型请求统一经过接口池。 |
| 知识检索 | BGE、Qdrant、RRF 融合与重排 | 从已有题目和知识资料中寻找相关内容，辅助讲解与练习。 |
| 数学核验 | SymPy | 在支持的题型内核验数学表达式和等价答案。 |
| 自动化测试 | Vitest、Playwright、pytest | 检查前端逻辑、真实浏览器操作和算法服务。 |

整体调用关系：**前端 → 仓颉业务后端 → MySQL / Python 算法服务 → 模型与检索工具**。Python 负责内部计算，仓颉负责主线业务和数据保存；旧 Python 业务版保留为兼容入口。

## 核心智能能力

- **检索增强生成（RAG）**：先检索相关资料，再交给模型辅助讲解，减少脱离题目和知识来源的回答。
- **先修知识图谱**：沿知识点关系寻找需要先掌握的内容；讲解中可以展开“参考知识”查看原知识卡。
- **可恢复的学习任务**：把订正、重新作答和巩固组织成连续过程，结合历史记录提供提示，保存进度并支持中断恢复。
- **ECED 错因诊断**：对照学生实际步骤、参考资料和规则核验定位错误；证据不足时先请学生核对。
- **AEMT 掌握追踪**：区分独立完成、使用提示和看过答案，避免把辅助完成直接记为已掌握。
- **ARPP 学习规划**：结合错因、薄弱知识、到期复习和学习量安排下一步，并提供实际可打开的题目。
- **贝叶斯知识追踪与信息增益选题**：根据已提交的作答估计薄弱知识，综合练习价值、重复程度和多样性选题。
- **结构化输出与数学核验**：模型结果先经过格式校验；支持的数学题再结合规则与 SymPy 检查。互动图示使用结构化描述，前端不执行模型生成的代码。

## 当前使用范围

截至本次题库核查，共有 1430 道可练题，语文和英语尚未覆盖，题型以选择题为主，仍不足以支撑初一至高三全科、完整教材章节的长期练习。模拟考试目前是题库抽题卷。

自适应选题使用冷启动默认参数，尚未训练个人专属模型；AI 讲解仍需要核对。当前已验证 H5 和 App 本地资源构建，尚不等于完成手机签名安装包交付。
