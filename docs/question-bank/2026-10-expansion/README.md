## 数据处理

- 保留原文、参考答案、解析、来源编号和原始图片，重导沿用同一题目 ID。
- RACE 按小题拆分，同时保留文章与小题序号；高考多小题综合题保持原始答案顺序，不转换成多选题。
- 小学题如实标记小学；TAL 无法从原始来源确定学段时标记拓展，不猜测年级。
- 同源题干、选项和答案完全相同的重复题保留入库记录，但不重复进入练习。跨源语义近重复尚未全量人工核对。
- 恢复有完整 B/C/D 且首段非空的缺失 A 标记，兼容 `B .` 等空格格式；单选项、未解析选项和“请在答题卡作答”占位答案不允许自动判分。
- 通过实际前端公式渲染器检查全部题目。缺图、缺答案、公式待核对、主观评分和重复题不进入自动判分题池。上游有答案不等于内容已经教师审校。
- 新题直接用于题库列表、关键词搜索、单题练习、随机组卷和自适应候选抽样。已有 BGE 向量索引不等于本次全量导入；本轮不把未向量化的新题宣称为已覆盖语义相似题检索。
- 批次事务支持失败重试；不改变用户错题、历史作答和原始上传图片。

## 复现

```bash
.venv/bin/python scripts/fetch_public_question_sources.py
# 使用 .env.cangjie 指向现有独立 MySQL；不要初始化或清空库。
bash scripts/question_bank_cangjie.sh --source all --include-primary --skip-index
```

`--include-primary` 保留全部原始学段。不指定时 CMM 两种适配器保持原有仅初高中行为。正式练习仅读取通过准入的行。

现有部署的 MySQL 缓存从 128 MiB 调整为 1 GiB，并通过 `SET PERSIST` 保留配置，未修改持久化刷盘安全等级。初次并发导入与回归发生提交超时，后续改为串行写入、每批最多 500 条，并复用已编译的原生库，避免每批重复编译。已有批次可重复执行，不能将中断日志算作全量完成。
