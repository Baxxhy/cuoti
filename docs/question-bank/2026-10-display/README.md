# 题库图片与表格显示修复（2026-10-21）

用户截图中的 `<ImageHere>` 来自 CMM-Math 的图片位置标记。原来题库把所有图片都当作题图，既会留下占位文字，也会把参考答案、解析的配图提前显示。

## 修复范围

- 题库列表去掉图片标记和尾部空行，缩略图数量只统计题干与选项图。
- 单题练习、模拟考试、答题结果和针对错题推荐的练习共用题目内容组件：按原文位置显示图片，保留图片前后的条件和数学公式；图片选项可点击作答。
- 仓颉按题干、选项、答案、解析的标记顺序分配原始图片索引。答案图和解析图只在提交后的结果接口返回。图片路径、图片文件和原始索引不改写。
- 图片缺失明确显示提示；加载失败可重新加载；题图与结果配图可放大查看。作答中的选项图点击用于选择答案。
- 题目中的 Markdown 数据表、单列表和换行标记正常显示，公式与普通 HTML 转义继续有效。连续坐标在完整坐标之间换行，宽表与其他长公式在内容区域内横向滚动。
- 新导入数据检查图片数量及位置标记是否一致。旧会话和推荐候选同样检查图片关联，异常题目不再被选入练习；未交卷会话提交时排除异常题目计分。

## 现有数据处理

只读检查当前 MySQL 中全部 9,763 条带图或图片标记的记录，确认图片文件存在。152 条记录的标记与图片数量不一致或缺少标记。其中原本可练习的 87 条通过仓颉原生核验命令暂时移出练习，其余原本就未准入。

每条变更以内容指纹校验，保留全部原始题目、选项、答案、解析、图片路径及内容指纹。未删除题目或学生学习记录。截图原题 `CMM-Math/894` 原先显示“2 张题图”，实际上是一张题图、一张答案图；现在答题前只返回题图。
