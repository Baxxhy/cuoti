# 导航与命名

顶层保留今日、错题、录入、学习、我的。录入是动作入口，提供相机/相册与手动录入。今日只突出一个已有任务，其余入口位于后面，避免重复同一任务。

二级页统一返回按钮；深链接无历史时回所属区域。作答、框选、诊断和图解不展示全局底栏。错题详情保留题目与错因、解析与练习、学习记录三个分区；讲解与订正使用不同标题。订正返回原题复用已有历史，防止栈增长。

同一入口统一叫类似题练习、知识卡片、错题组卷、学习安排、学习报告、作答记录。查看答案只展开参考答案；提交作答只执行原有提交接口；查看提示携带草稿但不自动提交。

教师、家长、管理员权限和路由保持业务边界；不得通过学生入口显示内部工具轨迹。现有search路由保留兼容重定向，实际搜索在错题本完成。
