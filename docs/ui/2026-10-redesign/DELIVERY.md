# 错题帮全站重构交付记录

2026-10-20。本轮基于当前代码完成48个注册路由的产品重构，保留学生、教师、家长和管理端能力。当前本地入口为 http://127.0.0.1:5175 。

## 实际改动

- 今日页集中展示一项优先任务，题库、模拟考试与易错地图改为紧凑入口；无错题时可直接录入或查知识卡片。
- 详情按“题目与错因／解析与练习／学习记录”组织，原始答案与订正分开保存，配图直接呈现，参考答案按需展开。
- 订正页突出题目、作答区和提交按钮；提示、拍照与图解下沉，保留草稿恢复、版本校验与等价答案判题。
- 全站统一字号、品牌蓝、灰白背景、按钮、图标、间距和反馈。逐页整理录入、错题本、学习、复习、题库、考试、知识、组卷、分析、个人中心及其他角色工作台；具体路由和数据关系见[页面清单](pages.csv)与[内容关系](CONTENT_MODEL.md)。
- 中文文案扫描覆盖78个前端文件、1845行相关源代码；统一“错题订正、提交作答、查看提示、类似题练习、学习安排、作答记录”，清理重复说明和内部状态名称。
- 浏览器验收额外发现并修复：原生按钮样式覆盖、图标读屏污染、教师选项裁切、公式原样显示、手动题误报缺图、题目附图未直接显示、讲解重复标题。
- 真实追问揭示文字题讲解未调用模型，已补齐通过ApiPoolProvider的结构化Qwen讲解。带图题继续使用多模态分支，模型不可用时保留回退。查看答案保留确定性参考结果，重复查看也不会被通用提示替代。

### 当前应用的真实Qwen检查

以下使用当前配置池、当前仓颉服务与MySQL，没有模型替身或浏览器接口拦截。是固定样本工程核验，没有真人学生参与。

1. `2x+1=2`、原答`x=2`：参考答案为`x=1/2`，规则验证通过，诊断定位第2步，原答案保留。
2. 浏览器先后提交`x=0.5`和`x=1/2`，刷新恢复草稿；后端学习记录中`original_independent=true`。
3. 学生追问为什么从`2x=1`需要除以2，真实讲解解释等式两边同时除以2、得到`1/2`；回复显示并保存到会话。此前返回通用提示的问题已复现、修复和重测；另经当前真实服务连续两次请求参考答案，均保留`x=1/2`并持久化，见[重复查看答案核验](evidence/live-repeat-answer.json)。
4. 合成印刷题图经真实框选、Qwen OCR进入确认题目页，题干、错误答案和两步作答可见。上传原件下载后逐字节一致。这不是实际手写照片识别准确率评测。

研究来源、技能取舍、失败修正与测试层次见[工作记录](WORKLOG.md)；最终对照见[验收清单](ACCEPTANCE.md)。本轮不把固定样本扩张为跨学科正确率或学习效果结论。
