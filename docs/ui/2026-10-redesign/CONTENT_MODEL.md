# 内容与数据关系

错题保存原图、框选图、识别题干、结构化选项、原答案与步骤；后续订正不覆盖原始作答。analysis提供参考答案、参考过程和知识点；diagnosis结合原步骤与证据说明错因。详情、诊断、按ID回放、学习安排、题目档案共享同一question_id。

持久学习任务以question_id、input_fingerprint、step_id和version约束提交，request_id负责重试幂等。草稿按用户/任务/来源/步号隔离。任务阶段从局部订正到原题重做再到变式，只有有效独立作答才更新学习状态；查看解析或提示不冒充完成。

题库练习与模拟考试使用study-session，自动保存答案、恢复当前题、提交后展示判题与解析。类似题练习从原错题知识点匹配。到期复习按plan_id提交和评价；易错地图按真实错因分组，链接原题及其复习安排。组卷保存选题顺序、题目编辑与导出文件。

所有业务数据与权限由仓颉/MySQL提供；算法仅计算，模型请求走ApiPoolProvider与Qwen。测试替身、演示种子与真实模型结果必须分开记录。
