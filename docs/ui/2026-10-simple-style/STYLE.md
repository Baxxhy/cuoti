# 简洁界面规范

更新：2026-10-20。依据本轮用户对登录页、聚焦边框与其余页面的连续反馈，沿用 ui-ux-pro-max 的视觉层级、可见标签、触控热区与响应式检查方法。

- **品牌与导航分开**：登录页突出“错题帮”，不附宣传副标题。其余页面采用紧凑顶部导航标题，17px、常规至中等字重、居中；避免左上角大号黑体。页面动作说明放到操作附近，不写成长标题。
- **单层输入边界**：输入框、文本域和选择框保留一层边框。聚焦采用品牌蓝，不再叠加外围 outline 或光晕；保留按钮及其他键盘控件的可见聚焦提示。
- **稳定的品牌蓝**：蓝色用于主操作、当前选择、导航状态和输入光标。错误、成功、待核验仍使用相应语义色和文字；裁剪操作使用品牌蓝，避免把橙色当成通用交互颜色。
- **减少装饰框线**：去掉卡片顶部或侧面的彩色条、厚重分隔及重复套框。白色分组和 12px 圆角用于组织有关系的内容；空状态直接展示内容和入口。
- **状态有意义**：订正、推荐、答案对照等通过标题、文字和必要的浅色背景区分，不依赖一根彩色竖线。时间线、表格、图形和答案对照需要的细分隔线保留。
- **可操作优先**：输入字号通常为 16px，主按钮和返回热区保持可触达；长题目、数学公式、大字体和窄屏按实际内容换行，不裁剪关键信息。
- **功能与数据不变**：本轮修改导航呈现、样式和少量冗长标题，保留原接口、判题、持久化、权限与数据关系。

代码主要入口：共享页头、导航、答题输入组件与全局样式；注册、修改密码、首页、错题列表、录入、诊断、订正、学习安排、练习、知识、地图、个人页、教师及管理页另做局部调整。

全站验收依据实际 `frontend/src/pages.json` 的路由清单。通过手机 / 桌面真实渲染核对标题大小、居中位置、单层聚焦、横向溢出与运行异常；完整结果见 [交付记录](DELIVERY.md)。
