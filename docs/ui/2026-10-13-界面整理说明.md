# 错题帮界面整理

日期：2026-10-13。根据用户“正常、吸引主要注意力、不要花里胡哨、学习经典软件设计”的要求，本轮采用白色与中性浅灰背景、黑灰正文、单一深蓝强调。用标题、留白和分隔线组织内容，把题目与当前学习任务放在前面。

## 参考与取舍

参考 [Apple 的视觉层级与布局指导](https://developer.apple.com/design/human-interface-guidelines/layout)、[提醒事项的任务组织](https://support.apple.com/guide/iphone/get-started-with-reminders-iphc7880ecd6/ios) 和 [Notion 的清楚导航](https://www.notion.com/help/navigate-with-the-sidebar)。借鉴任务优先、稳定入口和逐步展开信息的方式，界面内容依据本项目实际功能与后端记录。

## 实际改动

- 首页保留一个当前主任务：继续学习、到期复习、教师任务或录题；其他待办使用普通列表。合并重复的拍照入口与长篇首次使用说明。
- 错题本突出题干，科目用下划线筛选；移除大号占位图标和每道题重复的未完成提示。
- 底部五个入口使用相同尺寸的图标和可见标签，拍照入口不再凸起或带阴影。
- 详情先显示题目与主要行动，步骤、参考内容和知识点按需展开；无解析时不占用空的正确答案区域。
- 拍题、手动录题、识别核对、诊断、辅导与学习档案统一为普通表单和清楚分区。辅导文本保持可读字号，反馈与错误提示保留。
- 学习报告无记录时只显示一处简短提示，数据产生后展示实际报告；组卷的更多筛选条件可展开，排序、分值与导出入口保留。
- 个人页合并组卷与导出入口。登录与注册表单限宽，电脑上的学习内容和固定操作栏居中，避免控件横铺整屏。
- 增加键盘可操作的导航与返回入口，以及减少动态效果的系统设置支持。

## 验证

完整 `CI=1 make verify` 包含 248 项后端测试、66 项前端测试、TypeScript 检查、H5 构建、Ruff、服务身份检查、6 项浏览器流程及真实 MySQL 本地业务验证。浏览器覆盖登录、会话恢复与失效、录题入口、手动题与多选题、无图修改、学习档案、桌面限宽与导航。

另使用独立本地验收账号，检查 390px 手机、768px 平板和 1280px 电脑三种尺寸下的登录及 12 个学生页面。共保存 39 张实际截图，未发现横向溢出或页面运行异常。截图中的错题来自明确创建的本地验收记录。
