# 错题帮作品演示视频制作记录

目标：以初二学生“小林”的使用情境，完整演示学生端真实功能。开场采用动画，主体为432×936手机视口浏览器实录，配中文合成旁白和字幕，结尾总结。学生为演示角色；不作为真人学生试验或提分结果。

## 录制原则

- 使用独立新注册账号，所有业务操作通过真实页面提交，调用实际仓颉、MySQL和Python服务。
- 不使用接口拦截、模拟AI响应或替换页面结果；不通过修改DOM制造功能完成状态。
- 点击提示仅为录屏可视化，不改变页面业务。
- 剪去制作过程中的空等候和自动化定位重试。计算等待若明显压缩，在片中说明。
- 保留原始录屏与逐段起止时间；配音在剪辑后同步制作。
- 到期复习若使用预置到期计划，明确标示“演示账号预置到期任务”，只预置时间状态，实际作答、判定、自评与再次调度仍实际运行。

## 覆盖目标

1. 注册、登录、学习设置、新用户首页。
2. 选图、框选、OCR核对、确认、错因诊断、依据和人工核对。
3. 错因回放、学习安排、渐进提示、局部订正、重新作答、草稿与任务恢复。
4. 互动图解、观察保存、拍照作答、条件对照、自检要点、订正记录与学习档案。
5. 手动录题、收藏、检索筛选、题目管理。
6. AI讲解的实际活动和回答、类似题与变式练习、连续练习及结果恢复。
7. 知识卡片、AI老师、知识框架、个人知识关系。
8. 题库练习、模拟考试设置、计时、答题卡、保存恢复、交卷和错题收录。
9. 到期复习、作答判定、难度自评、复习记录、范围搜索保存。
10. 易错地图与原题证据、学习报告和每日记录。
11. 错题组卷、编辑排序分值、生成并读取题目/答案PDF及Excel。
12. 个人资料、使用指南、修改密码与重新登录。

管理员维护入口不属于学生使用流程，不以学生身份展示越权操作。
