# 品牌封面设计

最新要求：统一蓝色；封面不出现人物、产品截图、题目、作答内容或学习数据；后续卡通开场保留。

采用独立的蓝白纸艺主视觉：空白书页延伸为学习路径，以书本和前进方向表达学习主题。封面文字仅保留产品名称、产品类别、赛事名称和“作品演示”。没有页面拼贴、功能清单、成绩或能力指标。

使用的技能：

- imagegen：内置图片生成工具，新生成透明背景主视觉，不传入任何旧图、产品截图或学生内容。完整提示词见brand-cover-prompt.txt，原始输出见brand-cover-art.png。
- UI/UX Pro Max：参考minimalism-and-swiss-style中的单一视觉重点、清晰字号层级、留白与克制装饰；沿用项目既有蓝色和简体中文字体。

排版由cartoon_intro.py维护。生成图为抽象品牌插画，不作为实际产品界面或使用证据。
