## 本轮新增能力

### 无图片手动录入

入口：拍照录入 → 没有图片？手动录入。填写学科、年级、完整题干、原作答及逐行步骤。输入经 Pydantic 校验后写入 MySQL，保存不调用模型，可继续查看、诊断和组卷。含图形的题目仍建议上传图片以保留必要条件。

### 错题学习档案

入口：错题详情 → 学习档案。聚合该题在 MySQL 中的确认、诊断、教学、题库练习和复习记录，给出可点击的下一步，支持复制学习摘要。

- “本轮结束”与“独立迁移通过”分开判断，辅助完成不显示为独立掌握。
- 不确定判题和待提交难度反馈不计入有效复习。
- 题干修改后，旧辅导/练习/复习保留为历史，当前进度重新根据有效证据计算。
- 最近各类 50 条记录参与统计，时间线显示最近 30 条；页面明确说明范围。
- 不额外调用 AI，不根据缺失数据伪造学习提升。

## 使用与工程修复

- OCR 重新识别等待对应任务完成，失败可重试、离页停止轮询；用户改动同步到实际用于诊断的公式和步骤。
- 上传后可以继续裁剪；选择题和多选题有正确提交形式；复习显示题干图与选项，提交前不展示原作答。
- 诊断页遵循后端参考答案，不从某个中间公式猜测最终答案；无具体步骤时不虚构“第 1 步”。
- 修改题目使旧分析、诊断与可继续学习状态失效，原图和原作答版本保留；重新分析按外键关系安全清理派生数据。修改题干、学科或仅作答步骤都会使旧题库推荐和旧提交失效；内容与作答修订指纹阻止检索期间改题后写回旧推荐。
- 删除错题采用归档，取消待复习任务并保留历史；复习完成使用数据库行锁防止重复提交生成多个下次计划。
- 所有业务 API 默认要求登录，按资源所有者检查；试卷正文中的题目也校验归属。密码修改须验证旧密码，无邮箱验证时不提供虚假的“忘记密码直接重置”。
- 图片和导出文件使用短期签名地址；会话密钥在本机持久生成，不沿用公开常量。
- 组卷导出前保存当前内容；PDF 保留题目选项、独立题干图和分页，不将带作答的原始照片放入空白练习卷；Excel 中用户文本按文本单元格保存。
- 学情删除固定进步百分比；教师、家长和学生多个页面支持错误重试；空评分不会被转换成 0 分。
- 数学解析采用有界算术语法树，分数、单位和变量关系保留完整含义；含变量分母等需要定义域判断的题目不冒充本地验证通过。不确定判题不增加掌握度。
- 题库将答案和解析存为整段文字时，只提取明确答案段中的纯数学表达式，或每一步都经 SymPy 证明等价的“原式”化简链；兼容数学显示包装与有界整数指数。多问、否定、错误变形及无法处理的定义域仍保留待核对。
- 无图片选择题把完整选项传入分析；本地数值求解不能覆盖正确选项字母。教学活动与迁移题只返回当前可见内容，不提前下发内部评分答案。
- 上传检查图片格式、大小与像素数；中断的识别任务恢复为可重试状态，后台识别不能重新激活已归档错题。
- 本机 MySQL 完整保留 49 张表并恢复启动，修复隐藏数据目录导致的重启问题；恢复过程和备份位置见 [数据库恢复记录](../mysql-recovery-20261013.md)。
- 前后端端口可配置，启动前核对服务身份；本次运行使用前端 5174、后端 8001，避免占用机器上其他项目的服务。
- 前端类型检查现在运行实际 TypeScript 检查，H5 编译另行验证；Python 类型与边界模型同步完善。

## 8—10 分钟实机演示建议

1. 新学生登录，展示无数据时的真实空状态（约 1 分钟）。
2. 上传一道带步骤错题并裁剪，核对和修正识别结果；没有可用照片时现场手录另一题（约 2 分钟）。
3. 展示首错证据、参考推导与校验状态，完成一段针对性辅导（约 2 分钟）。
4. 独立完成练习，展示不确定判题如何保留待核对；打开学习档案说明完成与掌握的差别（约 2 分钟）。
5. 完成到期复习或展示真实计划，组卷并打开导出；换账号验证记录隔离（约 1—2 分钟）。
6. 准备异常场景：识别失败后重试、题干改动使旧诊断失效、重复复习提交、非预设多选题（答辩随机测试）。

演示视频、团队报名信息及外部服务保障需要团队实际准备；文档和代码不能替代实拍视频、成员贡献说明或服务可用性承诺。
