# 错题帮运行与第三方依赖说明

文档日期：2026-10-19。源码地址：https://github.com/Baxxhy/cuoti 。两份正式文档对应业务源码基线295366d；后续文档提交不改变该业务实现。本文件说明实际资源用途、来源及本次文档包的分发范围，不代替参赛团队对服务授权与资源许可的最终确认。

## 1. 运行架构

uni-app/Vue 3客户端访问仓颉业务API；仓颉管理身份、任务和MySQL，Python/FastAPI仅提供内部算法。原始图片与派生资源分开保存；BGE和Qdrant按需提供题库检索；模型通过ApiPoolProvider访问Qwen资源池。

当前可验证运行形态为H5，App资源工程已经构建；Android/iOS签名安装与真机验证按路线推进。本文件不是APK/IPA或程序运行包。

## 2. 环境与启动

先按仓库 `docs/final/QUICK_START.md` 准备仓颉工具链、Python、前端依赖和独立MySQL，再配置业务与模型资源。仓颉包清单对应cjc 1.0.5；前端锁文件与依赖声明用于还原工程。模型、检索资源与数据库由部署环境提供。

```bash
make install-final
# 按指南显式配置和初始化独立MySQL；实际配置不随文档分发。
make dev-final
make check-final
```

启动器输出当前H5地址；`make check-final`分别检查仓颉业务、MySQL表版本、Python算法和前端。它不调用付费模型，不代替真实题目质量验证。

主线完整验收入口为 `make verify-final`；旧 `make verify`面向保留的Python业务兼容入口。题库准备使用仓颉主线指南，不向新库运行旧业务版导入逻辑。所有数据库只使用MySQL。
