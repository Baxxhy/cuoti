# 错题帮程序包验收记录

验收日期：2026 年 10 月 23 日。平台：Linux x86_64、Docker Engine 26.1.3。使用独立的交付容器、数据库和自编验收题；宿主机原有学生数据没有导入。测试入口使用 5186，交付默认入口为 5175。

## 验证范围

- 注册、重新登录、手动错题录入与查询。
- 24 道自编基础方程题的题库查询；练习与模拟考试保存、交卷、重复提交。
- 知识卡、首页、复习列表和学习报告接口。
- 对自编方程题发起真实外部 AI 分析和错因诊断，结果保存到独立 MySQL。
- 容器重启后再次登录，原错题与学习会话仍存在。
- 浏览器 390 × 844 手机视口登录并进入首页，未记录到页面脚本错误。
- 离线 BGE 计算返回 1024 维向量及稀疏权重；候选排序返回两项得分。
- 本地语音模型加载及静音输入推理。此项没有验证真实口音与噪声环境下的识别准确率。
- 试卷 PDF、答案 PDF 和 Excel 文件导出、下载与文件格式校验。公式样例另行渲染检查，中文和分数公式可读。

JSON 结果与手机首页截图保存在“验收证据”目录。核心运行和 AI 请求在本次镜像构建期间验证；最终依赖调整后复测了核心业务与导出。各记录对应同一业务源码，Excel 兼容修复另有回归测试：test_paper_export_compute.py 共 5 项通过，耗时 5.13 秒；框架弃用提示不影响本轮结果。

## 本次修复

1. 补齐仓颉、Python、数据库和图像计算所需动态库。
2. 独立初始化 MySQL，采用项目允许的数据库名称，重启不覆盖已保存数据。
3. 补齐 CPU 检索环境及模型缓存，避免依赖原主机的 GPU 或损坏环境。
4. 加入 Node、Chromium、公式渲染依赖和中文字体，并保留 Python 所需的 XML 库版本。
5. 修复 AI 分数公式中的已知 JSON 换页控制字符导致 Excel 写入失败的问题；采用与前端相同的修复规则。其他非法控制字符返回可处理的输入错误，不修改已保存的题目内容。

## 验证边界

以上记录证明列出的运行流程与具体样例已通过，不能作为所有题型 AI 准确率或学生学习效果的证明。本次程序包验收没有逐一重跑应用全部历史测试；也没有把基础接口正常等同于所有辅导工作流均完成端到端验证。

图片识别、完整订正与复习链路、语音合成、手机摄像头与麦克风权限，可按《功能验收说明.md》进一步体验。本次独立容器验收没有对这些项目逐一完成新的端到端记录。浏览器手机视口不等于 Android APK 或 iOS 真机验收。

AI 解题和语音合成仍依赖外部网络与有效服务配置。Compose 文件提供替代入口，实际启动验收使用 start.sh。包中不提供真实密钥、学生数据库或已登录账户。
