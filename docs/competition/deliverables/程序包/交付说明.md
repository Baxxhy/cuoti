# 错题帮可运行程序包

交付文件：错题帮_可运行程序包_Linux_x86_64.zip（约 5.01 GB）。

包含预构建 Docker 镜像、启动脚本、Word 和 Markdown 部署说明、源码、模型及依赖、验收记录和校验清单。平台为 Linux x86_64，需要 Docker；AI 解题需要有效密钥及网络。

解压后先读“请先阅读.md”或“部署说明.docx”。首次执行 bash start.sh 会生成 .env，填写密钥后再次执行。默认访问 http://127.0.0.1:5175 ，自行注册账号。无预置学生密码，不包含原学生数据库或真实密钥。

已验证范围见“验收记录.md”。ZIP 为本地大文件交付，不纳入 Git 历史。
