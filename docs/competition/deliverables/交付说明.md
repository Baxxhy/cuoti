# 错题帮参赛文档

本包是源码基线950ce87对应的两份参赛文字材料。项目说明采用六章，解释需求、产品、创新算法、架构、验证与移动产品路线；系统设计采用七章，解释职责边界、模块、算法协同、数据、安全、测试与跨端演进。

## 阅读顺序

先阅读《错题帮_项目说明文档_重写终稿.docx》，再阅读《错题帮_系统设计文档_重写终稿.docx》。同名Markdown便于检索和版本维护，Word为可编辑排版版本。证据与来源、运行与依赖说明提供参考、数据和工具披露。

正文指定宋体，一级、二级标题指定黑体。Word中的可编辑文字统一纯黑色；机制图使用黑色标签和彩色分区。运行截图保留真实界面颜色，没有重绘界面或改写运行数据。无附录、页眉或页脚，目录中的页码为自动目录字段。依照本轮要求仅提供Word，不生成PDF。

## 机制图与截图

figures内含十张独立机制图及逐图完整提示词，均由当前内置图片工具生成。每张生成时不传旧图或其他生成图，完成后核对实际文字和连线。图像是PNG，不是可逐对象编辑的矢量图；Word正文、表格和标题可编辑。提示词支持后续重新生成，但生成结果不保证逐像素一致。

两份主文共18个图位，含10张机制图、11张不同运行截图；系统设计复用其中两张，说明界面动作与业务状态的关系。截图覆盖今日入口、诊断订正、独立作答、条件对照、自检、易错地图、复习回答与反馈、类似题结果和继续操作。均使用已有浏览器运行归档，保留原始像素；本轮没有重新运行对应学习动作，也未把工程样例称为真人学生试用。不同样例不拼接为同一次学习记录。

背景围绕“知道哪里错、确认自己会、安排下一步”展开，方案与算法放在后续章节。旧版文档和此前三轮审查记录另行保留，本轮增补的文件身份和验证结果见工作目录质量报告。

## 提交配套

本包不包含源码、数据库、密钥、模型权重、内部评审和临时预览。带历史的源码、程序及部署环境、演示视频、真实成员贡献和授权材料，按赛事平台要求由参赛团队一并提供。Word中的规则参数与工程测试结果不表示真实学生提分或题型总体准确率。
