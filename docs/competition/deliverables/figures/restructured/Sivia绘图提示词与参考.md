## 执行绑定

实际检测 draw.io 服务未连接（Linux，graph_ready=false）。使用 Sivia 的设计—绘制—检查—修正流程，产出逐对象可编辑的 SVG 与 CairoSVG 渲染 PNG。未调用 live draw.io、PowerPoint 或 ImageGen，不将本轮表述成这些后端的生成结果。所有图形均由本项目源事实重新组织。字体请求宋体/黑体；宿主缺少这两种字体，SVG/PNG 明确采用 Noto Serif/Sans CJK，避免缺字，Word 中字体设置由文档构建处理。

图中文字为纯黑，采用蓝、绿、橙、紫、暖黄五种语义色。颜色用于角色区域，黑白仍由形状、线型和标题区分。
