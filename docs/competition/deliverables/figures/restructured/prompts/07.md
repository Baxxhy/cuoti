# 关键时序：Sivia 绘制提示词

交付用途：Word正文中的可编辑矢量示意图。画布900×725，置入宽16.4cm；PNG导出3倍尺寸。

构图与关系：横向四个参与者、纵向时间。先显示受理回执，再显示异步worker领取与计算，最后呈现后续GET读取结果。长模型调用不位于数据库提交事务内。

视觉规则：白底，证据暖黄#fff0cd，计算浅蓝#d6eafa，业务浅绿#cfece1，核对浅橙#f8dcc9，工具与并列分支浅紫#e5ddf4。全部标签#000000。纸页表示原始材料，六边形表示运算，圆柱表示存储，胶囊表示终态；开放边界只表达真实作用域。主路径实线，反馈虚线，图例解释线型。不要把所有对象做成同样的卡片。

字体请求宋体和黑体；在本环境渲染使用Noto宋黑系以避免缺字。正文最小18px，组标题20—22px，禁止缩小字体来塞长句。以下是必须保留的短标签及坐标，按科学关系组织连线，线不得穿过无关标签。

- (105, 60)，20 px：学生端
- (325, 60)，20 px：仓颉业务服务
- (555, 60)，20 px：Python 计算
- (790, 60)，20 px：MySQL
- (215.0, 129)，18 px：创建／提交动作
- (557.5, 196)，18 px：校验来源与幂等，事务建任务
- (215.0, 240)，18 px：返回任务受理回执
- (557.5, 289)，18 px：工作器领取租约与快照
- (440.0, 348)，18 px：内部计算请求
- (440.0, 405)，18 px：结构化候选结果
- (250, 487)，18 px：提交事务：重新检查租约、任务版本与来源
- (250, 524)，18 px：有效：更新结果、事件与合格证据；失效：回滚
- (557.5, 567)，18 px：提交／拒绝过期结果
- (215.0, 616)，18 px：后续请求：读取任务状态
- (215.0, 663)，18 px：当前状态与下一步入口

检查：主路径与上述构图一致；必须保留来源有效性和写入归属；不得添加性能、准确率、用户规模或手机安装记录。先检查全色图，再检查去标题灰度图的层次，最后检查Word实际宽度。几何构造源为build_refactor/render_figures.py的图07段，所有文本、路径及形状可在SVG中编辑。
