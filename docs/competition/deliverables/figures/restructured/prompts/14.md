# 学生使用旅程：Sivia 绘制提示词

交付用途：Word正文中的可编辑矢量示意图。画布900×670，置入宽16.4cm；PNG导出3倍尺寸。

构图与关系：以学生行动旅程组织首次进入、录题、诊断、修复和复习，不画成营销漏斗。每阶段只有一个主要动作，下方以已有记录为个性化输入，回到真实题目来源。

视觉规则：白底，证据暖黄#fff0cd，计算浅蓝#d6eafa，业务浅绿#cfece1，核对浅橙#f8dcc9，工具与并列分支浅紫#e5ddf4。全部标签#000000。纸页表示原始材料，六边形表示运算，圆柱表示存储，胶囊表示终态；开放边界只表达真实作用域。主路径实线，反馈虚线，图例解释线型。不要把所有对象做成同样的卡片。

字体请求宋体和黑体；在本环境渲染使用Noto宋黑系以避免缺字。正文最小18px，组标题20—22px，禁止缩小字体来塞长句。以下是必须保留的短标签及坐标，按科学关系组织连线，线不得穿过无关标签。

- (43, 58)，23 px：首页：今日
- (43, 95)，19 px：新用户：年级／学科方向与知识入口     有记录：修复任务与到期复习
- (130, 215)，22 px：收录
- (130, 284)，22 px：收录与校对
- (450, 215)，22 px：理解
- (450, 284)，22 px：理解与订正
- (770, 215)，22 px：练习
- (770, 284)，22 px：练习与复习
- (130, 335)，18 px：保留原图与实际作答 / 识别结果支持校正
- (450, 335)，18 px：错因回放与依据核对 / 修复路线给出下一步
- (770, 335)，18 px：先独立作答再判定 / 复习保留真实反馈
- (42, 461)，21 px：跨页面可追溯入口
- (42, 504)，20 px：易错地图 → 对应原题 → 当前诊断／任务／历史记录
- (42, 539)，18 px：主操作保持清晰；详细依据进入二级页面，避免首页一次堆叠全部信息。
- (450, 645)，18 px：新证据改变后续任务与复习优先级，保留每次更新的来源。

检查：主路径与上述构图一致；必须保留来源有效性和写入归属；不得添加性能、准确率、用户规模或手机安装记录。先检查全色图，再检查去标题灰度图的层次，最后检查Word实际宽度。几何构造源为build_refactor/render_figures.py的图14段，所有文本、路径及形状可在SVG中编辑。
