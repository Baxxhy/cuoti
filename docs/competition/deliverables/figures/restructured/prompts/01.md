# 学习闭环：Sivia 绘制提示词

交付用途：Word正文中的可编辑矢量示意图。画布900×650，置入宽16.4cm；PNG导出3倍尺寸。

构图与关系：左侧用两张分离纸页呈现题目作答与参考解析之间的断点。右侧突出原始作答指向错因定位，定位进入修复任务，学生作答形成学习记录；记录回到新作答与复习。左侧虚线断点不能误连成成功学习路径。

视觉规则：白底，证据暖黄#fff0cd，计算浅蓝#d6eafa，业务浅绿#cfece1，核对浅橙#f8dcc9，工具与并列分支浅紫#e5ddf4。全部标签#000000。纸页表示原始材料，六边形表示运算，圆柱表示存储，胶囊表示终态；开放边界只表达真实作用域。主路径实线，反馈虚线，图例解释线型。不要把所有对象做成同样的卡片。

字体请求宋体和黑体；在本环境渲染使用Noto宋黑系以避免缺字。正文最小18px，组标题20—22px，禁止缩小字体来塞长句。以下是必须保留的短标签及坐标，按科学关系组织连线，线不得穿过无关标签。

- (36, 52)，21 px：(a) 学习断点
- (53, 125)，20 px：题目与作答
- (53, 159)，18 px：错题照片 / 分散的过程记录
- (158, 277)，18 px：断开
- (53, 345)，20 px：参考解析
- (53, 379)，18 px：看到答案 / 缺少独立验证
- (40, 515)，20 px：看懂之后
- (40, 550)，18 px：下一步仍不明确
- (308, 52)，21 px：(b) 以证据组织学习
- (328, 135)，20 px：原始作答
- (328, 169)，18 px：实际步骤 + 来源版本 / 可回看、可补充
- (718, 169)，22 px：错因定位
- (718, 202)，18 px：关联证据
- (628, 364)，20 px：修复任务
- (628, 398)，18 px：订正 → 独立作答
- (328, 365)，20 px：学习记录
- (328, 399)，18 px：作答结果 + 使用条件
- (455, 302)，18 px：新作答

- (450, 620)，18 px：实线：证据与任务主路径     虚线：后续学习反馈

检查：主路径与上述构图一致；必须保留来源有效性和写入归属；不得添加性能、准确率、用户规模或手机安装记录。先检查全色图，再检查去标题灰度图的层次，最后检查Word实际宽度。几何构造源为build_refactor/render_figures.py的图01段，所有文本、路径及形状可在SVG中编辑。
