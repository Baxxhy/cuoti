# 重构版图表源文件

本目录含 15 张独立信息图：SVG 为可编辑矢量源文件，PNG 为其 3 倍尺寸渲染，不是运行截图。图内内容表达当前实现机制或明确标注的演进路线，不代表学习效果实验。

统一规范：900 px 画布宽；最小文字 18 px；全部文字显式 `fill="#000000"`；Noto Sans CJK SC；白色、浅蓝、浅绿色及中性边框。以 16.4 cm 宽插入 Word 时最小字约 9.3 pt。禁止以白色文字覆盖深色底。

生成器：工作区 `../../build_refactor/render_figures.py`；正式ZIP内 `../render_figures.py`。运行需要 Python、CairoSVG、Pillow 和 Noto CJK 字体。源文件保留图形构图、标签、模块关系与所有布局坐标。`titles.json` 含每图标题和核心结论；`audit.json` 为生成后字体颜色、字号和画布边界检查结果。
