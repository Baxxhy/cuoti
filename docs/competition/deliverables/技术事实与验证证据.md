## 真实固定样本

2026-10-18记录`docs/final/EXTENDED_AI_ACCEPTANCE_2026_10.md`覆盖12道公开自编固定题。核对答案含义、实际步骤定位与说明依据，接受语义等价结果；出现过503，按有上限的重试完成。

| 样本 | 核对结论 |
|---|---|
| x/2+1=4，学生答6 | 答案与过程正确，不虚构首错 |
| −2x>6，学生写x>−3 | 正确解集x<−3，除负数未变号 |
| √(x+2)=x，学生答−1或2 | 仅2有效，−1应排除 |
| (x²−1)/(x−1)=2，学生答1 | 无解；约分需保留x≠1 |
| abs(x−1)=2，只答3 | 应为−1或3，遗漏分支 |
| 0.5x+0.2=1.7，学生答3 | 正确，未误判路径 |
| 三角形仅知A=50°，求C | 条件不足，不能假设B=50° |
| 72 km/h行驶10 s | 200 m，第2步单位不一致 |
| 密闭4 g氢气与32 g氧气恰好完全反应 | 水36 g，需计全部参加反应物质量 |
| She ___ to school every day，填goes | 正确，首错为空 |
| 光合作用吸收/释放气体 | 二氧化碳/氧气回答正确 |

## 受控机制案例

方程2x+3=11的受控回归按局部订正“11−3”、原题x=4、对照2x−3=11的x=7推进；对照生成只改左常数3为−3。对照答案满足条件后提供计算侧学习资格，仓颉仍核对有效来源、独立性及曝光去重。看过提示后答对与重复完成不产生新的独立近迁移证据。来源为`backend-algorithms/tests/test_learning_task_compute.py`及任务专项。

另一受控分支提交“2x=14”，依次出现check_step的错误反馈、knowledge_search零命中rejected、step_alignment支持，保留repair和未取得学习资格状态。对应`test_incorrect_observation_causes_bounded_replan_after_zero_hit`。这是回归中的执行序列，不是上述三条真实模型任务的工具日志。

复习规则情境依据`reviews.cj:102–130`：有效回执和来源下，确认正确＋easy为15天，确认错误＋easy为4天；待核对不推进计划。该值是工程调度规则，不是测得的遗忘曲线。
