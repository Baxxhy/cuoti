# 错题帮参赛文档

版本：2026年10月19日参赛定稿。业务源码基线：295366d。此次交付Word与配套Markdown，不生成PDF。

## 阅读顺序

1. `错题帮_项目说明文档_参赛定稿.docx`：需求、产品、核心创新、总体技术、实现验证与移动发展，共六章。
2. `错题帮_系统设计文档_参赛定稿.docx`：设计、模块、业务机制、数据状态、安全部署、测试与移动交付，共七章。
3. 《技术事实与验证证据》：实现状态、有效验收批次、真实固定样本及受控回归案例。
4. 《参考资料与案例出处》：官方来源与固定源码版本链接。
5. 《运行与第三方依赖说明》：运行入口、第三方模型与数据来源、许可状态和AI辅助披露。

创新机制围绕学生实际作答定位、工具反馈驱动的持久学习任务、有效独立作答的学习证据准入展开。单位换算、定义域、单条件方程对照和跨题地图等案例分别解释具体机制，真实任务记录与受控回归单独标注。

## 文件说明

正文与表格可在Word中编辑；正文宋体，一级和二级标题黑体，可编辑文字统一黑色。采用两级自动目录、全格线表格、居中题注，无附录、页眉与页脚。打开时需要系统可用的宋体/黑体；字体替换可能改变分页，更新目录即可重新计算页码。

`figures/academic_v5/`含15张PNG方法图、逐图独立提示词及用途说明。原始图片分辨率1536×1024，插入Word未改变源像素。图内部是栅格内容，可替换图片，不能作为可直接修改标签的矢量图。`figures/screenshots/`含4张实际页面细节，来自隔离核验账号，并保留原界面颜色。

Markdown与Word正文对应。内部三轮AI评审、生成脚本、渲染临时页和旧文档不放入本压缩包；它们保存在项目工作目录供追溯。文档包不包含业务数据库、私密模型池、权重、题库原包、安装包或演示视频。

## 成果范围

仓颉承担业务API、任务和MySQL交互，Python提供内部智能计算，uni-app/Vue 3提供客户端。本文记录现有工程与对应验证，不把模型语义建议等同形式证明。H5及App资源构建已有记录；签名安装与真机发行属于后续平台验证。既有测试数量和固定题样本范围见证据表，不延伸为所有新题准确率或长期学生提分结论。
