# 运行与依赖说明

源码地址：[Baxxhy/cuoti](https://github.com/Baxxhy/cuoti)，业务基线950ce87。客户端为uni-app/Vue 3/TypeScript，仓颉负责业务与MySQL，Python/FastAPI提供独立内部算法。只有当前一条业务主线，旧Python业务版已删除。

## 启动

按仓库README和docs/final/QUICK_START.md准备Linux、仓颉SDK、Python、Node/pnpm与MySQL。已有环境沿用配置，新环境按指南显式初始化，不覆盖学生数据。当前命令为make install、make dev、make check、make test、make build及make verify；make verify-final为同一完整检查入口。

前端可通过ZHIWEI_FRONTEND_PORT指定5175。仓颉默认8002，内部算法8012，具体地址由已有环境配置决定。模型池位于config/api_pool.json，逻辑名称Qwen，经ApiPoolProvider轮询；密钥、口令和实际配置不随文档分发。检索资源按仓库指南单独准备。

## 工具与贡献披露

Codex辅助本轮代码事实核验、写作、排版和任务内独立AI审查；内置imagegen以逐张独立提示词生成机制图，不传旧图作为参考，生成后核对技术关系与文字。采用Technical Writing和Manuscript Writing的实际版本规范，最后用anti-defensive-writing精简语言。图源提示词随包保留，PNG标签属于栅格内容。

当前工作只修改文档和相关交付材料，不将本轮文档重写当作新一次业务开发或重跑模型实验。真实成员贡献、既有成果归属、原创性与知识产权声明由参赛团队据实签认；AI审查不是真人专家或比赛官方背书。

现有H5和App本地资源构建可验证，签名安装、真机兼容与平台发布按后续阶段完成。文档包是文字与图片材料，程序、实录视频和评审服务另行提供。
