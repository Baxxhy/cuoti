# 参考文档版式学习

五份用户提供的Word均已读取正文、样式和段落属性。借鉴格式及段落组织，不采用参考项目的技术内容、测试结果和业务功能。

- 正文以12磅宋体为主，一级/二级标题黑体，主要采用16/14磅层次。
- 技术论述按完整主题组织连续段落，首行缩进两字符；机制解释之后紧接例证和图表。
- 复杂事项使用全框表格，图题位于图下居中，表题位于表上居中。
- 保留本项目六章/七章结构，短标题不附加解释；统一黑色文字，去掉页眉页脚。
- 参考材料中出现的其他技术架构、训练方案、准确率和用户数据不进入本项目正文。

原始样式统计见metrics.json；参考页直接由Word渲染为PNG进行观察，未修改原文件。
