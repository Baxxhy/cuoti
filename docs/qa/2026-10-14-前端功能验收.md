# 前端优先功能验收

日期：2026-10-14。验收对象是本项目 H5 前端（5174）、后端（8001）和 MySQL。采用四角色登录、浏览器实际输入/点击、数据库保存核对和页面截图，重点检查前端交互与信息呈现。

## 结论

验收开始时，存在阻断学习和影响使用的问题，不能称为“全部正常”。本轮已修复下表所列问题，已覆盖的主要使用流程复测通过。最终完整检查通过：后端 267 项、前端 72 项、浏览器 15 个场景；另完成真实 Qwen 辅导、题库练习、互动演示和复习的人工操作验收。

手机、平板、电脑分别按 390、768、1280 像素宽度检查了 31 个不同页面、102 个角色/尺寸页面实例。最终未发现横向溢出、未解析组件、页面运行异常、意外接口错误或 `[object Object]` 文本。该结果证明这些页面实例的检查结果，不代表已穷尽全部数据、所有浏览器和所有分支。

## 发现的问题与修复

| 问题 | 用户影响 | 修复及验证 |
|---|---|---|
| 讲回、非选择练习、复习的输入组件未实际加载 | 页面看似正常，但无法写答案 | 显式加载组件；真实辅导输入提交、真实练习、真实复习均通过；增加浏览器回归 |
| 互动演示和知识图谱组件未显式加载，演示也没有入口 | 图形功能难以找到或未显示 | 补齐组件及辅导入口；入口仅在有匹配演示时显示；实际绘制、图谱节点和科目筛选通过 |
| 演示只读取录入知识点，没有读取已生成的分析知识点 | 有相关演示仍提示无法加载 | 与辅导使用相同的分析知识点；实际等式天平加载成功 |
| 演示滑条仅监听拖动中事件 | 点击后滑条位置变化，显示值和保存值仍旧 | 同步处理最终变更事件；真实点击从 3 改为 -4，观察保存后返回辅导；浏览器回归通过 |
| 教师/家长白色个人图标出现在白色页头上 | 入口不可辨认 | 改为可辨认图标、44 像素操作区域和明确名称；两角色进入、返回、退出通过 |
| 管理员手机侧栏挤压内容 | 文字竖排、卡片过窄、页面过长 | 手机改为顶部四分区，详情纵向排列；实际分区切换、学生/会话详情、刷新、退出通过 |
| 教师样式未限定页面范围 | 教师的字段/标签样式可能影响学生页面 | 样式限定到教师页面；三个尺寸复查通过 |
| 直接打开角色页面后返回学生首页 | 教师/家长返回位置错误 | 根据页面角色选择返回入口；角色浏览器操作及导航回归通过 |
| 裁剪角点只处理触摸 | 电脑无法用鼠标调整识别范围 | 支持鼠标拖动并在退出时清理监听；实际上传裁剪和桌面回归通过 |
| 修改录入内容只有“预览”或再次分析，没有独立保存 | 用户难以确定修改是否保存 | 编辑模式提供“保存修改”，通过后端确认接口保存并返回详情；保存及数据库核对通过 |
| 教师关闭自动判题后仍先调用模型，复核后学生任务未完成 | 人工任务被错误送入 AI；学生始终等待 | 禁用自动判题时直接保存待复核；结论同步任务状态，尊重不计掌握度设置；真实师生闭环及行为回归通过 |
| 方程迁移题混入依赖缺图的函数/几何题 | 学习偏离当前知识点，无法独立作答 | 校验题干关联及缺图条件，重新检查缓存题；必要时使用明确标注来源的同知识点规则题；真实近迁移及远迁移完成 |
| 学习报告重复显示同一知识点、错因含原始公式标记 | 信息重复、公式难读 | 避免同一项在两个摘要中重复出现；错因使用公式渲染；移除泛泛的宣传与内部策略文案 |
| 确认弹窗继承英文按钮 | 操作含义与中文页面不一致 | 设置中文确认/取消及应用语言；取消归档、取消删除通过 |

## 信息与配色

主要内容使用白底、浅灰分区、深色正文；深蓝用于主操作和选中项。红色用于错误，橙色用于需要注意或观察任务，绿色用于成功状态；状态均有文字说明。教师样式不再影响学生页面，管理员手机内容有正常阅读宽度。删除家长页宣传横幅、摘要重复项和不帮助决策的内部策略文案，保留题目、反馈、证据与下一步操作。

配色和信息层级通过截图人工检查，未做完整 WCAG 审计。当前关键内容和操作可辨认；不据此声称所有次要文字均满足某项无障碍认证。

## 验证与证据

- 最终执行 `CI=1 QA_ROLE_TESTS=1 make verify` 成功：267 项后端测试、72 项前端测试、15 个浏览器场景，Ruff、TypeScript、H5 构建、本地 MySQL/账号/权限/文件导出检查通过。
- `frontend/e2e/functional-audit.spec.ts` 保存了新增交互回归；注册/登录/导出/师生任务使用真实后端。输入组件和演示入口的回归使用明确限定的公开任务响应来隔离远程模型，真实服务验证单独执行。
- `backend/tests/test_assignment_review_flow.py` 与 `backend/tests/test_variant_presentation.py` 覆盖人工任务状态、关闭自动判题、知识点偏离、缺图题和分析知识点演示关联。
- 页面检查摘要保存在 [2026-10-14-page-layout.json](2026-10-14-page-layout.json)。它只记录布局和错误检查，不包含密钥、令牌或输入内容。
- 实际服务操作证据保存在本机临时验收目录 `/tmp/zhiwei-qa-live-ui` 与 `/tmp/zhiwei-qa-extra-ui`；最终检查日志 `/tmp/zhiwei-qa-make-verify-final.log`。临时目录不是长期归档，主要结果和回归已保存在本仓库。

## 尚未覆盖
