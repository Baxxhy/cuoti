# 部署前回归验收

本轮在本机 HTTPS H5 发布产物、FastAPI 与 MySQL 上完成回归。部署目标尚未确定，未发布到外部环境。此前的页面验收是基线，本报告记录本轮修复和新增证据。

## 修复与清理

- 修改密码后，旧登录会话立即失效；新会话绑定当前凭据。旧版本未绑定凭据的会话需要重新登录。
- 合并两个 Alembic head；修复旧迁移重复建表、加列的问题。在独立 MySQL 库验证空库安装、中断后续迁、重复执行，未清空现有学习数据库。
- 教师确认错误、部分正确、退回重做和题目问题的反馈显示到学生任务页；完成数只计算已完成任务。
- 教师“必须手写”和“允许重复作答”设置生效。照片必须属于当前学生和当前任务；待核对、题目问题期间禁止再次作答；提交时锁定任务，避免并发覆盖。
- 教师复核页显示学生原始作答照片。原图保留，签名照片可访问，移除签名后访问被拒绝。
- 截止时间改成日期和时间选择，中文显示；输入时先转换为 UTC，MySQL 取回时间附带明确时区。
- 照片识别失败或未识别出文字时保留原答案；离开页面后忽略迟到结果；过程末尾已含答案时不重复添加答案。
- 统一前后端代码格式，抽取照片校验和时间处理为共享服务；移除未使用的 ECharts、Lucide、Axios 及适配器、重复 npm 锁文件、闲置导入和样式。保留 pnpm 锁文件、有效行为测试、用户数据和模型配置。
- 删除仅检查源码字符串的功能测试，补充照片恢复、图谱节点操作、日期选择等组件行为检查；主要功能继续由真实浏览器回归覆盖。
