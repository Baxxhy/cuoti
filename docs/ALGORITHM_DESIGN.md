# 三算法设计

2026-10-20，实施中；正式接入状态以 [升级记录](QUICK_UPGRADE_REPORT.md) 为准。

| 算法 | 输入 | 输出 | 复用与新增 |
| --- | --- | --- | --- |
| ECED | 实际步骤与 ID、参考步骤、已有模型候选、原题符号核验对齐 | 首错位置、错误类型、来源证据、分级可信度、核验状态、确认问题或订正动作 | 复用原模型诊断与多项式/不等式核验；新增来源匹配、证据排序和拒绝编造规则。 |
| AEMT | 现有掌握状态、作答事件 ID、判定、辅助情况、来源有效性、时间间隔 | 掌握状态建议、变化原因、证据权重、不确定性、遗忘风险 | 复用 `adaptive_practice.posterior/entropy`；新增提示、解析曝光、延迟迁移和无效证据门槛。 |
| ARPP | 当前阶段、薄弱知识、候选题、到期状态、重复次数、难度、可用时间与学习目标 | 动作、题目 ID、理由、预计时间、备选题与评分分项 | 复用信息增益；新增动作规则与多因素排序。 |

## ECED

配置入口为 `EvidenceWeights`。默认步骤匹配 1、规则支持 2、参考支持 1、课程资料关联 0.5、矛盾惩罚 4；分数只用于排序，不是概率。只有真实学生步骤和受支持的符号核验能建立已核验错误；未知前置步骤会阻止“首错已确定”的结论。检索资料沿用现有知识来源过滤，资料关联和模型解释中的认知原因不自动成为规则证明。

## AEMT

配置入口为 `MasteryConfig`。初始掌握估计 0.35；独立证据权重 1，提示后 0.35，间隔至少一天独立答对类似题为 1.25；正确作答可有最高 0.08 的学习转移。完整答案曝光只记辅助学习，不增加掌握证据。局部订正、来源过期、未确认 OCR 和核验失败不更新掌握估计。

后验复用现有 BKT，以权重调节似然；不确定性使用二元熵，遗忘风险使用时间衰减估计。参数是可解释的冷启动默认值，未经拟合。事件 ID 检查辅助防重；跨任务正式幂等仍须由仓颉事务和作答记录保证。

## ARPP

配置入口为 `PlannerConfig`。默认权重：错因关联 0.2、薄弱程度 0.2、信息增益 0.15、到期程度 0.2、难度适配 0.15、时间适配 0.1；重复惩罚 0.3。分项归一化到 0～1。符合时间与学科条件的到期题优先，刚掌握的题跳过，备选最多两题。

动作包含 explain、hint、repair、prerequisite、retry、practice、review、stop。先检查学习预算与目标、证据不足、先修不足、重复错误和连续失败，再按学习阶段与候选题安排下一步。无题时返回实际知识卡，或明确说明暂无合适题目，不生成虚构题目 ID。

学生已设置每日学习量时，仓颉从当天完成的订正任务和已交卷、可核验的题库作答计算剩余目标。时间按已完成题量估算（订正任务 3 分钟、题库作答 1 分钟），不是实际屏幕用时；协调图再扣除本次刚完成的题目。目标或预计可用时间用完后停止自动推荐，保留学生手动继续学习的能力。
