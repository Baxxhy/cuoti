# 教学会话创建读取与阶段迁移记录

日期：2026-11-17。版本：v1。起点：320e26e。

## 本次业务接入

| 方法 | 路径 | 迁移内容 |
|---|---|---|
| POST | /api/v1/tutor/sessions | 本人已确认题目与分析校验、完整或简短教学策略、教学简报调用、初始活动与答案讲解、会话/开场对话/Agent工具审计保存 |
| GET | /api/v1/tutor/sessions/{id} | 本人会话读取、旧阶段规范化、历史状态默认值补全、公开进度、活动、图片签名及对话历史 |
| POST | /api/v1/tutor/sessions/{id}/advance | 只允许已通过理解检查的understanding进入teach_back；保存阶段和提示及工具记录 |
| POST | /api/v1/tutor/sessions/{id}/rewind | 沿原规则返回上一阶段，清理对应阶段的临时评估，保留历史记录 |

实际阅读tutor_start、tutor_read、tutor_state、tutor_policy、tutor_navigation、tutor_activities、tutor_variants，以及tutor_answer、tutor_completion、tutor_dialogue等相关实现。核心代码位于tutoring.py，初始活动直接复用backend-algorithms的build_understanding_plan和activity_public，未新造一套教学生成算法。

本地教学策略决定阶段门槛。模型生成简报不能直接通过理解检查、完成教学或更新掌握度。公开state不含understanding_plan、activity_attempts或内部教学简报；活动使用已有公开投影移除correct_answers。答案讲解沿原界面约定单独展示。

会话创建在计算前读取本人题目与分析，事务外生成简报，写入前重新比较快照，防止变化后的旧结果提交。新建会话同时保存tutor_turns、agent_runs和agent_tool_calls。读取时签名媒体，阶段操作拒绝已修改或归档题目。

## 诊断知识上下文

同时迁移tutor_dialogue.cj的dialogueCardScore/dialogueKnowledge，用于诊断快照与输入：同学科最多200张候选，按原标签/别名评分选择最多3张锚点，初中排除高中内容，再补最多2张前置卡并去重，总数不超过8。知识卡也纳入写回快照，变化后不能提交旧诊断。该步骤是原有确定性卡片检索，并非宣称BGE/Qdrant全链路已迁移完成。
