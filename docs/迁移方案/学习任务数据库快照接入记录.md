# 学习任务数据库快照接入记录

日期2026-11-17，版本v1，基线9d2bdf0。

将原taskSnapshot的本人题目、最新作答、步骤、题图、分析、参考步骤和诊断读取接入Python，支持按需题目行锁。学习记忆的task_fingerprint改用同一快照与字段顺序，避免来源捕获和记忆版本各自实现产生差异。

真实MySQL集成测试1项通过，6.64秒，验证来源首次捕获、重复读取保持单条、跨用户拒绝、题目变化后旧来源拒绝，并清理本次waiting_student任务及来源行。该测试没有启动worker或执行模型。另复测受影响的学习记忆与来源单测。

仍需接入任务上下文、领取租约、实际检查点计算、结果提交与后台循环。当前不能宣称学习任务整体可用，更不能宣称全部仓颉迁移完成。
