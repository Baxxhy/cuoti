## 本轮完成的功能

1. 列表补齐question_type筛选，与subject、grade、knowledge_point、search组合使用。sort支持created_at、updated_at、oldest。page从1开始、page_size为1至200，非法值422，超出末页返回空数组。保留原显示去重及数组响应，不伪造总数。
2. 列表先选取当前页，再批量查询诊断摘要、复习、掌握度、缩略图和任务。测试1题与8题均为7次SELECT，避免原先逐题重复请求。为保持原显示去重规则，基础题目仍读出本人匹配记录后去重分页，尚非大数据量下的数据库游标分页。
3. 手动录题、PATCH编辑、draft及confirm支持可选correct_answer、explanation、source_info。使用既有problem_analyses、reference_steps和raw_result，标记manual_reference=true、verified=false。仅保存人工资料，不调用解题或诊断模型。详情按需增加reference_information，旧题未使用该功能时不增加此字段。
4. 正文、参考资料或图片变化前，将原分析、诊断、证据、参考步骤及题目/图片元信息存入既有agent_runs.result，agent_name=question_revision。详情按需返回reference_history。旧派生结果随后按原规则失效，学习会话、任务和复习记录保留，待复习计划取消，并标记题目已变化。
5. 新增已有题目补图与换图接口，支持规范化JPEG、原始字节保留、同题同图重复请求复用。换图将旧资产标记历史角色，保留文件和旧OCR记录；可先裁剪或直接创建识别任务。
6. 支持人工编辑状态，拒绝直接写running等任务内部状态。编辑参考资料、正文、状态及图片会取消旧识别任务，写回前仍校验指纹，避免旧结果覆盖人工修改。
7. 增加CUOTI_COMPUTE_TIMEOUT配置，默认200秒。实际超时记为任务失败，返回可重试原因；保持原pending/running/completed/failed/cancelled持久化状态、两线程及自有任务恢复机制。
8. 沿用原签名文件协议；显式携带Bearer访问时，额外检查本人题目或报告归属。归档不删除图片文件，失败事务清理尚未提交的新文件。

## API与兼容性

本阶段错题、任务及媒体共14条路径、18个HTTP方法路径组合。

| 方法 | 路径（业务接口前缀/api/v1） | 内容 |
|---|---|---|
| GET | /questions | 列表、组合筛选、搜索、排序、可选分页 |
| POST | /questions/manual | 手动录题、已有练习快照转入、人工参考资料 |
| POST | /questions/ingest | multipart单图上传，defer_processing可选 |
| GET、PATCH、DELETE | /questions/{id} | 详情、编辑、归档 |
| POST | /questions/{id}/images | 本轮新增；multipart补图，replace=true换主图 |
| POST | /questions/{id}/crop | 裁剪并识别，原图保留 |
| POST | /questions/{id}/ocr | 原同步识别入口，活动任务复用 |
| POST | /questions/{id}/reprocess | 异步重新处理 |
| POST | /questions/{id}/draft | 保存人工修订 |
| POST | /questions/{id}/confirm | 人工确认并保存 |
| GET | /jobs/{id} | 本人任务状态、进度、错误与时间 |
| POST | /jobs/{id}/retry | 失败重试和活动任务复用 |
| GET、HEAD | /uploads/{path}（无业务前缀） | 签名图片读取、下载、Range、ETag |
| GET、HEAD | /reports/{path}（无业务前缀） | 既有报告读取；本轮未迁移报告生成 |

默认字段、状态码和错误结构沿原协议。新扩展字段及images入口不要求原前端立即使用。原上传仍一次创建一道题，未虚构原系统不具备的批量上传接口；对同题补图做幂等，列表仍按原规则显示去重。

对运行中的仓颉服务进行了真实HTTP对照：比较完整新建题目详情、列表业务数据、收藏标签编辑结果、归档结果及跨用户404错误内容。仅规范化时间格式和签名URL易变参数，未仅比较200。另读取既有历史题目，与原服务核对字段集合、题文、答案、选项、知识点和状态。该对照不等于对全部旧路由进行穷举双写测试。
