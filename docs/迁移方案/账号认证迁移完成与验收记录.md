ORM只映射本阶段使用的users与student_profiles。未执行create_all、Alembic upgrade/stamp或任何DDL。MySQL仍为唯一业务数据库，其他59张本地历史表及已有资料保持兼容保留。

原生加密通过Python标准库替代。PBKDF2-HMAC-SHA256固定210000次、16字节盐和32字节结果，保持带填充URL-safe Base64哈希格式。令牌为payload.signature两段，保留sub/exp/credential字段及原HMAC规则。后端读取原密钥，不在新启动时生成替代密钥。未配置有效认证密钥时账号API返回503，不签发空密钥令牌。

使用Pydantic模型处理请求字段并生成公开用户输出，保留原来的字段宽松/严格区别。JSON请求上限64KiB，成功响应仍为success/data/error/request_id，业务错误使用中文detail。多方法路径的405 Allow合并保留所有允许方法。

## 运行与配置

沿用上一阶段安装命令，现有算法包和新业务包一起安装。新服务默认8003，前端继续使用原地址。

```bash
.venv/bin/python -m pip install -e './backend-algorithms[dev]' -e './backend-python[dev]'
CUOTI_ENV_FILE=/绝对路径/.env.cangjie .venv/bin/python -m cuoti_backend
```

配置优先级为CUOTI_*环境变量、同名配置文件值、旧CANGJIE_*配置。认证与算法密钥还可以从配置文件所在目录的.runtime/cangjie-auth-secret和cangjie-algorithm-secret读取。真实密钥不会输出或提交。算法池路径复用CANGJIE_API_POOL_PATH/CUOTI_API_POOL_PATH。

本地管理员命令提供--email、--name和--check。不带--check时使用getpass两次输入密码，至少12个字符，禁止换行。命令检查009_task_sources版本，仅创建admin，不自动升级或初始化数据库。
