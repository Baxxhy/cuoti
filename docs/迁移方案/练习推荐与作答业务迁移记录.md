# 练习推荐与作答业务迁移记录

日期：2026-11-17；版本：v1.0。

源码依据：`practice_recommend.cj`、`practice_attempt.cj`、`practice_generated.cj`，并沿用已迁移的来源校验、检索准备、原判题和认知计算。

已接入以下原路径，前端调用和请求字段保持不变：

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| POST | `/api/v1/practice/recommend` | 按错题、模式推荐题库题，复用缓存，必要时生成经过核验的练习 |
| POST | `/api/v1/practice/attempt` | 提交题库或生成式练习，返回判题、答案解析和学习写回结果 |

保留 `reinforce`、`variation`、`debug`、`force_new`。推荐检查题目归属、年级、学科、自动判分资格、目标知识点和匹配凭据；缓存失效则重新匹配。检索无有效结果、目标不明确或服务不可用时，调用原 `generate_practice`，只有通过原算法核验的内容才保存；已有有效练习可作为回退。生成期间原题、分析或诊断变化则拒绝保存。

题库作答要求该题已推荐给当前学生，提交前重查来源、目标、资格和匹配凭据。有效判题才保存正式练习记录，首次独立作答才写回掌握度。相同答案重试返回原回执并更新媒体链接；已完成的题库题更换答案返回 409。待核对结果保留答案已展示的事实，后续不能当作未见答案的独立证据。

生成式练习绑定原题版本，缓存携带上次作答与回执。相同有效答案重放不新增记录；更换答案可以继续练习，但已看过答案或已有练习记录时不再增加掌握度。复用原认知算法，不重新实现评分、检索或生成。手写关联校验复用原逻辑并扩展 `practice` 路径；通用手写上传接口仍待迁移。

MySQL 集成验证包含：新题库推荐保存、推荐缓存、作答回执、重复提交不新增证据、更换已完成答案拒绝、生成式推荐缓存、跨账号访问、无效模式与时长、生成式重复练习不重复写回、未通过核验时回退旧题、生成期间题目变化及旧题拒绝。

测试中的检索排名、匹配结果、部分目标准备和生成响应采用受控数据，实际规则判题、认知写回及数据库事务使用原实现。另通过未模拟算法的 `generate_practice` 实际调用，得到 `sympy_checked_practice` 来源并验证数据库缓存。该线性方程案例命中原有 SymPy 分支，没有证明模型生成成功，不计作真实模型出题验收。

尚需验证真实 BGE/Qdrant 检索和模型生成的完整练习流程、通用手写上传，以及其余复习、学习卷、可视化、导出、语音、管理和部署迁移。没有变更数据库结构、前端地址或旧服务。

验证结果：启用本地 MySQL、旧服务对照及原算法生成用例的后端全量回归 124 passed、13 skipped（47.65 秒）。推荐和作答针对性测试 2 passed（4.92 秒）；未模拟算法的生成入口测试初轮 1 passed（3.51 秒）。Ruff、格式和 Git diff 检查通过，保留既有 Starlette/httpx 弃用提示。
