# 可视化与认知统计迁移记录

日期：2026-11-17；版本：v1.0。

依据：`visualizations.cj`、`cognition_graph.cj`，以及 `student_experience.cj` 的 `studentErrorSources`。核对前端互动演示、认知图谱和错因地图的实际请求。

已接入：

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/api/v1/visualizations/types` | 原演示目录 |
| GET、POST | `/api/v1/tutor/sessions/{session_id}/visualization` | 获取当前图示配置、保存参数与观察 |
| GET | `/api/v1/visualizations/{visualization_id}` | 读取本人历史图示与交互记录 |
| GET | `/api/v1/analytics/cognition-graph` | 按时间和学科展示已有掌握、错因、错题、策略及证据连线 |
| GET | `/api/v1/analytics/error-sources` | 当前错因来源及到期复习入口 |

图示配置继续调用已有 `visualization_config`，由原 Pydantic 模型验证；仅返回 JSON，不生成或执行前端 JavaScript。保存观察时写入原交互表及审计记录，不把观察文本直接当作掌握证据。写入前检查会话归属、原题变化和归档；历史记录继续可读。

认知图谱沿用四类节点、显示数量上限、值排序、错因名称与学习策略文案。仅从当前账号已有认知记录、错题知识映射及知识关系构建，问题节点排除归档及重复问题，计数沿用原定义。节点数上限分别为知识 8、问题 4、错因 2、策略 2；保留原显示权重及连线规则，不新增分数或修改认知状态。

错因来源只读最近诊断，默认 90 天、最多 365 天，最多扫描 200 条并标记截断；保留题目去重与中国本地日界限的到期复习入口。图谱日期范围沿用最多 3650 天。

MySQL 验证：图示目录和匹配、参数保存、观察与审计、历史读取、跨账号拒绝、无效参数及原题变化后拒绝写入；使用原认知算法生成实际学习证据，验证四类图谱节点、知识映射、连线、学科筛选、日期限制和错因来源。没有模拟图示配置或认知计算结果。

同数据旧服务对照通过：图示目录、当前会话配置、历史图示及交互、认知图谱、错因来源。图谱节点与连线作为无序集合比较，保留实际显示数量与节点值检查。测试中的操作没有额外写入掌握度。

没有修改数据库结构、前端页面或旧服务。剩余迁移包括导出组卷、语音、管理与系统接口，以及最终统一部署和移除仓颉运行依赖；更多真实题型的交互质量仍需结合后续系统验收。

验证结果：启用本地 MySQL 和旧服务对照的后端全量回归 133 passed、15 skipped（60.84 秒）；本批图示及认知统计针对性测试 2 passed（5.14 秒）。Ruff、格式和 Git diff 检查通过，保留既有 Starlette/httpx 弃用提示。
