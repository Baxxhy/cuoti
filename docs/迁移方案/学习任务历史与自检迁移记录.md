# 学习任务历史与自检迁移记录

日期：2026-11-17；版本：v1.0。

源码依据：`backend-cangjie/src/learning_task_records.cj` 的 `learningSelfCheck`、`learningTaskHistory`，以及 `learning_task_sources.cj` 的 `taskSourcePublic`。

新增接口：

| 方法 | 路径 | 已迁移行为 |
| --- | --- | --- |
| GET、PATCH、DELETE | `/api/v1/learning-tasks/{id}/self-check` | 查看、确认保存、修改和删除本人自检要点 |
| GET | `/api/v1/learning-tasks/{id}/history` | 最近 50 次动作与是否存在更多记录、原题来源快照 |

自检沿用 `learning_self_checks`，仅当前来源且已完成任务可保存，要求学生明确确认。版本须为非负整数，修改冲突返回 409；同一句重复保存和重复删除保持幂等。每次实际修改留下 `student_self_check` 审计。自检标记为 `student_self_report`，不直接写入掌握度或错因状态。

原题变化后，旧要点仍可读取和删除，不能继续覆盖成当前版本的学习证明。历史接口只返回公开反馈、提交文本、作答阶段与结论、援助标记、来源和必要的图示摘要，不返回完整内部检查点。照片路径按原任务及来源版本查找并签名；来源快照只公开原题学科、年级、正文和选项。全部接口要求学生账号且任务属于本人。

本地 MySQL 测试覆盖：未完成拒绝保存、明确确认、版本冲突、重复保存和删除、编辑、恢复已删除要点、跨用户拒绝、原题修改后的历史保留与禁止保存，以及 51 条以上历史的 50 条上限。另验证私有检查点字段不会出现在历史响应中。测试使用临时账号和模拟准备状态，不调用真实模型；审计及测试记录按任务清理。

尚未完成：任务手写照片上传入口、题目学习旅程汇总 `addTaskJourney`、真实模型完整任务验收、前端切换、其他业务和部署中的仓颉依赖移除。本次没有修改数据库结构、原图或前端。

验证结果：启用本地 MySQL 与旧服务对照的后端全量回归 113 passed、12 skipped（39.83 秒）；相关 MySQL 接口测试 1 passed（4.42 秒）。Ruff、格式检查及 Git diff 检查通过；保留既有 Starlette/httpx 弃用提示。
