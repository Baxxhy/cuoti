# 教学答题认知与完成业务迁移记录

日期：2026-11-17。版本：v1。起点：d92312f。

## 已迁移

POST /api/v1/tutor/sessions/{id}/activity/answer与POST /api/v1/tutor/sessions/{id}/finish已接入Python。

参照tutor_answer、tutor_transfer、tutor_completion、tutor_finish、learning_evidence、learning_memory_sources和handwriting的具体实现，完成：

- 按本人会话、当前阶段及activity_id验证提交，拒绝陈旧活动、变更/归档题目及已完成会话。
- 理解活动、简短答案展示、针对性检查、讲清评估及辅助确认的状态推进。评分键只用于服务端判断，沿用既有公开活动投影。
- 近/远迁移答题评分、variant_attempts保存、失败次数、补救确认及后续练习；求助提供步骤提示但不消耗作答次数。评分can_update_learning不为true时不计尝试、不改变掌握情况。
- 完成时复用cognition_update计算，保存mastery_states、misconception_states和两类cognitive_updates，附带学习证据及来源版本。
- 未稳定安排1天复习；需要辅助安排3天；无辅助正常完成安排15天。辅助推进不等于通过，不伪造far_transfer或mastery_proven。
- completed会话重复finish复用已有复习，不重复更新认知或创建计划。保存与会话状态在同一事务，按会话行锁控制重复完成；按本人用户锁串行更新同一人的掌握记录。
- 迁移手写提交元数据验证：缺原图拒绝识别结果，图片必须属于本用户、本会话的合法路径并实际存在，复用validate_handwriting结构校验。本批未迁移上传手写原图入口。

learning_evidence.py负责业务读写与证据来源，tutor_answers.py负责活动和完成接口。评分及认知算术继续通过现有ComputeBridge调用原算法，没有新建重复算法或数据库表。

保留learning-memory-v1形状：题目核心字段、最新作答、学生步骤、题图、分析、参考步骤及原空扩展位。导入元数据和认知更新本身不被错误混入题目版本。dataset_version继续按现有数据集记录生成。
