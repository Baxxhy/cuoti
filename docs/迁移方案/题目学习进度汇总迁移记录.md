# 题目学习进度汇总迁移记录

日期：2026-11-17；版本：v1.0。

依据：`backend-cangjie/src/learning_journey.cj` 的 `learningJourney`、`buildLearningJourney`，及 `learning_task_records.cj` 的 `addTaskJourney`。

已接入 `GET /api/v1/questions/{question_id}/journey`，读取本人未归档题目的识别、诊断、辅导、题库练习、复习和学习任务记录，保持原字段、阶段名称、导航目标与事件展示文字。不新增评分算法，不把自检声明、辅助作答或过期记录当作当前掌握证据。

汇总包括：题目确认、诊断、理解与教回、独立迁移、间隔复习五个阶段；练习作答及有效判定数量；复习完成、到期数量和下次时间；任务订正、独立作答和近迁移状态；学生自检及来源是否有效；下一步操作。沿用中国本地日界限统计到期复习。各类查询最多 50 条，事件按时间倒序保留 30 条，相同时间维持来源顺序。

有可继续的当前学习任务时，优先回到保存的任务步骤；需要框选、识别或核对时仍保留前置操作。题目变化时将旧任务标记过期，历史事件和旧自检继续保留，但不计入当前进度。归档题目和其他用户请求返回 404。

验证：MySQL 临时账号创建错题、任务与自检，核对汇总、下一步导航、题目变化和归档行为。对同一份记录请求现有仓颉服务，与 Python 完整响应逐字段比较，仅排除实时 `generated_at`，结果一致。单元测试覆盖提示后练习与过期成绩排除、待判定复习不计完成、中国次日日界限、导航优先级、事件上限与同时间稳定排序。

本次没有改变数据库结构、前端地址或旧服务。任务照片、历史、自检、执行器及进度汇总现已分别接入 Python，但持续执行器仍默认关闭；完整真实模型闭环验收及其他业务、部署和仓颉运行依赖迁移仍待完成。

验证结果：启用本地 MySQL 与旧服务对照的后端全量回归 117 passed、12 skipped（42.87 秒）；补充活动任务导航后，汇总单元及 MySQL 对照测试 3 passed（3.98 秒）。Ruff、格式及 Git diff 检查通过，保留既有 Starlette/httpx 弃用提示。
