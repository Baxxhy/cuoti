# 知识库与学习概览迁移记录

日期：2026-11-17。版本：v1。起点：69ace68。

## 已迁移接口

| 方法 | 路径 | 原实现与行为 |
|---|---|---|
| GET | /api/v1/knowledge/cards | learning_insights.cj的knowledgeCards：公开知识库，按subject、grade、misconception筛选；q用Unicode空白、中文逗号和顿号拆词，保留长度至少2的前5词，按原OR条件检索，最多50项 |
| GET | /api/v1/knowledge/cards/{code} | readKnowledgeCard：支持code或id，返回前置与后续知识，沿用原关联方向和404 |
| GET | /api/v1/knowledge/framework | personal_learning.cj的personalKnowledgeFramework：本人非归档错题关联数、本人掌握状态、全部知识节点及前置关系，沿用资料默认学科与年级 |
| GET | /api/v1/dashboard | dashboard.cj：原显示去重计数、北京时间复习截止日、掌握点、错误原因、连续录题天数、有效继续学习入口与建议 |
| GET | /api/v1/analytics/overview | learning_insights.cj的learningAnalytics：本人掌握状态、规范化错误原因、学习方法名称、滚动UTC趋势与证据计数；days为1至365 |

实现集中在insights.py。SQL条件及JSON结构沿用实际仓颉逻辑。卡片接口原本公开，个人框架、首页与统计必须认证。没有新增虚构学习记录，没有调用模型生成页面数据。weekly_questions沿用旧接口的本人非归档显示去重总数，没有擅自改成最近七天。

接入FastAPI并补齐方法错误Allow收集，将诊断和新概览路由纳入405响应。
