# 诊断与作答迁移补全记录

日期：2026-11-17。版本：v1。开发基线：00167a6。

## 实际改动

- POST /api/v1/questions/{id}/student-work：迁移student_work_api.cj。校验answer、explanation与最多100个文字步骤；锁定本人题目，拒绝归档题目，保存新的student_works/student_steps。取消旧识别任务，失效派生诊断并保留现有历史快照，不删除旧作答。
- PATCH /api/v1/questions/{id}/diagnosis：迁移diagnosis_edit.cj。沿用原错误类型白名单，校验首错非负整数、置信度、文字和前置知识。首错序号必须属于当前作答，首错文字由该步骤填写。exact/equivalent不允许同时指定首错。记录user_confirmed及correction，保留原诊断证据；读取时沿用已有反事实过期证据降级。
- POST /api/v1/questions/{id}/diagnosis/counterfactual：已有缓存直接复用安全读取结果；缺缓存时调用原counterfactual计算入口，计算后比较快照，保存验证证据。该入口没有重新实现数学算法。
- knowledge_mapping.sync_links：迁移knowledge_links.cj的确定性知识映射，沿用标签清洗、精确/包含匹配、同分最长名称、primary优先与唯一键更新规则。分析、诊断及独立反事实写回接入关联同步。错误类型常量来自原diagnosis_edit.cj，打包为JSON资源，不依赖仓颉源目录运行。
