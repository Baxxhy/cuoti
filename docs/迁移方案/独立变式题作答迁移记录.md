# 独立变式题作答迁移记录

日期：2026-11-17；版本：v1.0。

源码依据：`backend-cangjie/src/variant_attempt.cj` 的 `variantAttempt`。该接口与教学活动答题接口存在阶段推进和响应差异，本次保留其真实行为，复用已迁移的变式生成、原判题算法与教学完成写回能力。

新增 `POST /api/v1/variants/{variant_id}/attempt`，接受 `answer`、`elapsed_seconds` 和可选 `hint_level`。沿用文字长度、数值范围及小数截断行为。验证变式所属会话归当前账号所有、当前教学阶段与变式一致、题目和练习没有变化或归档。

判题不具备有效学习证据时，返回 `attempt=null`、`correct=null`，记录“待核对”对话，但不增加作答次数或更新掌握度。确定性判题时保存原 `variant_attempts`，近迁移答对进入远迁移，近迁移两次答错保留讲解与确认活动。远迁移答对或两次答错结束本轮，复用原认知计算、审计和复习安排；不稳定时安排近期复习。

响应保持 `attempt`、`correct`、`branch`、`stage`、`feedback`、`grading`、`mastery` 和 `misconception`。没有增加前端字段要求、改动数据库结构或重写算法。

本地 MySQL 测试覆盖本人及他人权限、无效时长和提示等级、待判定不消耗次数、近迁移通过、旧阶段拒绝、远迁移完成、认知和复习写回、双向对话记录、近迁移两次失败补救、远迁移不稳定时结束与一天后复习，以及原题修改后的提交拒绝。实际规则判题和认知计算使用现有算法；待判定响应和远迁移题生成入口在该测试中模拟，使用预置变式避免不必要的模型调用，不宣称本次完成真实模型出题验收。

下一步继续迁移题库练习、复习、学习卷等剩余业务，并补齐其他接口、统一部署和仓颉运行依赖移除。照片真实模型任务验收仍未完成。

验证结果：启用本地 MySQL 和旧服务对照的后端全量回归 119 passed、13 skipped（44.74 秒）；新增接口初轮针对性测试 1 passed（3.76 秒），其后补充的远迁移失败分支纳入上述全量回归。Ruff、格式及 Git diff 检查通过，保留既有 Starlette/httpx 弃用提示。
