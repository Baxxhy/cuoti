# 学习任务接口与执行器接入记录

日期：2026-11-17；版本：v1.0。

依据：`learning_tasks.cj`、`learning_task_visuals.cj`、`learning_task_images.cj`，以及前端 `utils/task-entry.js`、`pages/task/task.vue` 中真实调用。

已接入以下 Python 路由，原路径保持不变：

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/api/v1/learning-tasks` | 当前学生最近 50 条任务，可按题目筛选 |
| POST | `/api/v1/learning-tasks` | 202；创建或复用当前任务，按请求编号防重复 |
| GET | `/api/v1/learning-tasks/{id}` | 查看任务，复核来源变化并将旧任务标记过期 |
| POST | `/api/v1/learning-tasks/{id}/actions` | 202；提交回答、提示、继续、查看答案、文字及可视化操作 |
| POST | `/api/v1/learning-tasks/{id}/cancel` | 取消未结束任务，保留记录 |

沿用学生角色限制、本人数据隔离、来源指纹、步骤标识和整数版本校验。相同请求编号不可更换题目或提交内容。创建要求已确认且已有分析答案；可关联本人同题教学会话。手写确认只接受当前任务版本和当前确认步骤的识别结果。可视化参数沿用键名、数量、范围、步长及阶段检查。公开视图仅暴露原有字段，并为图片签名；达到运行上限时要求重开。

应用生命周期已接入单线程持续轮询器，使用 MySQL 租约协调多个进程，退出时等待当前执行结束，再关闭算法桥接和数据库。迁移期间默认关闭，启用方式为设置 `CUOTI_LEARNING_TASK_WORKER_ENABLED=true` 后启动 Python 后端。未启用时，Python 创建的任务需要现有旧执行器处理；本次未变更旧服务或前端地址。后续独立运行验收必须显式启用，最终统一部署时会同步调整默认配置和启动说明。

本地 MySQL 接口测试覆盖创建条件、请求冲突、列表、详情、跨用户访问、整数版本校验、重复动作、过期提交和幂等取消。测试在事务内模拟准备完成，避免旧执行器领取测试队列或触发真实模型；不能作为真实学习闭环证明。另有可视化参数单元测试、轮询正常停止及应用生命周期启停验证。

未完成：`handwriting` 上传、`history`、`self-check` 及题目学习进度汇总接口；完整真实模型学习任务验收；前端切换与仓颉依赖移除。前端仍有这些调用，本次不能视为整个学习任务页面已迁移完成。

验证结果：本次 MySQL 后端全量回归 112 passed、12 skipped（40.06 秒）；补充生命周期测试及文字字段兼容调整后，相关接口与执行器测试 5 passed（3.36 秒）。Ruff、格式及 Git diff 检查通过；保留一条既有 Starlette/httpx 弃用提示。
