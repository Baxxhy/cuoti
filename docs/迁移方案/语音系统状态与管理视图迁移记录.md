# 语音系统状态与管理视图迁移记录

日期：2026-11-17；版本：v1.0。

依据：`voice_api.cj`、`system_api.cj`、`admin_api.cj`、`admin_trace.cj`。继续复用现有 Python 语音计算和 API 池状态能力，不重写语音模型或增加本地模型下载。

已迁移接口：

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| POST | `/api/v1/voice/transcribe` | 上传原音频、转写、保存语音记录，按原逻辑回填关联作答解释 |
| POST | `/api/v1/voice/synthesize` | 校验并保存合成音频，返回签名链接 |
| GET | `/api/v1/system/health` | MySQL 和算法提供方状态 |
| GET | `/api/v1/system/providers` | 原提供方轮询及可用状态 |
| POST | `/api/v1/system/providers/probe` | 原提供方探测入口 |
| GET | `/api/v1/system/voice` | 原语音提供方状态 |
| GET | `/api/v1/admin/workbench` | 管理员总体只读概览 |
| GET | `/api/v1/admin/students/{student_id}` | 学生学习摘要 |
| GET | `/api/v1/admin/sessions/{session_id}` | 会话、对话、工具调用与认知更新追踪 |

语音沿用题目和作答归属校验、允许的音频后缀、15 MB 上传限制、可编辑转写结果和原文件保存。转写失败保存失败记录及原音频，返回清理过的错误；不会把提供方错误详情暴露给用户。合成结果检查非空、大小和 SHA-256，保存记录失败时删除本次新合成文件。媒体访问增加本人语音记录检查，支持现有签名和携带账号的读取。

系统接口保留原读取和探测权限；提供方状态不新增原始凭据字段。管理接口仅管理员可访问，学生摘要不返回密码或邮箱字段，会话追踪递归移除凭据、内部提示词与推理内容字段，保留原中文决策标签和时间格式。

MySQL 测试覆盖：本人及他人音频上下文、空音频、转写回填、签名音频读取、合成结果校验、合成保存失败清理、转写失败保留文件及失败记录。使用模拟语音提供方调用原 `voice_compute`，不把模拟音频文件当作真实播放、转写质量或真实语音服务验收。

系统测试读取实际配置的状态，探测响应用模拟探测方法，未主动进行全池网络探测。健康状态字段集合与旧服务一致。管理测试使用临时管理员和学生，验证访问拒绝、字段投影、嵌套脱敏和不存在记录；同数据学生摘要与会话追踪与旧服务完全一致。工作台验证结构及访问权限，未宣称其随时变化的全局计数完全一致。

本次不改数据库结构、前端页面或旧服务。剩余工作包括导出组卷、真实语音服务验证、统一部署，以及移除仓颉 SDK、编译产物与运行时依赖。

验证结果：启用本地 MySQL 和旧服务对照的后端全量回归 136 passed、15 skipped（64.20 秒）。语音及系统针对性测试初轮 2 passed（4.08 秒），管理员与旧服务对照测试 1 passed（3.97 秒）；后续音频校验和失败清理用例已纳入全量回归。Ruff、格式和 Git diff 检查通过，保留既有 Starlette/httpx 弃用提示。
