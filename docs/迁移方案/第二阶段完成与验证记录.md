## 安装与启动

在仓库根目录使用现有Python 3.11+虚拟环境，或先创建.venv。以下命令安装两份现有包及测试依赖。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e './backend-algorithms[dev]' -e './backend-python[dev]'
.venv/bin/python -m cuoti_backend
```

默认读取仓库根目录.env.cangjie，沿用CANGJIE_DB_HOST/PORT/NAME/USER/PASSWORD。需要复用其他位置的本地配置时使用CUOTI_ENV_FILE。CUOTI_DB_*优先于旧变量，CUOTI_HOST、CUOTI_PORT和CUOTI_LOG_LEVEL控制新服务。

```bash
CUOTI_ENV_FILE=/绝对路径/.env.cangjie CUOTI_PORT=8003 .venv/bin/python -m cuoti_backend
```

不要将真实.env或密码加入Git。配置文件由python-dotenv解析，不执行其中的Shell命令。
