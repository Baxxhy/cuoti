# 第四阶段诊断业务接入进度

日期2026-11-16，版本v1。基线4d6ae8a。本文件是阶段进度记录，不是完整验收报告。

## 已实现

- POST /api/v1/questions/{id}/analyze：检查本人题目、人工确认和非空题文，读取实际作答、步骤、参考资料及图片，经既有ComputeBridge调用analyze。Pydantic校验输出，在事务中写problem_analyses/reference_steps，更新analyzed。
- POST /api/v1/questions/{id}/diagnose：缺分析先分析；调用既有diagnose，写diagnoses和三类diagnosis_evidence，保存步骤对齐、反事实与证据评估，更新diagnosed。
- GET /api/v1/questions/{id}/diagnosis：复用详情读取及历史反事实可信状态降级规则。
- GET /api/v1/questions/{id}/diagnosis/history：新增扩展接口，读取现存诊断及逐项证据；编辑前被归档到agent_runs的历史仍通过详情reference_history读取。
- 算法在事务外执行，写回时锁定本人题目并比较完整快照；分析/作答/图片等变化后拒绝旧结果。证据中的参考步骤及学生步骤ID必须属于当前快照，否则事务回滚。
- 再分析沿用现有invalidate及历史快照；重新诊断新增记录，保留旧诊断。未修改算法实现、前端、仓颉或数据库结构。
