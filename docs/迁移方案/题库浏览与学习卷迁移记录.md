# 题库浏览与学习卷迁移记录

日期：2026-11-17；版本：v1.0。

依据：`backend-cangjie/src/study_bank.cj`、`adaptive_practice.cj`，并复用已有判题、自适应选题、题目图片与任务来源校验。

已接入：

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/api/v1/study-bank` | 按个人年级、学科、来源、关键词筛选，固定种子的跨学科分页 |
| GET、POST | `/api/v1/study-sessions` | 本人学习卷列表，创建练习或限时模拟考试 |
| GET、PATCH | `/api/v1/study-sessions/{session_id}` | 查看、恢复与保存整卷作答 |
| POST | `/api/v1/study-sessions/{session_id}/submit` | 交卷判分、保存结果和重复读取 |

保留具体年级设置要求、初中年级别名和明显超纲数学排除规则。题库列表每页 20 条，跨学科按种子稳定打散，避免单一学科占满全部结果。保留分面与来源计数；未提交学习卷只返回题目公开投影，不露出答案和解析。SQL 保留筛选和排序语义，省略旧实现的强制索引提示，不增加或修改索引。

组卷支持原随机、自适应、指定单题和已完成学习任务推荐入口。自适应选题复用原算法，候选最多 200 条，使用本人最近有效作答观察，验证返回编号归属和数量。学生升年级后，已完成任务的推荐仍按原错题学习上下文验证，避免直接按新年级拒绝旧题。

作答保存要求整数版本、整卷题目集合一致及选项不重复；提交后拒绝修改，考试到时拒绝继续保存但允许交卷。题目内容以组卷快照保留；格式待核对或被列入停用历史的版本不计分。判分在事务外执行，每批最多并行 4 题、每题算法调用最多 20 秒；保存结果前重查版本及题目可用性，避免覆盖新作答。成绩沿用每题 5 分，停用题目从满分中排除。重复交卷返回已有结果，不额外写认知或伪造错题。

MySQL 测试覆盖：年级限制、别名、超纲排除、种子分页稳定及无重复、答案投影、本人隔离、作答版本冲突、正常判分与重复交卷、自适应选题、超时拒绝改卷、停用题排除、判分期间新作答阻止旧结果保存，以及任务推荐保留原年级上下文。使用原数学规则判题与自适应算法，不模拟这些算法结果。

旧服务对照：同一题库范围、种子与分页结果一致，分面和来源作为无序集合比较；同一份已提交学习卷的完整详情与旧服务一致。测试仅使用临时题库及临时学生账号，结束后清理，没有修改现有学生资料、数据库结构、前端地址或旧服务。

后续仍需迁移可视化、通用手写上传、导出组卷、语音、管理与系统配置等剩余接口，并统一部署、移除仓颉运行依赖。当前学习卷用例主要为规则可判分题目，不代表全部模型主观判题场景均已验收。

验证结果：启用本地 MySQL 和旧服务对照的后端全量回归 130 passed、14 skipped（59.80 秒）。补齐输入校验兼容文案后的学习卷测试 4 passed（10.54 秒）。Ruff、格式及 Git diff 检查通过，保留既有 Starlette/httpx 弃用提示。
