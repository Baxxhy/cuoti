# 学习任务真实模型闭环验收记录

日期：2026-11-17；版本：v1.0。

本轮在已迁移的真实 Python 算法、LangGraph、API 池和本地 MySQL 上验证文本学习任务。没有使用模拟模型响应。临时学生账号手动录入“解方程3x+2=17”，通过 FastAPI 创建任务，由 Python 后台轮询器执行，然后依次请求提示、提交原题答案、独立回答单条件对照题，最终任务完成并写入学习证据。

实际验证：

- 真实模型结构化调用成功 3 次；测试明确要求至少一次模型返回成功，规则回退本身不能冒充模型验收。
- 任务完成且 `learning_applied=true`；保存两条掌握度更新，原题记录 `hint_used=true`，对照题记录 `hint_used=false`。
- 复习计划、三条动作历史、来源快照及学习进度汇总均可读取。
- 测试中的对照答案取自服务端符号验证结果作为测试标准答案，不通过学生接口公开答案。
- 临时账号、任务、曝光、审计和认知记录在测试后清理，不修改现有学生资料或表结构。

迁移期间旧执行器仍在运行。为避免它领取测试任务，测试仅调整测试任务的排队可见状态，并将 Python 轮询选择范围限定为本次任务；租约领取、来源复核、模型调用、数据库保存和后续处理使用真实实现。此设计验证了 Python 执行链，不能据此宣称所有并发、题型或部署场景均已通过。

新增可重复执行的 opt-in 测试：`test_real_learning_task_workflow_roundtrip`。在项目 Python 环境及本地开发配置就绪后，设置 `CUOTI_TEST_MYSQL=1`、`CUOTI_TEST_REAL_TASK=1`，运行 `python -m pytest backend-python/tests/test_questions_mysql.py::test_real_learning_task_workflow_roundtrip -q -s`，并配置 `PYTHONPATH=backend-python:backend-algorithms`。普通回归不默认调用真实模型。

单独真实后台执行验收：1 passed，15.63 秒。补充历史、进度及提示证据校验后的全量回归：118 passed、12 skipped，57.66 秒，包含真实任务与已有旧服务对照用例。

同时检查 OpenAPI，发现同一函数同时注册多个 HTTP 方法时生成重复操作编号。已将自检和媒体 GET/HEAD 分别注册，保持路径和行为，新增完整 OpenAPI 操作编号唯一性检查。相关基础与媒体测试 19 passed；修改注册方式后的 MySQL 自检及图片链路测试 2 passed（5.28 秒）。Ruff、格式和 Git diff 检查通过；保留既有 Starlette/httpx 弃用提示。

仍需完成：真实模型手写照片任务验收、更多题型及失败路径验证；其余练习、复习、可视化、语音、管理、导出等业务迁移；统一部署与仓颉运行依赖移除。持续执行器仍通过 `CUOTI_LEARNING_TASK_WORKER_ENABLED=true` 显式启用，前端暂未切换。
