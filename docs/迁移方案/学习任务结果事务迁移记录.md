# 学习任务结果事务迁移记录

日期：2026-11-17；版本：v1.0。

依据：`learning_task_worker.cj` 的 `saveLearningTaskResult` 和 `learning_task_images.cj` 的结果保存、照片保留逻辑。

Python `task_results.save_result` 现已整合审计保存、曝光准入、旧工作流近迁移证据、LangGraph 掌握度写回、复习安排、请求应用状态、手写识别草稿及任务检查点。调用方负责锁住题目和任务、验证租约与来源，再提交或回滚事务。该函数自身不创建后台线程。

沿用既有表结构：保存后增加任务版本、更换步骤标识并释放租约；识别结果与照片确认步骤同步保存。提示、可视化和继续操作在阶段不变时保留照片，并同步更新确认步骤。照片只允许来自同一任务和来源版本，不更改或删除原图。单条件对照的学习证据仍不代表全部掌握。

验证：本地 MySQL 集成测试覆盖正常结果保存、请求状态、识别草稿、照片访问路径、确认步骤，以及检查点写入后超时的事务回滚。所有测试记录属于临时测试账号；新增照片记录和结果事务最终回滚，不写入实际图片。另覆盖提示操作后照片继续保留。结果、证据及 MySQL 集成针对性测试合计 9 passed（3.53 秒）；Ruff 和 Git diff 检查通过。

尚未完成：后台任务计算循环、公开学习任务 API 与手写上传入口尚未整合。当前测试没有证明真实模型完成整条学习任务，也没有切换前端。
