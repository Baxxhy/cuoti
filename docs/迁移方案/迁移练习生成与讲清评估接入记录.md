# 迁移练习生成与讲清评估接入记录

日期：2026-11-17。版本：v1。起点：36c8b98。

## 已接入业务

- POST /api/v1/tutor/sessions/{id}/variant：迁移tutor_variants.cj，按本人会话及near/far阶段校验，返回练习公开信息，不返回答案和参考过程。
- 近/远迁移阶段读取会话时，接入ensure_variant：原练习使用既有validate_variant重新验证；有效时复用，失效时保留旧行并记录invalidated_variant_ids，再生成新练习。不再因缺少练习直接返回上一轮的临时503。
- POST /api/v1/tutor/sessions/{id}/teach-back：迁移tutor_teach_back.cj，调用已有evaluate_teach_back算法；通过或两次未通过后进入相似题。未通过后辅助推进保留passed=false和assisted=true，不能写成已经掌握。
- 生成与评估同步保存会话、对话、agent_runs、agent_tool_calls及variant_questions，保留原阶段及审计协议。

读取retrieval.cj、tutor_variants.cj、tutor_teach_back.cj和dataset_images.cj实际实现。新增retrieval.py提供数据库快照适配，variants.py负责练习业务持久化，没有重写模型生成或数学验证算法。

## 检索与校验

沿原链路调用retrieval_prepare、retrieval_search、retrieval_rank，再将候选引用传入generate_variant。候选从现有MySQL题库读取，复核同学科、年级、可用答案、练习资格及图像占位符与文件数一致性；后续普通练习还会检查自动评分资格。附带数据集来源和知识关联，排除已经使用的检索ID及相同题文。

复用原BGE/Qdrant/重排计算模块，未另外下载或运行新模型。检索异常时沿原逻辑允许生成回退，元数据明确retrieval_status=unavailable，不能把回退说成检索成功。模型输出verified的真假原样保留，不以生成成功替代验证通过。

题目变化或归档检查提前到旧练习验证之前，即使旧候选返回valid也拒绝陈旧会话。原旧实现的缓存复验分支可能提前返回，本轮补齐这个状态保护。当前沿个人项目的同步事务与会话行锁实现，模型执行期间会持有本会话锁，未声称支持分布式调度。
