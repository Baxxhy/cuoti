# 题库图片与练习来源校验迁移记录

日期：2026-11-17；版本：v1.0。

依据：`practice_context.cj`、`practice_alignment.cj` 和 `dataset_images.cj`。本次先迁移练习接口依赖的图片和来源校验，推荐及作答主接口尚未接入。

已接入 `GET/HEAD /api/v1/practice/questions/{question_id}/images/{image_index}`。沿用媒体签名、题库根目录限制和原图片序号，复用媒体流响应处理范围请求、缓存验证与 HEAD。图片路径必须位于配置的题库目录内，文件打开拒绝符号链接和目录穿越；不移动或改写历史图片。错误保留独立 `detail` 响应，不改成业务数据包。

图片布局遵循题干、选项、答案、解析的原出现顺序。题目预览不混入答案或解析图片；标记数量与原图不符时，题目图片进入需核对状态。无标记的普通附图仍按题干附图展示。图片 URL 继续按读取时间签名。

练习来源校验已实现：

- 保持旧排序 JSON、空格和数字格式生成来源指纹，包含原题字段及学生作答修订编号。
- 分析、诊断、目标知识卡和候选题参与版本及匹配凭据校验。
- 作答必须先有本人、原错题、题库题和模式一致的推荐记录；原题变化后旧推荐被拒绝。
- 保留 `symbolic_linear` 和 `qwen_grounded_concept` 两种既有匹配凭据，不重新实现匹配算法。

抽出现有检索准备函数供教学变式与后续练习接口共用，算法输入保持原样。没有新增数据库表或重建向量索引。

本地 MySQL 与媒体测试覆盖：原图访问、签名过期、GET/HEAD、范围下载、缓存验证、越界序号、越出题库目录、来源题目变化、候选答案变化及目标知识卡变化。图片布局单元测试覆盖题干、选项、答案、解析分离及旧 JSON 指纹格式。使用临时题库记录和临时图片目录，测试结束清理关联记录。

下一步接入推荐缓存、题库筛选与匹配、生成式练习回退和作答回执，再验证避免重复增加掌握度。当前不能宣称整套题库推荐与作答流程已迁移完成。

验证结果：启用本地 MySQL 和旧服务对照的后端全量回归 122 passed、13 skipped（44.85 秒）；补齐不支持方法的媒体错误响应后，相关 MySQL、图片布局及 OpenAPI 检查 4 passed（3.74 秒）。Ruff、格式和 Git diff 检查通过，保留既有 Starlette/httpx 弃用提示。
