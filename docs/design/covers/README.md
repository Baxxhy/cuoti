# 错题帮文档封面

- 文件：`cuotibang-product-cover-v1.png`
- 用途：产品说明文档首页，A4 竖版比例。
- 设计：沿用产品蓝色 `#426fce`，以纸页、订正轨迹和知识卡表现错题学习流程。
- 生成方式：内置 imagegen 工具。
- 校对：标题、说明及底部流程文字可读；插画中的错误因式分解用于表现原始错题，后续纸页展示正确订正。
- 使用：在 Word、WPS 或排版软件中作为整页封面插入，按比例缩放；图片中文字不可直接编辑。
