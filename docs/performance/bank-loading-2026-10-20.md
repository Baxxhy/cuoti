# 题库首次加载优化

2026-10-20，本地现有 MySQL 与仓颉服务实测：题库接口优化前 5.251 秒，优化后两次分别 0.723、0.727 秒；数学筛选 0.486 秒、第二页 0.787 秒。真实浏览器从学习页点击题库到首题显示 1.409 秒。不是跨设备或公网延迟保证。

- 页面移除总题数及重复学科摘要；分页与组卷仍使用真实总量。
- 题目列表独立完成加载，不等待练习历史；筛选和翻页不再重复拉取历史。
- 增加覆盖可练条件、排序与分组字段的组合索引，列表统计显式使用该索引，避免选择低区分度布尔字段的旧索引。
- 删除列表查询中不必要的来源关联，来源统计先聚合再关联；每页来源名称一次读取，替代逐题查询。
- 精确题目查询、随机组卷和自适应候选不强制使用列表索引。

部署前运行 `bash scripts/cangjie.sh upgrade-db`，应用 `011_bank_browse_index`；迁移检查索引是否已存在，可在中断后重试。当前环境已完成迁移及服务更新。索引通过在线 ALTER 添加，未改动题目或学习记录。

验证：仓颉构建通过；真实接口默认、重复请求、数学筛选及翻页均返回 20 条，分组统计与来源统计总量一致；两次首页 ID 相同、第二页无重叠，返回内容不含答案。浏览器确认总题数不显示，打开首题耗时见上。前端针对慢历史请求、筛选不重复加载历史、隐藏总数及返回导航进行专项回归；类型检查通过。
