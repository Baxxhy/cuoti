# 多题复习切换

## 本轮计划

1. 保持一次一道题，增加上一题/下一题及准确位置；单题缺少参考或判题待核对时仍可先做其他题。
2. 切换保留每题的文字、照片引用、在途编号和主动修改状态；不发作答/评价请求，不更改完成状态。缓存不可用时至少保留当前页面内的草稿。
3. 普通入口恢复上次所看计划；指定计划的链接优先定位该题。返回/刷新重新读取实际列表，题目版本变化时仍拒绝旧草稿。
4. 作答/评价/照片识别期间禁止切题，防止把迟到结果带到其他题；结束一题后优先显示原队列的下一题。
5. 行为测试与真实仓颉浏览器核对缺参考失败→切题→返回草稿、刷新位置及缓存失效/窄屏；完整主线回归观察通过后提交。

基线：`e42e45c`的复习恢复已接入，但没有页面内选题动作，完成后始终回到首题；文字草稿依赖持久缓存，缓存失败时无法保证跨题保留。本轮不改判题算法、仓颉合同或数据库。

## 已实现

- 当前题下方显示上一题/下一题；首尾边界与忙碌状态同时提供disabled和aria-disabled，支持Enter/Space。位置有可播报说明，放大文字时计数保持一行。
- 切换只读取本次已加载的列表和每题草稿，不发判题/评价请求。题目来源变化仍由重新读取和服务端版本检查处理。
- 内存草稿按账号/计划/来源版本隔离；持久缓存失败时，本页仍能跨题保留文字和照片引用。刷新或关闭页面后，缓存不可用时无法保证恢复，页面持续提示保持打开后提交。
- 普通入口记住上次计划；指定plan的新页面入口优先该题。完成当前题后优先选择原队列下一题，未完成的题仍保留在列表。
- 既有待核对结果主动修改、回执恢复和来源版本限制保留，切题不将自述或未提交作答算成学习证据。
