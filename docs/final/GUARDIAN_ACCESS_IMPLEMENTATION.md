# 家长查看权限与报告

学生个人学习为主，家长只能读取被学生授权的报告。延续既有家长身份，不开放注册时自选教师、家长或管理员，不引入商业多租户体系。

## 操作边界

- 学生从“我的 → 家长查看权限”填写已有家长账号邮箱，确认说明后授权。页面说明可读掌握估计、错因和学习统计，不授予修改作答、判题、任务或学习记录的权限。
- 学生可随时解除；家长在“家长中心”也可解除。解除只删除当前双方的查看关联，不删除学生的学习记录，不影响教师班级关系。
- 同一学生最多5位家长；重复授权同一位不重复创建。此上限为产品策略，不是实际家庭人数判断。邮箱不是所有权凭据，授权必须使用学生已登录身份。
- 本批不开放自助创建家长身份；本地管理者使用[角色账号配置命令](LOCAL_IDENTITIES.md)创建专用家长账号。不存在的邮箱、学生/教师账号不能被当成家长关联。页面不通过邮箱自动创建账号或提升角色。

## 仓颉与MySQL合同

| 方法 | 路径 | 身份与结果 |
| --- | --- | --- |
| GET | `/api/v1/students/guardian-links` | 学生本人；只返回已授权家长的id、姓名、邮箱 |
| POST | `/api/v1/students/guardian-links` | 学生本人；`email`与严格布尔`confirmed:true`；返回当前关联的家长公开信息 |
| DELETE | `/api/v1/students/guardian-links/{guardian_id}` | 学生仅撤销自己与该家长的关联；重复解除安全返回 |
| DELETE | `/api/v1/guardians/students/{student_id}` | 家长仅撤销自己与该学生的关联；不能移除另一家长 |
| GET | `/api/v1/guardians/students/{student_id}/overview` | 沿用报告接口；每次重新检查当前关联，无权限返回403 |

复用现有`guardian_student_links`，不新增迁移，不修改旧学习记录。所有授权/解除先锁同一学生行，再操作双方关联，串行处理公开API的并发授权、限额和解除；SQL使用参数绑定。列表消除历史重复行，解除删除该双方全部重复行。身份来自当前数据库记录，客户端角色或用户ID不能授权。

当前关联保存创建/更新时间，不保存独立授权事件历史；不将这些记录混入教师审计。已经获取的报告不能通过解除操作从对方记忆、截图或外部副本中撤回。

## 页面状态

授权和解除分别有明确确认，成功反馈与失败信息；失败不显示虚假的已授权/已解除。家长卡片支持键盘进入报告，卡片与解除按钮分开，避免嵌套操作。

报告每次显示、手动刷新都重新请求并验证权限；读取前清空旧内容。离开/隐藏时清空报告并使在途响应失效；旧响应不能覆盖后来的拒绝结果。403/404显示无权查看和返回家长中心行动。当前未做服务器推送撤权，因此一直停留的已打开页面在下次刷新/重新进入前不会主动感知远端解除；不能宣称即时远程擦除。

- `scripts/smoke_cangjie_guardian_links.py`：真实MySQL/HTTP确认类型、身份、邮箱归一化、并发去重、5位上限、双方解除和无关账号隔离；随school回归执行。
- `frontend/e2e/functional-audit.spec.ts`：学生页面授权→家长读实际报告→学生取消解除/确认解除→家长刷新拒绝→重新授权→家长解除→学生刷新与权限拒绝。
- 完整命令：`CANGJIE_VERIFY_FOCUS= make verify-cangjie-browser`。使用隔离测试库随机账号，不能替代真实学生/家长试用。
