# 高中固定样本与不等式解集核验

## 本批计划

1. 预先固定三个自编课程样本：二次不等式、英语虚拟语气、生物减数分裂，明确标准答案和学生错误；区分请求成功与内容核对。通过现有仓颉HTTP和ApiPoolProvider/Qwen运行，不调用单个池条目。
2. 对实际发现的不等式首错误判，新增基于原题的有限多项式解集核验，接入分析、诊断、反事实修复与统一判题，保留仓颉/MySQL业务边界。
3. 对同一实际题重新分析诊断，再运行三个样本的持久任务与原作答保留；核对窄屏页面。全部算法与最终主线回归完成后提交。
4. 记录基线失败、支持范围与没有证明的范围，不能将三个自编题当成考试基准、真实学生试用或全学科正确率。

## 实际基线

脚本`check_live_high_school.py`在调用模型前固定题目和核对期望；报告及登录信息分别写入Git忽略的0600私有文件。不打印池信息、供应端地址或凭据。逻辑模型Qwen，实际物理模型版本未知；没有编造版本或usage；私有报告记录本批实际核对代码的SHA-256摘要，便于对应最终提交。

- 数学：`x^2-5x+6≤0`，学生先写`(x-2)(x-3)≤0`，再错写`x≤2或x≥3`。实际分析答案为`{x | 2≤x≤3}`，但未获符号验证；诊断错误地把第一步标成符号错误，实际错误在第二步。
- 英语：`If I ___ you, I would tell the truth.`，选项am/was/were/will be，学生按主语I选am。实际答案C/were，错因指出主句would与虚拟语气，实际错误步骤0与输入一致。
- 生物：体细胞2n=8，问减数第一次分裂完成后的次级精母细胞染色体数，选项4/8/16/2。学生混淆DNA复制而选8。实际答案A/4，错因指出同源染色体分离与数目减半。

首轮英语/生物手动录题因脚本使用key而非接口要求的label失败；修正字段后复用同一账号继续，未放宽业务校验或重复数学调用。基线日志`/tmp/zhiwei-high-school-actual.log`、`/tmp/zhiwei-high-school-actual-resume.log`。语义核对由本次助手对照预定课程答案完成，未进行外部教师评审或真实学生试用。

## 实现边界

- 只对明确要求“解不等式”的完整、无选择选项的独立原题做符号覆盖；一个变量、有界有理系数的一至四次多项式、一个比较关系。其他目标、额外条件、多变量、参数、变量分母、三角函数与根式定义域不提升为确定结论。
- 使用已有安全算术AST与SymPy。先检查结构次数再构建Poly，限制系数和输入大小，避免先展开高次外部表达式。不执行模型代码。
- 比较完整实数解集、端点开闭、区间/双边不等式/有限集/并集。分析答案由原题核验；不能核验的参考步骤仍标未核验。在已有模型池配置、分析调用暂不可用而原题可符号确定时，可构建规则分析；缺少模型池配置的启动边界仍沿用原合同。
- 诊断按原题比较学生数学关系，不要求学生照抄模型参考文字。边界零点、尚未作为最终答案的必要条件可作中间工作；未知叙述不当成错误，也不当成已验证正确前缀。未知前缀存在时不臆定后面某步就是最早错误。
- 反事实必须保留原正确前缀，修复后的最终解集与原题一致。局部修改不能替代完整解集核验。
- 判题只直接确认完整、单行、可解析的解集；参考答案与原题不一致则需重新分析，不产生学习更新。多行过程/未支持表达沿用原过程复核，不只抽取最后一个正确区间。
