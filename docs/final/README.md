# 当前产品与架构

唯一业务主线为仓颉/MySQL；Python仅执行内部计算，旧Python业务服务已移除。功能与安装入口以项目根目录README为准。

学生录题后先核对题干、选项、作答和图片。分析诊断保存到MySQL，订正任务保留状态、草稿、提示与学习证据；独立作答和看过答案的辅助学习分开记录。类似题优先检索题库，不足时生成并核验；模型或核验失败时可重试。复习、图谱和报告均使用学生本人的记录。

Python算法包中的`learning_core`包含实际使用的模型池、结构化输出、数学、OCR、教学与导出算法，不包含账号、ORM、业务数据库或第二套业务API。内部服务只监听本地端口并验证密钥。仓颉决定用户归属、标准答案、任务流转和数据库事务；前端不能覆盖这些规则。

原始学生资料、数据库、模型与题库图片保留。仅删除确认未使用的旧源码、脚本、历史生成物和缓存；其他Git工作树不属于本轮清理对象。

当前清理和测试结果见[实施记录](IMPLEMENTATION_STATUS.md)。
