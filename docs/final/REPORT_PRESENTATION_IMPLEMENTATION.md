# 学习报告呈现与刷新

本批依据UI_SPEC的信息预算继续完善学生、家长和教师报告，使用原仓颉/MySQL数据，未改变认知计算或报告授权。

## 修改与边界

- 学生近期学习卡展示所属学科和记录估计，并提供“查看本学科错题”行动；同名知识/错因不跨学科合并，知识记录按最新状态去重。原始错因代码用于既有搜索，中文显示不改变查询含义。
- 已解决、尚未分类的记录不列为当前重点错因；已知代码显示中文。家长报告保留“已解决与待核对记录”入口，图谱保留原节点ID、连线和历史，用“待核对的错因”表达未知分类，不把内部unclassified当作确定错因。
- 家长报告默认三项重点知识、三项当前错因，其他内容按需展开；切换报告后恢复收起。去掉大头像和“出现概率”等容易误解的表述，分数始终标为学习记录估计，不能当作独立掌握证明。
- 学生、教师每次重新进入报告会读取当前数据；离开清空已读报告，拒绝迟到响应。家长原有每次进入重验权限、离开清空及撤权处理继续复用。
- 所有改动在前端视图层；未删除数据库记录、改写原作答或新增模型调用。没有添加新的语音入口或宣称朗读恢复。
