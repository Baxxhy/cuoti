## 真实链路固定样本

使用独立 QA 账号，通过实际仓颉 API → Python → ApiPoolProvider/Qwen → MySQL 录题、分析、诊断。下表是人工逐题核对的公开自编样本，页面步骤编号从1开始；不是网上题库准确率或真人学生研究。

| 样本 | 独立预期与实际核对结果 |
| --- | --- |
| 分数方程 `x/2+1=4`，学生答6 | 答案6；两步均正确，没有虚构错误 |
| 不等式 `-2x>6`，学生写 `x>-3` | 解集 `x<-3`；第1步除负数后未变号，规则修复证明保留 |
| 无理方程 `sqrt(x+2)=x`，学生答−1或2 | 仅2；第1步平方不被误判，第2步未排除增根−1 |
| 分式方程 `(x²−1)/(x−1)=2`，学生答1 | 无解；指出约分时需保留 `x≠1`，1为增根。将第1步漏写限制定位为错误线索合理，不把约分本身误称符号错误 |
| 绝对值方程 `abs(x−1)=2`，只答3 | 解为−1或3；指出只取正分支，不能判整题正确 |
| 小数方程 `0.5x+0.2=1.7`，学生答3 | 答案3；正确路径不被判错 |
| 三角形只给A角50°，求C角 | 条件不足；不编造唯一角度，指出无依据假设B角50° |
| 72 km/h行驶10秒，学生答720m | 答案200m；第1步 `s=vt` 正确，第2步单位未统一 |
| 密闭4g氢气、32g氧气恰好完全反应 | 答案36g；指出不能只计氧气质量，使用质量守恒 |
| `She ___ to school every day`，填goes | 答案和说明正确，首错为空，不虚构语法错误 |
| 光合作用吸收/释放气体，答二氧化碳/氧气 | 答案正确，首错为空，不虚构过程错误 |
| 2红3白摸红球，学生答2/3 | 答案2/5；第1步记录球数正确，第2步分母应为总数5 |
