# 长期个人学习系统实施与验收

日期：2026-10-20。目标来源：用户要求借鉴外部设计与思想、自行实现，完善复习搜索、知识框架、遇错查知识及 AI 老师讲解，覆盖不同学习情境并逐项测试。

## 原则与参考边界

- 保留 uni-app / Vue 3、仓颉业务 / MySQL、Python 算法架构；不复制六个外部项目源码。
- 借鉴字段级核对、常用复习集合、分级提示和持续学习记录的机制。实现、接口及组件由本项目自行编写。
- 小红书指定主页无法由搜索工具读取；直接访问虽返回 200，但只有通用页面外壳，没有作者与笔记内容。未以此编造该账号内容或用户研究结论。
- 对不同用户提供可用情境：首次使用、日常整理、薄弱知识补习、间隔复习、考前专项，以及现有教师、家长、管理员流程。原生签名发行、备份恢复沿用已有延期/排除约定。
- 知识框架描述教材概念关系；学习状态只来自真实作答。查看知识、请求讲解和自述不会直接增加掌握度。

## 当前源码事实

- 复习支持真实判题、评级后安排下一次复习、按用户和来源版本保留草稿及位置，目前没有题目搜索。
- 知识卡支持搜索和单卡前置/后续关系，但缺少按章节形成的框架；题目相关知识中的前置名称目前不可点击。
- AI 老师与持久学习任务已有题目上下文、执行预算、证据判定和掌握度保护，需要完善知识查阅时的连续体验。
- 既有教师、家长、管理员及导出等功能保留，最后的全功能验收需覆盖，不能只以新增页面通过作为交付依据。

### 已实施的服务与数据

- `GET /reviews/search`：本人待复习/到期/已完成安排，搜索题干、知识点、标题及原因；20 条分页，列表不返回参考答案。
- `GET/POST /reviews/filters`、`DELETE /reviews/filters/{id}`：最多 20 个本人常用范围，相同范围重复保存不新增副本；移除范围不删除错题或学习记录。
- `GET /knowledge/framework`：全部真实知识节点和前置关系，附本人掌握记录、相关题数和学习方向默认值。没有作答证据不标已掌握。
- `GET/POST /knowledge/cards/{code}/lessons`：有界知识讲解、最近 10 条记录；最多使用最近 3 条同来源版本上下文。仓颉保存，Python 调用 Qwen 池并用 Pydantic 验证；查看或提问不写掌握度。
- MySQL 版本 `012_personal_learning` 新增讲解记录和复习范围表；没有删除或覆盖原题图片、作答、任务记录。
- 知识提要由项目自行编写，不复制外部源码或教材原文。`knowledge_explanations.json` 为编写源，`compile_knowledge_content.py` 同步导入文件；保留 250 个原编号与原关系。年级仅作检索参考，并非宣称覆盖某一教材版本的全部内容。数学数值示例另用 SymPy 核对。
