## 本批计划与发现

1. 用三个固定公开例题核验实际Qwen：二次方程完整解、欧姆定律、氢气燃烧配平。使用独立测试账号，只调用固定数量的分析/诊断；协议成功与内容正确分开记录，不冒充学生试用。
2. 已发现二次方程正确因式分解被按参考解析行号判为符号错误。修复明确范围内的数学对齐：按原方程实数解集核对，不把参考文字行数当作必须完成的学生步骤；正确分支与完整答案区分，漏解定位到实际作答处。
3. 知识页按信息预算重做：默认三个知识点、两个相关基础，对应作答按需打开；不盲切公式。详情/知识/诊断三页统一区分有提示、未发现错误和待核对，不凭空默认第1步。
4. 核验算法反例、前端行为、实际修复后的诊断与手机截图，再做完整回归并提交。

## 约束

仓颉仍持有权限、MySQL和诊断证据；Python只计算。新符号路径限明确要求求解的独立、一元、次数1至4、有非空有限实数解的多项式方程；不把条件中的方程替换成目标，不处理变量分母、根式定义域或任意几何关系。分支正确不代表所有根完整；正确步骤配错误最终答案不宣布全对。超出范围沿用原计算路径，不冒充符号证明。

真实多学科核验入口 `scripts/check_live_subjects.py`；私有结果保存于 `.runtime/live-subjects-check.json`，仅固定公开题干与专用测试账号，不进入Git。初次运行三道题分析/诊断/重读均成功；原二次方程诊断内容存在上述错误，不计内容通过。物理答案30Ω与公式误用、化学配平与点燃条件经人工核对符合题意；均未宣称自动符号证明。
