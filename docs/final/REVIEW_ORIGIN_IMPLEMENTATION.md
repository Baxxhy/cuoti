# 复习回原题与旧草稿核对

## 实施计划

1. 复习失败或判题待核对时提供回原题学习入口，离开前保存草稿；详情记录复习返回位置，刷新详情后仍可返回。旧计划已失效时说明待办变化并保留继续原题的入口，不复活失效安排。
2. 原题/参考版本变化后，旧请求、照片和判题结果继续失效；保留旧文字作为折叠参考，经学生显式确认才放入空白的新作答。
3. 当前已输入的文字不被旧稿替换；旧稿可主动不再保留，跨账号隔离与原有草稿恢复合同保持。
4. 用行为、真实仓颉导航/返回与受控来源变化呈现验证，再核对实际分析补全后的版本变化；完成必要回归后提交。

基线：复习422提示到详情完成分析，但当前没有导航按钮；严格来源过滤同时丢弃旧文字。任务记忆已将复习结果的独立性标为unknown，本轮不改掌握评分、判题或后端合同。

## 当前实现与专项

- 失败/待核对时可回原题学习，详情携带返回的计划和题目；返回优先复用页面栈，刷新详情后使用明确的复习回退地址。
- 来源变化后的旧文字折叠保留，只允许显式放入空白的新输入；不会带入旧请求号、旧照片或旧判题。已有新文字不会被替换，可主动不用旧稿；本地缓存和页面内存均按账号隔离。
- 重新分析会使旧复习计划失效，保持原后端规则。旧安排不在待办时说明真实状态、保留旧文字查看及继续原题入口；其他题仍可作答，旧文字不会进入其他题输入。没有其他题时不再用“录入错题”覆盖恢复行动。
