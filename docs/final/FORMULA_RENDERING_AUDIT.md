# 题库公式渲染核验（2026-10-19）

本轮处理题库列表、题干、选项及共用公式组件。原始题库、上传图片和已保存的题目快照没有被改写。

## 修复

- 区分相邻公式与空 `$$$$`，兼容 CMM-Math 用转义美元包围的填空间距，保留真正的美元文本。
- 对解析失败的公式，兼容 `\triangleABC`、`\sinx` 等符号命令与变量粘连；已合法的 `\sinh`、`\infty` 等不拆分。
- 仅在存在 `\left` 且原式解析失败时，兼容残缺 `ight)` / `ight]`；已有的 `\right` 不重复替换。
- 缺失 `$$` 的 CMMU 文本按 TeX 分组之外的中文正文边界恢复连续排版；中文下标和 `\text{…}` 保留。仅接受所有片段都可渲染的恢复，不猜补关系符号或操作数。
- 无法恢复的片段保留转义后的完整原文，并显示“公式原文待核对”；相邻题句和后续合法公式继续显示。HTML 转义、KaTeX `trust: false` 保留。
- 题库列表显示原有签名题图、加载失败状态及明确的“来源：CMMU”标签，取消题干高度硬截断。确认题目页与教学练习的题干、选项也采用行内公式；正常解析步骤仍支持独立公式。

## 重复核验

`frontend/scripts/audit-formulas.mjs` 只读取导出的 JSONL，不连接数据库。每行包含 `id`、`question_text`、`options: [{key,text}]`、`solution`，可选 `usable` 标记当前可练资格。也接受导出字段 `question`。

```bash
node frontend/scripts/audit-formulas.mjs exported-questions.jsonl report.json
```

发现未恢复字段时退出1，报告只记录题目ID、字段和资格，不复制整道题；退出0只表示语法审计没有遗留片段。当前全库命令正确退出1，不能计为全库公式已全部修好。完整本地记录位于 `.runtime/latex-audit/final-audit.json`、`frontend-tests.log`、`typecheck.log`、`build-h5.log`、`build-app.log`、`browser-report.json` 和 `chemical-regression.log`。
