# 题库公式与学生页面核验（2026-10-19）

当前学生页面不显示数据集名称、来源标签或来源筛选。学科、学段、题型、题干和题图保留；来源及许可证仍在后台元数据中保存。

## 公式处理

- 相邻公式与空 `$$$$` 分开处理，兼容转义美元包围的填空间距，保留真正的美元文本。
- 仅对解析失败的公式，兼容 `\triangleABC`、`\sinx` 等命令粘连；合法的 `\sinh`、`\infty` 不拆分。
- 在存在 `\left` 且原式解析失败时，兼容残缺 `ight)` / `ight]`；已有的 `\right` 不重复替换。
- 对漏写 `$$` 的文本，按 TeX 分组之外的中文正文边界恢复排版，保留中文下标及 `\text{…}`。仅接受所有片段都能渲染的恢复，不猜补关系符号或操作数。
- 补充没有分隔符的公式、单位、几何符号、章节标题和数组表格；长行内算式在运算符之间自然换行，宽表格独立显示并局部横向滚动，答案括号不再居中到表格旁边。
- 保留 HTML 转义与 KaTeX `trust: false`。学生自己的 OCR 校对内容若仍损坏，共用组件保留原文核对提示；公共练习题库中的损坏内容由后台停止供应。
- 列表补题图和加载失败状态，取消题干高度硬截断；题干、选项和短答案连续行内排版，正常解析步骤仍支持独立公式。

## 残缺内容停止供应

当前真实 MySQL 题库1770题，覆盖9215个题干、选项和解析字段。旧解析器发现325个有分隔符公式片段报错，另外对裸命令检查发现初轮审计遗漏的59个字段。补充渲染后，仍有24个字段不能可靠恢复，涉及24道题；其中12道此前可练，另外12道原本已不在练习范围。

本轮通过仓颉原生命令将24题标记为 `format_review`，关闭练习和自动判题资格。原题文字、选项、答案、解析、图片和用户作答均未改写或删除；只更新质量状态、核验元数据和版本时间。当前1430道可练题的全部文本字段复查后，未恢复公式字段为0；移除渲染结果中的KaTeX节点后复查，未渲染的裸命令字段也为0。

保护范围：

- 题库列表、显式点题、随机练习、模拟考试及已有推荐资格检查均不再供应这些题。
- 已有练习/考试的快照保留，接口屏蔽停用题正文、题图及参考答案，学生页显示简短停用状态。
- 此后交卷在判题前、提交事务中都复查题目状态；停用题不调用算法、不计入得分或满分，不写成学生错题。事务内共享锁避免停用与交卷检查互相穿透；重复交卷仍幂等。
- 整次练习都停用时，显示“本次练习已暂停”，不显示误导性的零分。此前已交卷的历史分数不倒改，停用题内容仍隐藏。
- 相同内容指纹重复导入保留停用状态和核验依据；修正为新内容版本后保留旧损坏版本指纹，旧会话不会因此重新显示坏内容，新版本可以正常使用。新导入先用学生端实际渲染器审计，再由仓颉写库。

格式审计不等于逐题语义校勘；语法合法但原资料已缺失关系符号的情况，不能凭渲染结果判断正确。本轮没有猜改原题的数学结论或标准答案。


```bash

```
