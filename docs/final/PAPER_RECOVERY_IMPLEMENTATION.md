# 组卷编辑与失败恢复（2026-10-17）

组卷保留原有筛选、选题、分值、排序和三类导出，不增加新的功能目录。本轮修复打开试卷的请求乱序，并完善编辑期间的错误反馈与窄屏操作。

## 当前行为

- 连续选择甲、乙试卷时，只有最后一次选择能更新编辑区；较早返回的成功或失败不覆盖当前结果。打开期间显示“正在打开试卷”，暂时禁用旧试卷的编辑、排序、删除和导出。页面卸载后不采用迟到的打开结果。
- 保存、创建、导出和删除失败有持续可见的错误说明。保存失败保留标题、分值和排序；创建失败保留选题。确认删除后再次检查当前试卷，避免确认框打开时切换试卷而误删旧选择；删除失败仍可重试。
- 导出生成后若读取记录失败，不提示“导出已生成”；可以重新打开对应试卷核对实际记录。网络中断仍可能发生在服务端已写入之后，创建操作不宣称具备请求编号幂等；需要先核对历史再决定是否重试。
- 排序改为带题号和方向名称的按钮；删除、排序及导出按钮至少44 CSS px。标题与分值在H5使用原生输入，将可访问名称绑定到实际输入；App保留uni-app输入。标题可收缩，导出按钮按可用宽度换行。

本轮未增加刷新恢复未保存组卷编辑的本地草稿；“失败保留”指当前页面，服务端已保存的试卷仍可重新打开。App签名安装和真机按既有范围后置。
