# 作答照片中的图形关系核对

## 本批落地计划

1. 复用持久任务的照片上传、原件、异步识别与本人核对，不增加新的图片存储或数据库服务。数学几何题使用严格结构化转写，提取可见的角度、平行、垂直、等长、共线标注；外观判断不视为条件。
2. Python按原题明确条件核对候选关系；在有限、无歧义的三角形内角条件下计算角度关系。不能确认的图形标注明确待核对，不能从比例或外观推理。不执行模型代码，不把图形候选加入原题条件。
3. 核对作为独立工具记录进入现有智能体轨迹、照片与任务版本。页面折叠显示候选标注及核对状态，保留照片/文字修改；图形核对视为学习辅助，不增加独立掌握证据。
4. 验证标注结构、证据引用、互相冲突/外观候选、提示计分、照片版本/原件和恢复；完成实际固定图形样本与手机页面核验，再执行完整回归并提交。

目标是把手绘关系变成有来源、可核对的学习观察，而不是把任意几何证明交给模型后直接判为正确。角度和有限符号关系是本批可验证范围，其他图形保持待核对并继续已有文字作答。


## 实际实现

- `figure_review.py`定义严格Pydantic图形观察和核对结果；原图只在计算临时目录转换识别副本。几何题的照片一次结构化调用同时转写文字/标注；普通文字手写继续原路径。
- `inspect_figure`作为独立工具进入持久任务轨迹。标注候选须有逐字转写依据；外观、目标命题、选择项、歧义/冲突条件不当作已知事实。支持明确线段关系/共线与单个无歧义三角形的有限内角检查；不声称任意几何证明。
- 任务视图折叠显示核对结果和依据，原图仍可查看。图形反馈计为辅助，清掉照片或改用文字也不能消除已获得的提示；照片确认仅关联作答，模型图形候选仍明确未获事实确认，不写为原题条件或已验证记忆。
- 数据复用现有照片、动作、步骤和工具记录JSON；仓颉验证照片归属/版本并保存，Python不写MySQL，无新数据库依赖或迁移。
- 单个角度判题兼容度数/角标及常见LaTeX表示；角标不符、角名不明或多行过程不直接规范化为同一答案。模型的可能正确/可能错误进入待核对并保留真实反馈，不误报为确认错误。

## 支持边界

候选图形关系来自模型观察，必须对照照片；与原题相符不代表模型像素识别永远正确。已验证的是有限原题关系核对与来源/计分边界，不是自由手绘全自动证明。复杂图、多个三角形的角名歧义、无明确标记或未支持的命题保持待核对，已有文字作答与原图继续可用。真实语音与学生试用仍未由本批完成。
