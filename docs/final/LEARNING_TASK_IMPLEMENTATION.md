# 学习任务实现与验收记录

这是新版方案的代码实施记录。最终需求仍以 [总方案](README.md) 与 [智能体规格](AGENT_SPEC.md) 为准；本阶段没有完成所有最终交付门槛。Android/iOS发行继续按用户要求暂缓。

## 实际运行链路

详情页完成分析和诊断后，“继续解决”创建或恢复本人的学习任务。今日页会优先显示未完成任务；学习中心的“更多记录与任务”保留“订正学习记录”。新增“之前的过程”按需读取最近50次学生动作；学习完成后可主动打开“自检要点”。原完整教学、手写、图示和迁移题通路仍在“完整引导学习”中可达。

仓颉使用MySQL保存任务、学生动作、租约、步骤和审计。两个有界worker读取队列，Python执行只读算法，仓颉重新核对授权、题目指纹、记忆/知识快照和租约后事务提交。调用算法期间不持有题目/任务业务锁。任务完成与知识掌握分开；局部订正不写整题掌握。

- `backend-cangjie/src/learning_tasks.cj`：创建/查询、动作校验、版本、所有权、只读学生投影。
- `learning_task_worker.cj`：租约、受限并发、恢复、取消门槛、原子审计与学习证据提交。
- `backend-algorithms/learning_task_compute.py`：有类型的目标、内容块、检查点、策略规划、工具执行、验证和后续步骤。
- `frontend/src/pages/task/task.vue`：一个当前问题、真实等待状态、提示/答案曝光、刷新草稿与前后台恢复。

## 状态与接口

| 接口 | 作用 |
| --- | --- |
| `POST /api/v1/learning-tasks` | `question_id/request_id`，可选本人同题`session_id`；202返回，重复/并发创建复用活跃任务 |
| `GET /api/v1/learning-tasks` | 本人最近50项，可按`question_id`筛选 |
| `GET /api/v1/learning-tasks/{id}` | 重新检查输入版本，返回当前学生视图，不返回私有答案、工具输入或租约 |
| `POST /api/v1/learning-tasks/{id}/actions` | `kind/text/version/step_id/input_fingerprint/request_id`；202；动作含answer/hint/reveal/resume/use_text/visualize/observe_visualization/close_visualization；照片识别由上传入口排队，不接受前端伪造识别结果 |
| `POST /api/v1/learning-tasks/{id}/cancel` | 幂等取消；迟到算法结果不能覆盖取消/完成 |
| `POST /api/v1/learning-tasks/{id}/handwriting` | multipart原始照片、版本/步号/指纹/request_id；保存原图并202受理，后台转写、本人核对后另行提交 |
| `GET /api/v1/learning-tasks/{id}/history` | 本人最近50次动作；白名单返回原回答、公开反馈、判定作用域和辅助标记，不返回私有结果 |
| `GET/PATCH/DELETE /api/v1/learning-tasks/{id}/self-check` | 一任务一句要点；显式确认、当前版本、冲突重读；删除可重放 |

同一动作request_id的语义内容必须相同，JSON键顺序变化不算新请求。旧版本/步号不能提交到新步骤。已受理动作保存在MySQL；浏览器草稿按用户、任务和题目指纹隔离，网络失败保留请求编号，不在刷新时自动重复POST；退出清理本机任务草稿。设备存储失败不阻断向后端提交。

状态为queued/running/waiting_student/needs_review/completed/failed/cancelled/stale。主动结束和原题失效不会删除原作答。离开页面会保留活跃任务，可继续同一检查点；主动结束需要回原题重新开始。错误参考结论、无法可靠核验的答案和耗尽预算均不写确定成功证据。

## 实际决策与证据边界

1. 基于原题、原作答和诊断位置选择可验证的局部步骤。当前局部符号订正适用于独立的一元一次方程；学生写出右端表达式或完整对应等式均可验证。不支持的题型进入原题独立作答，继续复用统一判题，不能伪造局部验证。
2. 答错后，规划器在受控知识检索/步骤关系之间选支持工具。Qwen通过原ApiPoolProvider轮询；模型不可用、超时或引用无效时记录规则回退及原因。
3. 知识卡来自仓颉按学科、名称/编码匹配的真实MySQL记录；Python过滤年级与内容。零命中会留下rejected轨迹并换用原题关系，不任取同学科前几条冒充精确命中。
4. 局部正确转到原题独立作答。判题复用原`grade_answer`；主观或不确定结论保留needs_review。仅凭“我会了”不推进。
5. 一元一次方程可构造一个常数项变化的对照题；原式、单一变化、目标和新答案独立验证后才展示。其他题型本阶段不生成未验证的对照题，原版真实题库和迁移练习能力保留。
6. 对照题独立正确才可提交一次近迁移证据与复习安排。看过提示/答案、重复做过同一对照题均不重复计为新的独立迁移；同学科重复录入原题也不绕过该边界。对照曝光使用用户/题目内容散列唯一记录，与任务和学习更新一起提交，防止不同记录并发重复计分。该结果不宣称整个知识点已掌握。

数学验证额外拒绝符号化简丢失的变量分母、负幂和函数定义域条件。例如`0*x/x`不能因为化简成0而被记为确定正确。符号工具的适用范围有限，超出范围明确不作自动证明。

每个工具保存作用范围、验证状态、规划来源、公开决策摘要与来源引用；关联既有agent_runs/agent_tool_calls。当前支持check_step、grade_answer、knowledge_search、step_alignment、compare_variant、recognize_handwriting、inspect_figure、visualization。当前记忆按本人/学科收集掌握估计、误区候选、有来源的历史更新、复习结果、安排和自检要点；包含来源版本与时效，提交前重新读取。实际合同见记忆实施记录；有限图形关系核对已接入，见文末补充，任务图示工具见下节。任务内照片转写见下节。

## 执行上限与恢复

- 一次学生动作最多3条工具轨迹，最多2次路径调整；支持策略规划最多5秒。
- Python计算至多38秒、仓颉客户端至多40秒、认知计算至多5秒；共用领取开始的45秒单调提交预算，按剩余时间缩短。准备、重验、检查点更新后和提交前均复核。
- 两个worker；租约90秒。重启或失效租约重新执行只读计算，写入依靠动作唯一键、租约、版本和事务防重。
- 一个任务最多24个计算回合，含恢复的执行尝试最多72次；达到上限给出暂停/回原题行动。
- usage不可获取时记录null，不编造token或费用。取消不保证远端推理立即停止，但禁止其结果继续写入。

实际异常验证见预算实施记录；提交预算不等于底层IO硬实时中断，不能据此宣称所有真实模型请求的端到端延迟均已测量达标。

## 自检要点、动作历史与档案投影

- 一次学习任务保存一句最多300字的自检要点；只有当前原题版本已完成的任务可新建或编辑，保存请求必须带学生确认、题目指纹和要点版本。前端主动展开后才加载；H5实际文本框有可访问名称，处理uni-view子组件插槽渲染时序。断网保留草稿，冲突重读展示最新要点和原草稿，不能静默覆盖。
- 一句要点是student_self_report，与解题正确、教回和迁移证据分开；保存、编辑、删除不调用认知更新。save_self_check审计与要点同一事务，审计只保留操作、关联ID与版本，不重复保存正文；删除清空正文并保留删除版本以拒绝旧窗口覆盖。
- 相同版本/内容重试不重复增加版本或审计。删除后可以确认保存新的内容；不同内容的旧版本请求返回409。原题更新后要点保留为历史提醒，禁止编辑、仍可删除。
- 任务历史仅返回学生动作、公开反馈、作用域与判定，默认收起；参考答案、完整检查点、工具输入、凭据和租约不作为历史接口字段返回。主动请求过的答案可能出现在其当时的公开反馈中。
- 学习档案新增任务及要点投影，当前有效任务可直接继续。局部订正、原题独立正确、一次近迁移分别显示；不改变既有“理解并讲清”“相似与综合迁移”要求。源题变更后的任务不计当前进度，事件与要点仍可回看。
- 新要点当前用于学生回看；接入完整长期记忆检索、来源重验证和时效策略仍属于后续工作。

本阶段最终验证：前端98项/28文件、类型、H5和App本地资源构建通过；`make verify-cangjie-browser`中的45项算法、27组仓颉原生、完整HTTP/MySQL、重启恢复、20项浏览器均通过（4角色项仍跳过）。新增真实浏览器流程包括保存、刷新回读、编辑、删除、重新保存与原题档案回读；日志`/tmp/zhiwei-self-check-browser-final.log`。[自检页面样例](screenshots/task-self-check.png)。外部模型仍使用模拟协议，真实教学质量和学生试用没有因此获得证明。

## 持久手写作答

- 拍照/选图按original上传，仓颉保存原始JPEG/PNG/WEBP字节和SHA256，不用识别副本覆盖。15MB文件上限，图像真实格式/2500万像素校验在算法执行；签名正确但图像损坏会形成可恢复失败，不计解题证据。
- 上传入口不调用模型，校验当前任务所有权、步号、版本和原题指纹后202受理。MySQL保存照片及recognize_handwriting动作，复用任务worker/租约/检查点。识别副本仅在Python临时目录规范化，Qwen仍经过ApiPoolProvider，32秒转写上限属于原38/40/45秒执行预算。
- 转写结果经Pydantic验证，仅表示照片中的学生文字。空内容/不清晰标为待核对，不自动触发判题，不更新掌握分。学生可对照照片编辑文字、恢复上传前输入或仅用文字；必须显式“确认文字并提交”才关联照片进入原统一判题。
- 前端只提交照片ID和确认标记，仓颉重新读取已保存的识别，不接受客户端传入的识别JSON/原图路径。照片同时绑定任务、原题指纹和识别后确认步号；旧步骤及其他任务照片不能混入本次作答。
- 断网保留上传请求号和文字；刷新查询任务，不自动重传。识别失败可重试同一原图或改用文字；本机文件路径不可用时先核对服务器状态再重新选图。查看照片时重新读取签名地址，保留已修改文字；原图和已修改文字可从任务/动作历史回看，图片主动打开，不默认占满作答页。
- 取消或编辑原题后丢弃迟到识别结果；保留原图，不提交旧学习证据。重启仅重做只读转写，动作和步骤依靠租约/唯一键防重。
- 手写照片目前作为转写来源与学生确认后的作答记录；图形关系与图像推理仍需后续接入，原式图示另见下节，不能把OCR完成称为几何证明。

照片专项可使用 `CANGJIE_VERIFY_FOCUS=task-images make verify-cangjie`（隔离库，仅该照片链路的HTTP专项；不替代完整验收）；完整门槛仍为`make verify-cangjie-browser`。任务失败只记录执行阶段/HTTP或MySQL类别代码，不写上游错误正文和凭据。

手写阶段最终证据：50项算法、27组仓颉原生与完整HTTP/MySQL通过；实际进程重启恢复同一照片且不重复步骤；20项浏览器通过、4角色项待补验。前端100项、类型、H5/App本地资源构建通过。[最新核对页面](screenshots/task-handwriting.png)。完整命令`CANGJIE_VERIFY_FOCUS= make verify-cangjie-browser`，日志`/tmp/zhiwei-handwriting-delivery-final.log`。新增浏览器确实执行文件选择/上传、刷新保留、文字修改和确认后的统一判题；外部模型为本地模拟，不代表真实字迹识别质量已验收。

## 原式图示与持久观察

图示复用既有VisualizationSpec和静态Canvas，不执行模型生成的代码。学生在文字作答阶段按需“用图看看”；规划器也能基于卡点选择visualization工具。生成前重新读取当前原题/对照题，验证学科、作用域、原式与参数；不支持或工具无效时记录rejected并回到步骤支持，不把不完整条件改成另一道题。

| 图示 | 实际范围 | 确定性验证 |
| --- | --- | --- |
| 等式两边同操作 | 当前可验证的一元一次原式或已验证对照题，常数和系数绝对值≤10000 | SymPy校验两边同减delta后等价；数值示意不展示未知数解，不把天平当作物理测量 |
| 一次函数 | 完整独立的`y=kx+b`数值表达式，支持有理数/有限小数及等价形式，原k/b绝对值≤10000 | 多项式次数、参数来自原式；k=0说明不再是一次函数 |
| 二次函数 | 完整独立的二次多项式，展开/顶点形式均可，顶点参数a/h/k绝对值≤10000 | 验证顶点式与原式等价；a=0说明不再是二次函数 |

带额外文字条件、变量分母、负幂、三次/非多项式及超范围表达式不自动转换图示；继续原文字作答和既有教学。函数视窗根据原系数/顶点固定，参数变化后曲线在同一坐标范围内移动，超窗部分裁剪；不随当前参数自动居中。大平移量仍显示真实坐标，分数原式保留精确排版，控件数值展示若取近似明确标“约”。当前不提供缩放或完整几何作图证明。

动作`visualize`、`observe_visualization`、`close_visualization`仍使用既有202受理、版本/步号/题目指纹/请求号、租约与事务，不另建写库路径。函数控制值必须严格匹配当前图示变量、范围和步长，布尔值/多余键/非有限数拒绝；仓颉先校验，Python按真实上下文重建核验。结构化图示和最多1200字观察存入检查点/动作JSON，无新增数据库迁移。相同请求号调换JSON键序可重放，改变内容不能覆盖旧动作。

图示标记该阶段assisted，不产生attempt或认知更新；观察“我会了”仅是学生自述。查看对照题图示后正确作答也不算新的独立迁移证据，继续复用提示/答案/重复曝光的资格边界。进入下一阶段清除当前图示，保留动作历史。历史只输出标题、当前关系、控制摘要和观察，不暴露完整检查点、预期观察或参考答案。

页面一次只展示当前图示和观察输入，暂收起原答案输入，收图后恢复原文字及照片。控件有文字与加减按钮，键盘可操作；文字参数摘要提供图形替代。观察草稿按本人/任务/题目指纹/阶段/原式隔离；记录冲突保留本机草稿并明确展示已保存内容，不静默覆盖。任务记录与本机草稿仍有跨设备步号隔离的后续门槛。

照片与支持动作同阶段时重绑确认步号，图示保存回滚的失败视图保留照片，恢复后仍可核对并提交原作答；原始图片字节保持不变。完整回归另验证进程重启后恢复同图示、参数和观察，不重复写步骤。
