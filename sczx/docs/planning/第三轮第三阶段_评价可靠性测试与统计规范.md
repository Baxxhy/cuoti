# 自动评价可靠性测试与统计规范

2026-11-16 / design-v1。以下是待实现的验收门槛，不是已测性能。

## 冻结夹具与可靠性门槛

夹具至少覆盖：已知可证正确、已知错误、证据不足、不存在引用、越年级引用、错误干预、无效历史、来源片段不支持、等价改写、输出顺序反转、组标签注入、参考答案/expected_strategy金丝雀泄漏、格式错误、超时/拒绝、统计缺失。每类至少4个独立fixture，划分开发集与从未参与调参的冻结留出集；一次拆分后禁止按结果挑样本。

冻结标签由自动可证的构造事实提供，例如不存在ID、明确年级冲突、符号计算反例、标记为helped/unverified的历史，不能把LLM生成的“正确”标签当独立真值。开放学科的语义金标无法自动建立时，只做可证约束与变换一致性测试，开放语义准确率标unknown，不靠自循环模型评分证明正确。

门槛：白名单字段及金丝雀泄漏0；确定性身份/年级/历史/数学范围单元夹具100%符合断言；应为unknown的不可证案例不得输出deterministic_verified。LLM留出集仅在具备独立可证oracle的项目上计算一致率、严重错误漏检率、unknown率；预注册一致率≥0.90、严重错误漏检0作为工程启动门槛，并报告样本数和区间，不声称其证明真实场景90%准确。顺序反转代理均分差≤0.10（0—2量表）、等价改写绝对差≤0.20；这些是规划阈值，实现和实测前可见但不能事后调阈值通过。

执行3次无状态重复评估，报告重复一致率与各指标波动，不能以多数票消除所有相关模型偏差。开发集调参后必须新版本且只在冻结留出集做一次门槛判定；失败自动停止，旧结果保留，不能无限重试直到成功。

## 自动统计

组键由统计器在评分锁定后读取。保留全部192个预定生成位置的状态；生成失败率=生成失败/超时/拒绝/中断数÷192，未执行单列并报告完成率，禁止将未执行混写为模型错误。Evaluator失败率另用已安排评价的输出作分母。每个指标同时给有效n、unknown、not_applicable、not_measurable与生成失败数量。

LLM代理指标均分和分布与确定性指标分别报告。主要差异B−A、D−B、C−D；所有原始逐例及六种组间描述比较公开，主次预注册，不选择性报告。报告困难类型/学科/历史类型分组，不在有效样本不足时输出假精确值。

配对统计先对每个情境同组3次重复求可测均值；按同题不同历史的family_id整块重采样，保留所有组、历史配对及重复关系，禁止把同一情境的3次当成3个独立受试者。冻结种子20261116，10000次family级配对bootstrap，取差异分布2.5%/97.5%分位点为描述性95%区间。当前16情境含5个配对家族及6个单例，最多11个family，不能推广总体显著性。

仅对双侧均可测的配对计算差异，同时披露丢失配对及其组别，不用0补unknown。少于10个独立family、全部值相同导致退化或覆盖率不足0.8时，区间标insufficient_information，给出原始差异和缺失结构，不伪造CI。分科常不足此门槛，应显示不可估区间。

生成失败单列并提供失败惩罚敏感性界限（按量表理论最小/最大值形成最坏/最好界限），不得把失败当作合格教学内容。时间分生成端与评价端分别统计；token可得则记录，实际计费未知为null。真实学生学习增益和长期教学效果始终not_measurable，不输出LLM模拟学生分数替代。

## 无人值守验收状态机

设计冻结→实现检查→配置就绪→可靠性门槛→生成→评价→结果封存→统计→报告。任何门槛失败输出machine_blocked并有限退出，不要求人填写评分表；停止是自动化的有效结果，不是自动判通过。只有之后收到正式实验启动授权才能进入生成阶段。第三阶段本次交付停在设计冻结与设计完整性校验。
