# 四组全自动实验设计

2026-11-16 / design-v1。用户当前明确采用无人值守实验、自动评价和自动统计。本次只交付设计及可机器核对的契约，不实现运行评价器、不发模型请求、不启动正式实验。旧pilot-v1/v2/v3、旧评分文件及业务数据不改写。

## 四组定义

四组均输入相同当前题目、原答、自述和通用公开学科知识，共用模型、思考强度、输出schema、时限、候选预算、输出预算和重试规则。

|组|检索候选|相同范围学习历史|项目审核/困难/适用范围/策略决策|
|---|---|---|---|
|A 普通模型|无|无|无|
|B 检索增强|同一检索器，最多4条|无|无，由模型判断|
|C 完整方法|与B/D完全相同的检索候选，再筛选|有|有，复用现有纯函数|
|D 历史信息对照|与B/C相同检索器和最多4条|与C相同原始相关历史|无，由模型自行利用历史与候选|

D是本阶段设计选择，定位为信息匹配基线；不是声称既有代码已实现。固定D模型也可自行判定来源或提出困难，这不算违反分组；禁止人为削弱D。C筛除候选后不另补召回。C/D历史的证据ID、正确性核验状态、helped标志和时间范围完全相同，C额外仅为处理/决策产物。不得给C增加参考答案、独立题答案或更有利公开知识。

主要对照：B−A衡量检索包差异；D−B衡量历史信息差异；C−D衡量该已定义审核、适用性、困难与策略机制组合的差异。C−B是信息与机制的混合差异，不能称纯算法贡献；C−D也不能拆解各机制的单独因果贡献。六种组间比较中以前三项为主，其余描述，不挑最大差异作为主结论。

## 运行与冻结

沿用16情境作为新版本候选，先自动检查每条包含原题/原答/证据/历史/来源/独立题，剔除评测标签泄漏，不修改旧版本。未来每情境每组3次为16×4×3=192个生成试次，不是原144次。此数量仅规划，当前执行预算0；评价调用另算，不能混进生成预算。

未来使用三轮Latin式轮换并以冻结种子置换情境顺序，每个情境按ABCD/BCDA/CDAB的顺序交错；因3轮无法让4组完全平衡位置，明确记录不完全平衡，不假称Latin方完整平衡。后续若要4轮需另行改冻结版本与预算，本阶段不调整。每试次失败仍保留，公平重试/修复次数上限各组一致。失败、超时、拒绝、中断和未执行分别统计。

生成模型规划gpt-6-luna/low，与当前工程一致；精确模型快照若服务不返回，标为unavailable，不能宣称固定版本可严格复现。Evaluator规划使用独立提供者或独立模型系列、独立无历史会话；当前尚无已核实独立服务，状态unconfigured，不擅自借备用密钥。独立配置缺失时自动停止为configuration_blocked，禁止拿被测生成器冒充独立评价器。

冻结文件包括新情境、候选快照、来源许可、历史范围、公共知识、机器规则、两类提示词、模型/版本可得性、schema、预算、可靠性夹具、统计口径、随机种子及依赖源码哈希。写入只增manifest，运行绑定manifest SHA256；任何变更建新版本和run，不重写旧输出。设计manifest与运行冻结分开，设计文档SHA不代表模型配置已经落实。

## 无人值守门槛

配置检查→输入/盲化检查→Evaluator可靠性测试→生成→盲化评价→锁定结果→组别关联→统计→机器报告。每步成功才继续；失败写结构化原因、保留原始数据并自动停止或按统一有限预算重试，不进入人工仲裁或人工填写表。只有另行明确启动正式实验后才运行192次。当前任务结束于设计验收。

旧人工盲评/专家确认规范从当前活跃流程退出。旧CSV与pilot内容只读存档，不删除或修改；不再作为运行依赖。业务经验库既有来源审核记录属于冻结历史输入，本轮不改业务审核功能，也不将其变成人工实验门槛。
