## 2026-11-08 接入方式调整

用户明确要求所有模型调用使用本机 Codex 终端、`gpt-6-luna`、最低思考强度，并拒绝使用备用 `OPENAI_API_KEY`。当前本机模型目录的最低强度是 `low`，输入模态仅为文字与图片。CLI 是外部模型调用客户端，不部署本地模型。

- 默认传输已切到 `codex_cli`，保留作业、重试、SSE 和 MySQL 业务记录。没有自动回退到旧 HTTP 请求。
- 新增 `codex_provider.py`，通过 `codex exec`、JSON Schema、标准输入和图片附件调用；固定模型与 low。每次使用临时工作目录，不进入项目源码工作区。
- 命令不用 shell 拼接，限制为只读，关闭 shell、应用、插件、网络搜索和多代理工具；结构与重排 ID 再校验。取消与超时回收子进程组。
- 显式排除备用 OPENAI 凭据及地址环境变量。CLI 默认使用自己的登录；本机默认工作区路由不可达，实际验收采用项目忽略目录中的独立 CLI 配置，复用已获授权主服务的 Responses 协议与凭据环境变量，未复制密钥。
- 文本、OCR、语义重排走 CLI；向量、ASR、TTS 显示明确不可用原因并禁用运行，不伪造向量、转写或音频。
- `SCZX_CODEX_HOME` 相对路径以 backend-business 为基准；支持可选 CLI 可执行路径及代理继承设置。

本轮证据：真实 OCR 返回 `Solve: x - 3 = 5`；重排把天平材料排首位；网页文字作业 `job-c97f21eab9944262a73f5c0712cf61f4` 保存了 `Codex CLI · low` 与 `gpt-6-luna` 执行记录。网页刷新恢复、三类不可用按钮、390px 无横向溢出、1440px/390px 截图检查通过，浏览器异常为 0。临时子进程契约检查验证固定模型/强度、剔除备用密钥、结构错误、进程失败、取消回收和不可用能力；仅为工程证据，与真实模型调用分开。

首轮 OCR 返回未满足题图核对断言，未计为成功；复核真实原图并重新调用后匹配。识别后人工修订确认流程继续保留。受限环境的临时子进程检查曾挂起；在与实际后端相同的主机环境通过，已停止挂起检查。

以下内容保留先前 HTTP 版本的工程与历史验证依据；其中 Embedding 成功不代表当前 CLI 提供向量能力。

## 已确认范围

2026-11-08 用户确认第一轮四项选择，并确认最终共同理解。

- Vue 3 + JavaScript，现有 Nova 视觉与 Vue 组件；FastAPI、MySQL、CPU 部署，全部模型通过外部 API。
- 学生学习页文字/题图求助 → OCR 修订确认 → 提示优先、按需展开指导 → 保存 → 教师回看。
- 数学未能核对时标记需核对，不直接判对错；保留原图、原答、修订和发布快照。
- 页面离开后后台继续，刷新恢复；服务重启保留已完成结果，中断执行可手动重试。
- 六类能力可使用不同供应商及模型，全部至少一次真实调用；ASR/TTS 本步在管理端提供最小上传、转写、修订与播放入口。
- 可恢复错误最多自动重试两次，之后手动重试并保留执行记录。缺少配置时继续独立工作，明确缺项，不以模拟结果代替真实验收。
- 工程保持简单可运行，不建设费用统计或预算功能。

## 环境与配置调查

沙箱内最初看不到服务进程；随后通过获准的主机检查确认，隔离 MySQL 23317、Vite 5177 及旧 API 8000 原本仍在运行。复用了隔离 sczx 数据目录，没有重新初始化或连接父项目数据库。

`/tmp/sczx-venv` 已安装新增 HTTPX 和 SymPy，依赖也已写入项目安装清单。原环境代理失效，安装通过官方包索引直连完成。API 已按本次代码重启，迁移应用到 `0005_model_job_deduplication`。

当前可用配置来自既有授权 API 池：文本/图文使用 `gpt-6-luna`，Embedding 使用服务实际列出的 `text-embedding-3-small`。向量、重排和语音没有从旧池字段中被假定为可用。

对同一已配置服务的专用 `/rerank`、`/audio/transcriptions`、`/audio/speech` 最小探测均返回 HTTP 503。随后保留标准 Rerank 适配，并增加明确的 `chat_rerank` 协议：通过现有文本模型进行真实 LLM 语义排序，不冒充专用重排端点，保留模型名和分值含义。该方式已通过实际调用。

语音又按官方 Chat 音频格式探测了已授权主服务，输入音频和输出音频请求均返回 HTTP 400，没有可用音频结果。当前剩余配置缺口为 ASR 与 TTS。公开探测音频来自官方文档样本，下载时未发送任何 API 凭据。

环境还有一组备用 `OPENAI_API_KEY`。使用该组凭据向已配置 OpenAI 地址（未配置时回退官方地址）查询模型的提议被自动审批拒绝，原因是缺少对该组凭据和具体目的地的明确授权。该探测未执行。当时另行发出只读查询授权问题，用户随后明确拒绝使用备用凭据；不再执行该查询。
