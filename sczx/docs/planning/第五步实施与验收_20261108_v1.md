状态：实施中。grill-me 访谈及最终共同理解均已获用户确认。六类适配、任务及页面源码已实现，文本、图文/OCR、Embedding、LLM 语义重排已通过真实调用；ASR、TTS 仍缺少已验证的可用服务配置。尚未达到“六类全部真实验收通过”，不能宣布第五步完成。

## 已确认范围

2026-11-08 用户确认第一轮四项选择，并确认最终共同理解。

- Vue 3 + JavaScript，现有 Nova 视觉与 Vue 组件；FastAPI、MySQL、CPU 部署，全部模型通过外部 API。
- 学生学习页文字/题图求助 → OCR 修订确认 → 提示优先、按需展开指导 → 保存 → 教师回看。
- 数学未能核对时标记需核对，不直接判对错；保留原图、原答、修订和发布快照。
- 页面离开后后台继续，刷新恢复；服务重启保留已完成结果，中断执行可手动重试。
- 六类能力可使用不同供应商及模型，全部至少一次真实调用；ASR/TTS 本步在管理端提供最小上传、转写、修订与播放入口。
- 可恢复错误最多自动重试两次，之后手动重试并保留执行记录。缺少配置时继续独立工作，明确缺项，不以模拟结果代替真实验收。
- 工程保持简单可运行，不建设费用统计或预算功能。

## 当前工程

基于 `8fb1aa4` 的第四步工程继续开发，已有未提交的父级文档改动和 sczx 旧文件删除不纳入本次工作。

已新增：

- `model_provider.py`：按能力选池、兼容 HTTP 协议、结构解析、有限重试错误类型与限流冷却。真实配置位于本地忽略的 `backend-business/config/model_pool.json`，公开配置只有样例。
- `ai_schemas.py`：OCR、指导和作业输入模型；`math_tools.py` 迁入适用旧数学程序；`grading.py` 负责后端表达式核对。
- `model_jobs.py`：MySQL 作业、执行尝试、事件、工作循环、超时、恢复和自动重试。
- `ai_routes.py`：创建/列表/详情/事件/手动重试/转写修订，使用原会话及师生记录关联。
- 迁移 `0003_model_jobs`、`0004_model_job_utc`、`0005_model_job_deduplication`：新增任务及数学核对字段、UTC 时间修正、进行中输入唯一约束；旧教学记录保持原格式。
- 前端 `ModelAssistant`、`ModelResult`、`ModelConsole`、`ModelHistory`、模型服务与任务订阅，接入学习、独立检查、教师学情和管理运行页。
- 作答及补救改用后端接口与数学核对，移除前端固定答案判定；聚合保存不接受前端补救正确性结论。

交付代码不依赖父项目源码或虚拟环境。旧 API 池只支持文本和图文，六类适配已重新组织；旧本地 ASR 未搬入。

## 环境与配置调查

沙箱内最初看不到服务进程；随后通过获准的主机检查确认，隔离 MySQL 23317、Vite 5177 及旧 API 8000 原本仍在运行。复用了隔离 sczx 数据目录，没有重新初始化或连接父项目数据库。

`/tmp/sczx-venv` 已安装新增 HTTPX 和 SymPy，依赖也已写入项目安装清单。原环境代理失效，安装通过官方包索引直连完成。API 已按本次代码重启，迁移应用到 `0005_model_job_deduplication`。

当前可用配置来自既有授权 API 池：文本/图文使用 `gpt-6-luna`，Embedding 使用服务实际列出的 `text-embedding-3-small`。向量、重排和语音没有从旧池字段中被假定为可用。

对同一已配置服务的专用 `/rerank`、`/audio/transcriptions`、`/audio/speech` 最小探测均返回 HTTP 503。随后保留标准 Rerank 适配，并增加明确的 `chat_rerank` 协议：通过现有文本模型进行真实 LLM 语义排序，不冒充专用重排端点，保留模型名和分值含义。该方式已通过实际调用。

语音又按官方 Chat 音频格式探测了已授权主服务，输入音频和输出音频请求均返回 HTTP 400，没有可用音频结果。当前剩余配置缺口为 ASR 与 TTS。公开探测音频来自官方文档样本，下载时未发送任何 API 凭据。

环境还有一组备用 `OPENAI_API_KEY`。使用该组凭据向已配置 OpenAI 地址（未配置时回退官方地址）查询模型的提议被自动审批拒绝，原因是缺少对该组凭据和具体目的地的明确授权。该探测未执行，已另行发出只读模型查询授权问题，等待用户回答；不得绕过此拒绝。
