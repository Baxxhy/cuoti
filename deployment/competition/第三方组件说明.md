# 第三方组件说明

本包分发应用运行所需的第三方组件，保留组件随附的许可证和软件包元数据。应用采用这些组件的原有功能，不将其模型或通用算法作为团队自行训练或独立发明。

| 组件 | 用途 | 来源 |
| --- | --- | --- |
| Ubuntu 22.04 | 容器基础系统 | https://ubuntu.com/ |
| 仓颉运行时与 stdx | 执行仓颉业务程序 | https://cangjie-lang.cn/ |
| MySQL Community Server 与客户端 | 业务数据保存 | https://dev.mysql.com/downloads/mysql/ |
| CPython | 执行算法服务 | https://www.python.org/ |
| FastAPI、Uvicorn | 算法 HTTP 服务及部署网关 | https://fastapi.tiangolo.com/ |
| LangGraph | 单协调工作流 | https://github.com/langchain-ai/langgraph |
| SymPy、Pydantic | 数学运算与数据结构检查 | https://www.sympy.org/ 、https://docs.pydantic.dev/ |
| Qdrant | 检索索引 | https://github.com/qdrant/qdrant |
| BGE-M3、BGE reranker v2 m3 | 文本向量与候选排序 | https://huggingface.co/BAAI/bge-m3 、https://huggingface.co/BAAI/bge-reranker-v2-m3 |
| faster-whisper small | 本地语音识别 | https://huggingface.co/Systran/faster-whisper-small |
| Edge TTS | 在线语音合成 | https://github.com/rany2/edge-tts |

AI 接口由部署者自行配置合法有效的服务凭据；本包不包含 API 密钥和外部 LLM 权重。基础镜像和组件各自的许可继续适用。MySQL 源码及对应发行资料可从官方 MySQL Community 下载页取得；本包未修改 MySQL 源码。

演示题库为程序构造的 24 道基础方程选择题，明确标注为自编演示内容，可用于本项目演示和验收，不包含原运行环境中的个人学生数据或第三方大规模题库。公开知识内容来自本项目已有工程资料。

试卷公式排版使用 Node.js、KaTeX、esbuild 与 Playwright Chromium；图形页面由浏览器在容器内部渲染为 PDF 或表格内公式图片。对应来源：https://nodejs.org/ 、https://katex.org/ 、https://esbuild.github.io/ 、https://playwright.dev/ 。中文字体使用 Noto CJK，来源：https://github.com/notofonts/noto-cjk 。这些组件及模型的授权以随附许可文件为准。
